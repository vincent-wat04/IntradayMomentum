# 日内回转 = 做T 叠加仓(用户定义,2026-10-12)

* 目的:持有 B&H 底仓时,日内**高点卖出、低点买回**,降低持仓成本、增厚 B&H 利润(倒T = 先卖后买;正T = 先买后卖,需要现金)。
* 一直没碰到买回点位 → **收盘强制买回**(MOC);不得隔夜留下偏离底仓的头寸。
* 评估对象 = **叠加仓的净收益**(扣每边成本),与底仓无关;卖出侧(叠加空)与买入侧(叠加多)分开报。
* 首选设计 = **事件驱动的『卖出信号 → 买回信号/收盘』配对**,一次只开一个叠加仓;不要用『每根 bar 按指标状态翻仓』作为主检验(换手会淹没 alpha)。
* 不能忽略的机会成本:卖出期间错过的 B&H 漂移(QQQ 10:00→收盘平均 +2.3bp/天),已含在叠加仓 P&L 里。
* 噪声护栏默认 |ΔSharpe|<0.15。用户询问过降到 0.05 能测哪些线索(尚未决定);若采用,仅用于线索发现,真正过滤器是族内安慰剂与前向验证。
