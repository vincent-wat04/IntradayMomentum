# 全仓库实现审计

你的要求是"重新扫一遍所有实验的 implementation，确保绝对正确"。先说清楚我的做法和它的边界。

## 0. 为什么不用"逐行读代码"

这个项目里我漏掉过至少 5 个错误（逐 bar 累加的前视、bar 时标偏移、TQQQ 名义金额、
后复权价算每股成本、横截面零假设设计错误）。每一个都是**读代码时看起来完全正常**的。
再读一遍只会得到同样的结果。

所以这次换成**机械化审计**：写能自动抓住整类错误的测试。判断一个测试是否有价值的标准是
——**它能不能在本项目已经发生过的真实 bug 上失败**。抓不住任何已知错误的测试是摆设。

四种手段：

| 手段 | 抓什么 | 对应踩过的坑 |
|---|---|---|
| **未来数据投毒** 把 T 之后的数据乘以夸张倍数，T 之前的输出必须逐位不变 | 任何形式的前视 | 全样本标准化、忘记 shift(1)、未来除权因子 |
| **日内 bar 投毒** 污染当日后段 bar，前段的**决策**必须不变 | bar 级前视 | PART8 的 `pnl += pos*(op[j+1]/op[j]-1)` |
| **独立重写实现** 用结构完全不同的方式再写一遍，逐位对账 | 记账错误 | 成本重复扣/漏扣、入场价错位、MOC 价格错 |
| **预言机对照** 灌入人造信号（`score_t = r_{t+1}` 必须赚大钱；`score_t = r_t` 必须≈0） | 对齐错位/泄漏 | 横截面回测的滞后约定 |

每个测试都配了**反向对照**：故意制造一个应当失败的场景，确认测试真的会失败。
没有反向对照的"通过"是没有信息量的。

**边界（必须说清楚）**：这套方法能证明"代码实现了我以为的那个策略"，
不能证明"这个策略在未来赚钱"。它抓不住的是：参数选择的过拟合、
样本期特殊性、以及我**没想到要去检验**的假设。所以"绝对正确"做不到；
能做到的是"整类错误被机械化排除，剩余风险被显式列出"。

跑法：
```
python audit/audit_data.py        # 数据层  22 项
python audit/audit_engine.py      # 引擎层  19 项
python audit/audit_factors.py     # 因子层  16 项
python live/replay.py             # 实盘代码等价性
python live/crosscheck.py         # 实盘状态 vs 回测状态
```

| 日期唯一且递增 | 是 |
| 所有非空 bar 价格为正且有限 | 3,028,080 个 bar，异常 0 个 |

**查实的一个差异**：QQQ 有 33 天（1.7%）的隔夜收益与 yfinance 口径差 5~10bp。

用 yfinance 的 Open 替换我们的分钟首根 bar open 重跑策略：Sharpe 1.1217 → 1.0998，
差 **−0.022**，受影响 32 天。即：不影响结论，而且我们的数据源给出的是**更保守**的那一边。

## 2. 引擎层（19/19 通过）

### 2.1 前视

- 跨日投毒（cut = 2021-06-30 / 2023-03-15 / 2025-01-15）：cut 之前 629/1058/1519 天 ×
  6 个输出**逐位完全一致**。
- 日内投毒（污染 13:00-15:30、11:00-15:30 的 bar）：之前的 704 笔决策完全一致。
- **反向对照**：从 09:40 开始投毒 → 决策从 1725 笔变成 1641 笔（投毒确实生效）；
  检查时点后移 5 分钟 → 累计收益变化 40.47%（测试确实有鉴别力）。

### 2.2 成本记账

| 检查 | 结果 |
|---|---|
| 零成本时 net == gross | 最大差 0.00e+00 |
| 成本对 cost_bp 严格线性 | 最大偏离 0.00e+00 |
| 仓位路径与成本无关（成本不反馈进决策） | gross 最大差 0.00e+00 |
| 每股成本 ∝ 1/价格，bp 成本与价格无关 | 价格×10 后 per_share 成本比 **0.100000**，cost_bp 成本比 **1.000000** |

最后一项直接针对 PART8 的 TQQQ 错误那一类。**第 3 条很关键**：它是 PART9 用
`net = gross − turnover × rate` 重算四套成本口径的前提，现在被逐位验证了。

### 2.3 杠杆与对称性

- 常数杠杆 3x：收益严格 ×3（最大相对偏离 1.4e-17），Sharpe 0.682556 → 0.682556 不变。
- 多空对称：做多 862 笔、做空 863 笔，空头占比 50.0%（不是伪装成择时的单边多头）。

### 2.4 独立重写实现对账 —— 并查出一个语义歧义

`audit/reimpl_noise.py` 用**显式股数 + 现金 + 逐笔佣金**的账本重写了一遍
（被测引擎用的是"入场价→出场价比值"记账，结构完全不同）。

第一次跑**不一致 1114 天、最大日差 2.5%**。查到原因：

> **引擎在同一根 bar 上止损后会立刻按原方向重开**。
> 例：2022-04-26，13:00 止损、同一个 13:00 又重开空单。
> 这不是前视，而是论文没写清楚的**语义歧义**：止损条件（close > min(LB, VWAP)）
> 与同方向开仓条件（close < LB）可以同时成立（当 VWAP < LB 时）。
> 引擎的处理是"先平后立刻重开"，净仓位没变，却白付了 2 条腿的成本。

把三种语义都实现后逐一对账：

| 止损/重入语义 | 出场腿成本口径 | 累计收益 | Sharpe | 与引擎是否逐位一致 |
|---|---|---|---|---|
| **same_bar**（引擎的行为） | **leg_price**（引擎的口径） | 1.2042 | **1.1217** | **是，最大差 8.3e-16，0 天不一致** |
| same_bar | actual（正确账本） | 1.2042 | 1.1217 | 差 1.3e-06（可忽略） |
| next_check | leg_price | 1.1891 | 1.1172 | — |
| **hold**（实盘采用） | leg_price | **1.2307** | **1.1469** | — |

三点结论：
1. **引擎的全部算术逻辑得到验证**（same_bar/leg_price 下逐位一致到 8e-16）。
2. **结论对这个歧义不敏感**：6 种组合的 Sharpe 范围 1.117~1.147，**极差仅 0.030**。
3. 引擎默认的 same_bar **不是最好的那个**。`hold`（止损触发但同方向条件仍成立时不平仓）
   省掉那 2 条腿的空转成本，Sharpe 1.147 vs 1.122。**实盘采用 hold。**

另：出场腿成本按出场价反算股数（引擎口径）严格说是错的（真实股数在入场时就定了），
但差异只有 7e-6 的累计收益，**可忽略**。

### 2.5 安慰剂

随机筛掉 1/3 交易日 × 60 次：零分布均值 0.599、std 0.153、p5 0.396、p95 0.872，
真实值（全交易日）0.668。**这量化了"随机改变交易日集合"本身能造成多大的 Sharpe 波动**
——PART9 §2.4 的置换检验正是靠这个才知道 +0.104 不显著。

## 3. 因子/横截面层（16/16 通过）

### 3.1 截断不变性

`xs_factor_library.build` 产出 **77 个因子**。在 55% / 75% / 92% 三处截断：
**77 个因子的当日值全部逐值一致（容差 1e-8）**。

反向对照：前向收益在截断后必须全变 NaN（截断后 0 个非空，全历史 98 个非空）✓

预处理步骤：`winsor_std`（去极值标准化）和 `neutral_ind_size`（行业市值中性化）
的截断不变性最大相对差 **0.00e+00** —— 证明它们是纯横截面操作，不含时序信息。

### 3.2 预言机对照：回测对齐

| 灌入的人造信号 | P=1 多空 Sharpe | P=5 | 期望 | 结果 |
|---|---|---|---|---|
| oracle `score_t = r_{t+1}` | **+42.801** | +6.443 | 必须 >> 0 | ✓ 测试有鉴别力 |
| contemp `score_t = r_t` | −0.362 | −0.193 | 必须 ≈ 0 | ✓ 无泄漏 |
| lagged `score_t = r_{t-1}` | −0.191 | −0.658 | 必须 ≈ 0 | ✓ |

### 3.3 查实的第二个问题：IC 与组合回测的滞后口径不一致

用"哪个 `r_{t+k}` 做预言机能打满"精确定位：

- `fwd_ret(h=1)` 在 t 这一天 = **r_{t+2}**（IC 恰好 +1.0000，k=0/1/3 的 IC 都 ≈ 0）
  → 信号 t → **次日收盘**建仓 → 再持有 h 天（保守口径）
- `group_books` 把 score_t 配给 **r_{t+1}**（预言机 Sharpe 峰值在 k=1）
  → 信号 t → **当日收盘**建仓（乐观口径）

**两者差一天。都没有泄漏**（信号不含未来），但执行假设不同：PART6/PART7 报告的
IC 用保守口径、Sharpe 用乐观口径。

**量化影响**（77 个因子 × 2 个调仓周期，多加一天滞后）：

| 调仓周期 | 平均 ΔSharpe | std | 最强 5 个因子 |
|---|---|---|---|
| P=5 | **+0.002** | 0.061 | +0.956 → +0.940 |
| P=20 | **+0.012** | 0.067 | +0.963 → +0.990 |

> **影响可忽略**，而且平均是**正的**（保守口径略好，因为少吃一天短期反转噪声）。
> PART6/PART7 的横截面结论站得住。

### 3.4 中性化有效性

市值中性化前 corr(因子, log 市值) = +0.0078，中性化后 = **−0.0019**。
直接针对 PART4 踩过的"中性化控制变量又被当成特征喂回去、中性化被静默撤销"那一类。

## 4. 实盘代码与回测的等价性

这是实盘系统的正确性基石，细节见 `docs/LIVE_SYSTEM.md`。摘要：

| 检查 | 结果 |
|---|---|
| `decide()` 逐根 bar 回放 vs 已审计的账本（sizing=fixed） | 最大差 **0.00e+00**，0 天不一致 |
| 同上（sizing=voltarget 4x） | 最大差 **0.00e+00**，0 天不一致 |
| `Cfg(reentry='same_bar'/'next_check')` 被拒绝 | ✓ 纯函数架构不可表达，显式报错而不是静默走偏 |
| 实盘 σ profile vs 回测 σ（19 天 × 6 时点） | 最大相对差 **0.00e+00** |
| 实盘 bar 收盘价 vs 回测（165 个点） | 最大相对差 **0.00e+00** |
| 实盘敞口 vs 回测敞口（18 天） | 最大相对差 1.1e-05 |

对账过程中查出并修掉的第三、第四个问题（都只在实盘路径上存在）：

**问题 3：复权不一致。** 我第一次灌历史用了 moomoo 默认的前复权（QFQ），
而实时流和回测的 min1 都是原始价。结果实盘缓存里 2026-09-21 之前的 bar
整体低 0.1042%。定位到 QQQ 除息日 **2026-09-21、每股 0.75143**
（验证：原始收盘 718.80 − 0.75143 = 718.05 = moomoo 前复权价，完全吻合）。
σ 和敞口是比值所以不受影响（已验证到 1e-10），但混着拼会在下一个除息日破功。
**修复**：bootstrap 改用 `autype=AuType.NONE`。修复后 bar 价差 → 0.00e+00。

**问题 4：除息日的带参考价。** 噪声带参考 `max(开盘价, 复权前收)`。实盘拿到的
`prev_close_price` 是**原始**前收，除息日比复权值高一个股息（QQQ 约 0.10%），
而 10:00 的 σ 只有 0.282%，**所以上下轨会整体偏约带宽的 20~30%**。一年 4 天，但错得很具体。
**修复**：`get_rehab` 取除息日与每股股息，除息日 `prev_close_adj = 原始前收 − 股息`；
日波动率也同样复权。修复后敞口差 1.86e-02 → **1.1e-05**。

## 6. 审计结论与剩余风险

**查实并修复：4 个问题**
1. 引擎的止损/重入语义歧义（影响 Sharpe 极差 0.030，引擎默认不是最优 → 实盘改用 hold）
2. IC 与组合回测的滞后口径差一天（平均 ΔSharpe +0.002~+0.012，可忽略）
3. 实盘历史灌入的复权口径与实时流不一致（已修，差异归零）
4. 实盘除息日的带参考价未复权（已修，一年影响 4 天）

**确认无误：** 前视（跨日 + 日内）、成本记账（4 项）、杠杆不变性、多空对称、
77 个因子的截断不变性、回测对齐（预言机）、中性化有效性、数据与独立源对账（8 项）。

**审计抓不住、因此仍然是风险的部分：**

| 剩余风险 | 为什么审计抓不住 | 怎么缓解 |
|---|---|---|
| 参数过拟合（vm=1、lookback=14、检查时点） | 这些是论文给定值，但"选用这篇论文"本身是事后的 | PART8 已报告逐年衰减；只能靠样本外持续观察 |
| 2023-2026 的样本期特殊性 | 审计验证实现，不验证未来 | PART9 §1.6：好年份 1.4~2.3、差年份 0.6，2025/2026 偏弱 |
| 真实价差与滑点 | 回测用的是假设值 | **已实测**：模拟盘 $0.009985/股/边（见 LIVE_SYSTEM.md §5） |
| 模拟盘不建模价差 | 纸上成交按最新价，没有买卖价差 | 实盘前必须用真实账户的小额成交重测 |
| 我没想到要检验的假设 | 定义上抓不住 | 保留全部审计脚本，发现新问题时新增一条机械化检查 |
