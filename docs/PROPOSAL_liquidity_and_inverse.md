# PROPOSAL — ① 流动性/换手率能否提升策略;② 恐慌时改用三倍做空(SQQQ)还是继续做空 TQQQ

状态:**预注册(执行前冻结)**。脚本 `studies/liquidity_inverse_study.py`。用户 2026-10-12 的两个问题。

## 0. 先把问题拆对(这一步决定后面测什么)
**关于②的结构性前提**:Sleeve **已经是多空双向**的,空头腿当前的实现就是**做空 TQQQ**(`reimpl_noise.simulate` 的 `ENTRY_SHORT`,执行标的 TQQQ,1/3 名义拿同等敞口)。所以『改用三倍做空 QQQ』**不是一个新信号,而是空头腿的换工具**。它只能通过三条路径影响利润,必须分开建模:

| 路径 | 问题性质 | 本篇怎么测 |
|---|---|---|
| **I1 工具成本** | 买入 SQQQ 与做空 TQQQ 的费用/融券/跟踪差异 | 会计恒等式 + 融券盈亏平衡率(描述性,非假设检验) |
| **I2 仓位不对称** | 恐慌时空头腿是否比多头腿更赚 → 是否该把空头腿放大 | **这才是唯一的 alpha 问题**,预注册检验 |
| **I3 隔夜持有 SQQQ** | 完全不同的策略(Sleeve 不留隔夜) | **本篇不测**,只写清为什么需要单独预注册 |
**诚实声明**:I1 的核心数字我在写本文前的数据可行性检查中已经算过(见 §3 先验),因为它是**机械恒等式**而非需要盲测的假设;I2 的任何结果我在本文冻结前**没有看过**。

**关于①的旧记录**:相对成交量类特征我已经测过三次(`PROPOSAL_lowvol_avoidance` 三轮的 `b_rel_vol`、`PROPOSAL_disp_prediction` 的 `rv30`),均无增量。所以本篇把重点放在**从未检验过的两件事**:(a) 流动性作为**成本真实性与容量上限**(可能直接改变历史业绩数字);(b) 杠杆 ETF 的**相对成交额**作为新的持仓/情绪变量。

## 2. 检验设计(冻结)

### L1 成本真实性与容量(可能改变历史数字,最高优先)
* **时变有效价差**:对 TQQQ 日频 OHLC 算 Corwin–Schultz(2012)估计量 `S_t`(负值截 0,再取 21 日中位数平滑);半价差(美元)`hs_t = S_t × P_TQQQ,t / 2`。现用假设是**固定 $0.005/股**(TQQQ ≈ $81 时 ≈ 0.6bp 半价差)。
* **重算**:从成交明细 F 精确反解当日 TQQQ 成交股数 `n_t = (Σcm_t / 0.0095) × scale_t`(`scale_t = P_QQQ/(3P_TQQQ)`,与 `sleeve_anatomy.run_phases` 同一口径),则
  `rr_new = rr_sim + Σcm_t − n_t × (hs_t + 0.0045)`。30 相位均值。报全期/dev/test 的 Sharpe 与 CAGR 变化,以及**价差最高 20% 的日子**上的损益变化。
* **容量**:每日 TQQQ 成交额 = `n_t × P_TQQQ,t × 资本`;对参与率上限 {1%, 5%, 10%} × TQQQ 的 20 日 ADV,反解**最大资本规模**;另报恐慌日与平静日分别的上限。
* 判定:描述性,不设通过/不通过;但若固定价差口径下的 Sharpe 在时变价差下下降 >0.15,则**现有历史数字需要加注**。

### L2 流动性/换手作为信号(低先验)
* 特征(全部因果,≤t−1 收盘或 ≤10:00):
 1 `cs_spread_z`(TQQQ 的 CS 价差相对 60 日均值);2 `amihud_d` = |r(t−1)|/成交额(t−1) 的 60 日 z;3 `kyle_lambda` = 过去 20 日、分钟级 `r ~ sign(r)·√(成交量)` 回归斜率的 z;4 `turnover_z` = log(QQQ 成交量/20 日 ADV);5 **`lev_demand`** = log(TQQQ 成交额/QQQ 成交额) 的 60 日 z(零售杠杆需求,**新**);6 **`inv_tilt`** = log(SQQQ 成交额/TQQQ 成交额) 的 60 日 z(做空/避险持仓倾斜,**新**);7 `vol_prof_surprise` = 10:00 累计成交量相对 14 日同时段剖面的 log 偏离。
* 目标:当日 Sleeve 净损益(bp)。方法:逐年扩展窗口岭回归(α=10,标准化),OOS 2021–2026;报 Spearman IC 与分位表;**变现**:因果排名最低 20%/30% 的日子不交易(与 `PROPOSAL_ffa_vol` E2 同口径),族内置换 p(7 个特征 × 2 个阈值 + 1 个合成 = 15 个配置)。
* 判定:dev/test ΔSR 同号为正、全期 ≥0.15、族内 p<0.05 ⇒ 有证据;否则线索/无。

### I1 工具:买 SQQQ vs 空 TQQQ(描述性会计)
* **楔子** `w_t = r_TQQQ,t + r_SQQQ,t`(开盘→收盘),若两者完全互为镜像则 ≡0;`w<0` 表示**买 SQQQ 比空 TQQQ 少赚**。报全期/恐慌日/|QQQ 日内收益| 最高 5% 的均值与分布。
* **融券盈亏平衡率**:把 `w` 换算到单位经济敞口(÷3)并年化,得到使两种实现等价的 TQQQ 年化融券费率 `b*`;报 `b*` 的全期与分年值。实际融券率 > `b*` ⇒ 买 SQQQ 更划算。
* **流动性**:TQQQ 与 SQQQ 的日成交额、以及恐慌日两者的相对变化(检验『恐慌时 TQQQ 难借/SQQQ 更活跃』的说法)。
* **按持仓时长折算**:Sleeve 空头的平均持仓时长(从成交明细算),把 `w` 按时长比例折算到每笔。
* 判定:描述性。不做『哪个更好』的统计检验(这是成本/可得性问题,取决于券商条件)。

### I2 恐慌时的仓位不对称(唯一的 alpha 检验)
* **腿级分解**:从 30 相位的成交明细重建**逐笔净损益**(`shares×(exit−entry) − cm_in − cm_out`),按 side 与日期聚合;**必须先验证**重建的日收益与基线曲线逐日一致(报最大绝对差)。因为仓位缩放不改变信号(止损按价格、与股数无关),所以对某一侧乘以 `k` 等价于把该侧逐笔损益与成本同乘 `k`——这是**精确**的,不需要重跑模拟。
* **恐慌状态(全部事前可知,冻结)**:
 `P1` = `Δln VIX(t−1) > 0` 且 `r_QQQ(t−1) < 0`;
 `P2` = `P1` 且 `VIX(t−1) > 25`;
 `P3` = 隔夜缺口 < 0 且 `VIX(t−1) > 20`(开盘即可知);
 `P4` = `P3` 且 09:31–10:00 收益 < 0(10:00 可知,Sleeve 首次决策时点)。
* **配置(族 = 20)**:恐慌日的乘数 `(k_long, k_short)` ∈ {(1,1.5), (1,2), (0.5,1.5), (0,1.5), (1,3)} × {P1,P2,P3,P4};非恐慌日 (1,1)。
* 评价:Sleeve 层与组合层(L1 RV[0.5,1.5]+Sleeve)的 ΔSR(dev 2019–22 / test 2023–26 / 全),分布面板(Sortino/MDD/CVaR5%/最差日/峰度);**置换检验**:在同星期几、同『完整交易日』池内置换恐慌标签(2000 次),族内 max。
* 判定:dev/test 同号为正、全期 ΔSR ≥0.15、族内 p<0.05、**且 CVaR5% 与 MDD 不劣于基线** ⇒ 有证据;同号为正且 ≥0.05 但不满足其余 ⇒ 线索;否则无。
* **风控红线(不论回测结果)**:`k_short=3` 意味着恐慌日空头经济敞口达 `3×min(4,2%/σ)`,在 σ 低而后续突然放大的日子是尾部灾难来源;即便通过也**只建议 ≤1.5**。

### I3 不测什么(并说明原因)
隔夜持有 SQQQ 是另一个策略:(a) Sleeve 的全部证据都建立在**不留隔夜**之上;(b) 3x 产品的**波动衰减在恐慌期最严重**(日内高波动 → 多日复合损耗),恰好与『恐慌时长期持有 SQQQ 更赚』的直觉相反;(c) 需要隔夜缺口/限跌/熔断的建模。要测必须新开预注册。

* **结论与用户直觉相反**:这是**成本/可得性问题,不是收益放大器**。只有当 TQQQ 融券费率 **> ≈10%/年**(平静期)时买 SQQQ 才划算;而**在最恐慌的时候(VIX>30)门槛升到 ≈39%/年**,即恐慌期**继续做空 TQQQ 明显更优**(两只 3x 基金的再平衡损耗在高波动期同时放大,买 SQQQ 要承担自己那一份)。
* **流动性也不支持换工具**:SQQQ 成交额中位仅为 TQQQ 的 **0.37×**,恐慌日只升到 **0.40×** —— TQQQ 在恐慌时依然是流动性好 2.5 倍的那一只。
* 按 Sleeve 空头平均持仓 **3.24 小时**折算,每笔工具楔子 ≈ **−1.92bp**(ETF 价格口径)≈ −0.64bp/单位敞口。
* **唯一真正支持 SQQQ 的理由**:融券不可得(硬券)或券商融券费率异常高;以及空头亏损上界(SQQQ 最多 −100%,空 TQQQ 理论无上界)。这是风控/运营理由,不是 alpha。

### I2 恐慌时仓位不对称(唯一的 alpha 检验)
全期(周二至周五,2019+):多头腿 **+3.43bp/日**、空头腿 **+2.58bp/日**。
| 恐慌状态 | 天数 | 多头(恐慌/平时) | **空头(恐慌/平时)** |
|---|---|---|---|
| P1 VIX↑且前日跌 | 517 | +2.25 / +4.01 | **−1.42 / +4.52** |
| P2 P1 且 VIX>25 | 114 | +3.44 / +3.43 | **−3.24 / +3.03** |
| P3 跳空跌且 VIX>20 | 264 | +0.52 / +4.02 | **+8.42 / +1.42** |
| P4 P3 且首半小时跌 | 120 | −0.10 / +3.72 | **+9.79 / +1.99** |
**机制很清楚,且方向取决于定义**:P1/P2 是『**昨天**恐慌』(事后反弹日)→ 空头被挤,日均转负;P3/P4 是『**今天**在跌且延续』→ 空头日均 +8~10bp,是平时的 4~6 倍。所以『恐慌时加大空头』只有在**当日延续**的定义下才对。
**但 20 个配置无一通过**:全期 ΔSR 最大 **+0.022**,dev/test 同号为正 6/20,**族内置换 p 最小 0.922**。最好的几个是 P3/P4 配 `k_long=0`(恐慌日关掉多头腿):组合 ΔSR +0.09(dev +0.12 / test +0.08),但 Sleeve 层 ΔSR 仅 +0.02。
**风控结论(不论回测)**:`k_short=3` 使 CVaR5% 从 −142.9 → **−297bp**、最差日 −249.7 → **−682.9bp**、峰度 15.5 → **59.3**。放大空头是在**把尾部变厚**换一点点均值。**判定:无证据;且红线确认。**

### L2 流动性/换手作为信号
Spearman IC(2019+,对当日 Sleeve 净损益):`vol_prof_surprise` −0.049、`kyle_lambda` +0.030、**`inv_tilt` +0.022**、**`lev_demand` +0.020**、`cs_spread_z` +0.010、`turnover_z` −0.015、`amihud_d` −0.006 —— **全部 |IC|≤0.05**。岭回归 OOS(2021–26,n=1175)IC **−0.032**,按预测五分位的 Sleeve 日均 bp 9.3/2.7/9.2/9.5/6.3(**无单调性**)。
变现(16 个配置):dev/test 同号为正 **1/16**,族内 p 最小 **0.478**(kyle_lambda q=0.3,dev −0.004 / test +0.277,分年不稳);新造的 `lev_demand`(TQQQ/QQQ 成交额)与 `inv_tilt`(SQQQ/TQQQ 成交额)同样 ≈0。**判定:无证据**,与此前三次相对成交量检验一致。

### 总判定
* ① 流动性/换手**不能提升收益**(L2 无证据);但它**量化了两件实用的事**:成本有 ~12 倍缓冲(稳健性好消息),以及 5% 参与率下的容量上限约 **$2.4 亿**。
* ② 恐慌时换用 SQQQ **不会让利润更大**(纯成本问题,平静期融券门槛 ≈10%/年、恐慌期 ≈39%/年,且 SQQQ 流动性只有 TQQQ 的 0.4 倍);恐慌时**加大空头腿**也无统计证据,且显著恶化尾部。唯一有价值的副产品是**机制发现**:空头腿在『当日跳空下跌且延续』时日均 +8~10bp,而在『昨日恐慌』后的反弹日为负 —— 作为**前向观察的描述性事实**记录,不作为规则上线。
