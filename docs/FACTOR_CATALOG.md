# 因子动机与实现表

下面的 `V_i` 是第 i 个五分钟 bar 的成交股数，`P_i` 是该 bar 的开盘价，`r_i=log(P_{i+1}/P_i)`，最后一段以当天终盘价格代理；`Q=Σ_i V_i`，`n=78`。所有时点以纽约交易时间为准，t 日终盘确认后交易。用 `log(1+V_i)` 以处理零成交量。定义是从**横截面思想转为时间序列代理**，没有沿用原报告的截面方向与超额收益结论。

## 东北证券报告：16 个手工构造的变体

`σ` 在日内序列用样本标准差，`Var_K` 在 K 日序列用总体方差；未达到两条显著正收益 bar 时，上行时段的两个日频指标缺失。

| ID | 日频定义，随后按 K 聚合 | 原有解释与时序改造的假设 |
|---|---|---|
| `LOGVOL_STD` | `std_i(log(1+V_i))` | 成交时段离散度；指数中可能反映集中交易/冲击风险 |
| `LOGVOL_SKEW` | `mean_i(((log(1+V_i)-μ)/σ)^3)` | 成交量集中于少数时段的尾部形状 |
| `OPEN_VOL_SHARE` | `Σ_[09:30,10:00)V_i/Q` | 隔夜信息在开盘集中释放或过度反应 |
| `OPEN_VOL_SHARE_VAR` | `Var_K(OPEN_VOL_SHARE_t)` | 开盘份额跨日不稳定性 |
| `OPEN_VOL_SD` | `std_[09:30,10:00)(V_i)/Q` | 开盘交易流量异常跳变 |
| `OPEN_VOL_SD_VAR` | `Var_K(OPEN_VOL_SD_t)` | 开盘流量跳变强度跨日不稳定性 |
| `AM_PM_OPEN_RATIO` | `Σ_[09:30,10:00)V_i / Σ_[13:00,13:30)V_i` | 早盘与午后开盘流动性偏移 |
| `AM_PM_OPEN_RATIO_VAR` | `Var_K(AM_PM_OPEN_RATIO_t)` | 早/午开盘偏移的不稳定性 |
| `PM_MID_CLOSE_RATIO` | `Σ_[15:30,16:00)V_i / Σ_[11:30,12:00)V_i` | 收盘前相对午间成交堆积 |
| `PM_MID_CLOSE_RATIO_VAR` | `Var_K(PM_MID_CLOSE_RATIO_t)` | 相对收盘交易强度的不稳定性 |
| `UP_RVOL` | `std(r_i | up_i) × mean(V_i | up_i)/mean(V_i)` | 显著上涨时的价格波动和推动量 |
| `UP_RVOL_VAR` | `Var_K(UP_RVOL_t)` | 上行量价结构跨日不稳定性 |
| `UP_VOLSD` | `std(r_i | up_i) × std(V_i | up_i)/mean(V_i)` | 显著上涨区间的价量共同波动 |
| `UP_VOLSD_VAR` | `Var_K(UP_VOLSD_t)` | 上行区间共同波动跨日不稳定性 |
| `VP_MED_SKEW` | `3(μ_volume-weighted-price-decile−median)/σ` | 成交量主要被市场接受在哪个价格区域；bar 开盘价近似逐笔价格 |
| `VP_REVERSAL` | `intraday_return × (1+POC−close_decile)` 若当日跌；若涨用 `(1+close_decile−POC)` | 成交密集价格区 POC 与收盘价的潜在回归；此处 POC 是近似值 |

`up_i` 同时满足 `r_i>0` 和 `r_i>mean_j(r_j)+std_j(r_j)`。价格分桶按**当天 78 个 bar 开盘价的十等分经验分位点**，把 bar 成交量归到对应的开盘价桶；桶标号为 `0,0.1,...,0.9`。中位数由累计成交量权重确定；POC 用相邻桶成交量平滑后取峰值，首尾各以自身两倍加相邻桶。这是可计算的 OHLCV 代理，无法重建报告使用的逐笔成交价分布。窗口 K 的普通因子取 K 日均值，`_VAR` 取 K 日方差；后者 K=1 无定义。

报告的 Logsig-Alpha-v 是 20 日五分钟对数成交量 lead-lag 路径的十阶 log-signature 和截面 MLP 组合。本项目没有把上述 16 个手工变体命名为 Logsig-Alpha，也没有伪造该学习模型。

## 广发网页：6 个单 ETF 代理

网页中“动量/波动/反转”原本根据**一个股票因子多空组合的历史收益**来预测该因子下一期表现。下表改成 ETF 自身过去收盘收益，研究的问题变成 ETF 市场择时，不能归因于网页的原回测。

| ID | t 日日频定义 | rationale |
|---|---|---|
| `MOM_RV` | `10 日收盘收益 / std_20(日收益)` | 波动率调整后的近期趋势 |
| `MOM_SIGN` | `sign(10 日收盘收益)` | 动量方向 |
| `VOL_TARGET` | `clip(sign(10 日收益)×0.4/(sqrt(252)×std_20(日收益)),-3,3)` | 波动目标缩放与趋势方向，0.4 取原文概念参数 |
| `RV_RATIO` | `std_5(日收益)/std_20(日收益)` | 短期波动对长期基准的状态变化 |
| `REV_5` | `−5 日收盘收益` | 短期反转 |
| `AMIHUD_ILLIQ` | `10^9×|日收益|/当日近似美元成交额` | 流动性冲击代理；金额为 Σ(bar 开盘价×成交股数) |

“特征差”需要股票多空组合与 Barra 暴露，原网页 `agru_dailyquote/DL_1/fimage` 等需股票截面与训练输出，`ratio_volumeH8` 等只有名称且缺精确口径；没有可靠释义时**不伪造同名公式**。

## Green–Hand–Zhang：5 个可观测思想代理

| ID | 日频定义 | 所需原数据的缺口与改造 |
|---|---|---|
| `ST_REV_20` | `−20 日 ETF 收盘收益` | 原股票短期反转，改为 ETF 时间序列 |
| `MAXRET_20` | `max(过去 20 个日收益)` | 股票 max return 的指数代理 |
| `VOL_20` | `std(过去 20 个日收益)` | 总波动，**不是**股票四因子模型的特质波动 |
| `DOLVOL_20` | `log(1+过去 20 日均近似美元成交额)` | ETF 成交额，**不是**股票份额换手率 |
| `ILLIQ_20` | `mean_20(10^9×|日收益|/近似美元成交额)` | Amihud 形式的 ETF 代理 |

没有股份总数、市值、财务报表、分析师预期或股票横截面，因此不生成这篇论文其他约 89 个股票特征。本文主要贡献是多特征联合检验和 data-snooping 调整，不意味着单 ETF 的 5 个代理有正收益。所有窗口和方向由实际样本外检验决定，不能套用原股票横截面预期符号。

## 原项目基线

`MID_AVG` 是 11 个半小时采样点相对噪声带中点的有符号标准化距离的日内均值。`SKEW_DIFF=MID_AVG−该 11 点的中位数`。噪声带和历史估计见 `README_index_timing.md`。两者也参加同口径的 1/5/10/20/30/60 日聚合与滚动正交，供新候选比较。

## 时序与统计约束

每个 `(ID,K)` 的日因子先形成，再用过去 K 日收盘收益和**以前 120 个配对**做滚动 OLS，残差与原始值在相同日期配对。所有测试有 `available` 与 `common120D` 两套日期，不能将不同期限的 `available` 当成严格配对。高低五桶按此前最多 120 个有效因子历史分位定义；上涨比例是 ETF 原始收益大于零的频率；高减低为条件均值差。没有股票截面，因此传统截面 Rank IC/ICIR 的解释不适用；这里为**同一 ETF 的时序相关**。长目标事件高度重叠，h 阶 HAC 仅是有限样本诊断。研究因子数和参数很多，无多重假设校正或 2026 独立样本。
