# PROPOSAL — 统一的仓位模型:把「低波动日缩仓」与「恐慌日空头加码」放进同一个可学习的 sizing 框架

状态:**预注册(执行前冻结)**。脚本 `studies/unified_sizing_study.py`。用户 2026-10-12 的问题:能否用一个模型同时处理『低波动日缩仓』(FFA 擅长)和『高波动/恐慌日』;该看 precision、recall 还是 AUC;是否用类似 sigmoid 的函数缩放仓位。附带:读用户给的 Valeyre et al.(2013)Reactive Volatility Model(RVM),并补充相关文献。

## 0. 把问题定义对(ML 视角)
前几轮的教训可以归结为一句话:**我们一直在优化代理目标,而不是经济目标**。
* 『预测波动』R² 0.75 → 变现为负(预测了错的变量);
* 『识别低振幅日』AUC 最高的 ML-10:00(0.858)→ 经济效果最差(−0.25);
* 『恐慌日加码空头』:描述性的 +8~10bp 在 20 个规则里族内 p≥0.92。
所以统一模型的**目标函数必须直接是 Sleeve 的风险调整收益**,分类指标只作诊断。具体:
1. **决策对象**是每天(10:00 决策时)两条腿的仓位乘数 `k_long(x), k_short(x) ∈ [0, 2]`,作用在已有的 vol-targeting 仓位之上(σ₁₄ 不动,符合用户『σ₁₄ 负责平稳期放大、模型反向调整』的定义)。腿要分开,因为 P3/P4 显示**同一天两条腿的条件期望符号相反**。
2. **两类错误的代价不对称**(Sleeve 是凸性收益):漏掉一个大位移日(把它当成平静日缩仓)损失 ≈ 平均 +80bp,误交易一个平静日损失 ≈ −20~−30bp。因此不能用对称的 AUC/accuracy 选模型;要用**代价敏感**的决策(Elkan 2001)和**利润曲线**(按『被标记为坏日』的比例画出被拦截日的平均收益)。本篇会把『跳过需要的 precision 下限』直接从数据算出来。
3. **sigmoid 缩放 = 有界的参数化策略**:`k = 2·σ(θᵀz)`,θ=0 时 k=1(即基线),输出天然在 (0,2)。直接以训练期效用为目标估 θ,就是 Brandt–Santa-Clara–Valkanov(2009)的参数化组合策略(PPP);用分类器概率经 sigmoid/正态 CDF 映射到仓位,是 López de Prado(2018)的 meta-labeling bet sizing。两者是同一个思想的两种估计方式,本篇都测。

## 1. 数据与 PIT
* Sleeve 逐笔重建(30 相位、TQQQ 实际成交价口径)→ **多头腿、空头腿的逐日净损益**(`liquidity_inverse_study` 已验证三项 0.000000bp 校验,本篇复用并重验)。
* 决策时点 10:00(Sleeve 首次检查点);全部特征只用 ≤10:00 的分钟线与 ≤t−1 收盘的日频数据。
* 样本 2019-01~2026-10(Sleeve 只有这一段),周一排除。**walk-forward**:每年初用之前全部年份训练,OOS = 2021–2026(dev 2021–22 / test 2023–26)。第一折只有 2019–2020 两年训练 —— 小样本,模型必须低复杂度。

## 2. 特征(10 个,冻结)
| 名称 | 定义 | 来源/理由 |
|---|---|---|
| `ffa_rank` | FFA-P 对当日振幅的预测在过去 504 日的因果分位 | `PROPOSAL_ffa_vol`(低波日识别) |
| `gap_n` | 隔夜缺口 / σ₁₄(带符号) | Lou–Polk–Skouras 2019;P3 |
| `r30_n` | 09:31–10:00 收益 / (σ₁₄·√(30/390)) | Gao–Han–Li–Zhou 2018 |
| `b30_n` | 首 30 分钟 Parkinson 振幅 / (σ₁₄²·30/390) 的 log | 盘中实现的波动 |
| `lvix_z` | log VIX(t−1) 的 252 日 z | 恐慌水平 |
| `dlvix` | Δlog VIX(t−1) | 恐慌变化 |
| `rvm_panic` | **RVM 恐慌因子在 10:00 的即时值** `ℓ·(L_f(t−1) − P₁₀:₀₀)/L_f(t−1)`,ℓ=8,λ_f=0.1484 | **Valeyre et al. 2013 式 (5)** —— 论文强调 RVM『对每一次价格变动即时调整』,正好可以在盘中更新 |
| `rvm_ratio` | RVM 的 σ_I/σ̃_I = L/I(t−1) 的 log | 同上,式 (7) 的反应因子 |
| `P3` | 1[gap<0 且 VIX(t−1)>20] | 上一轮的描述性发现 |
| `P4` | P3 且 r30<0 | 同上 |
**样本内污染声明**:`ffa_rank`、`P3`、`P4` 这三个特征本身是在 2019–2026 上被发现的。所以本篇的 OOS 不是『从零发现』,而是检验**一个学习框架能否以 walk-forward 方式稳健地使用这些已知效应**;结果会偏乐观,写在前面。

## 3. 模型(冻结;配置族 = 4 个可学习方案)
* **U0 基线**:k_long = k_short = 1。
* **U1 手工规则(样本内基准,不入族)**:FFA rank ≤0.2 → 两腿 0;P3 → (k_long, k_short) = (0, 1.5)。
* **U2 双头回归 + sigmoid**:每条腿一个岭回归(α=10,标准化)预测该腿当日净损益;`k_leg = 2σ((ŷ_leg − m)/s)`,m、s 为训练期拟合值的中位数与标准差(de Prado 式映射,不调参)。
* **U3 参数化策略(PPP)**:`k_leg = 2σ(θ_legᵀz)`,直接最大化训练期 Sleeve 均值–方差效用 `mean(R) − (γ/2)var(R) − λ‖θ‖²`,`R = k_long·L + k_short·S`,γ 设为使基线(θ=0)处于效用一阶条件的值 `γ = mean(B)/var(B)`;λ 在训练期内按『留一年』交叉验证从 {0.1, 0.3, 1, 3, 10} 选(单位 bp)。
* **U4 分类器(用户的直觉:低波模型 + 高波模型)**:两个 L2 logistic(C=0.5)分别预测 `P(低位移)`(dn ≤ 训练期 20% 分位)与 `P(高位移)`(≥80% 分位)。
  * U4a sigmoid:`k = 2σ((d − m)/s)`,`d = p_high − p_low`,两腿相同;
  * U4b 只跳过:`p_low` 的因果分位 ≥0.8 → 两腿 0。
* 诊断(不入族):每个分类头的 OOS AUC、Brier、校准斜率;precision/recall 在 10%/20%/30% 标记率下;**利润曲线**。
* **RVM 复现(描述性)**:在 QQQ 上实现 RVM(式 1–7,论文参数 λ_s=0.0241、λ_f=0.1484、ℓ=8、φ=1/0.3、λ_σ=1/40),复现论文图 4:隐含波动日变化(VXN、VIX)对 σ_RVM / σ_EWMA / σ_GARCH 日变化的回归斜率与 R²。另报 RVM 替换 σ₁₄ 做 Sleeve 仓位的结果(1 个描述性配置)。

## 4. 统计与判定(冻结)
* 指标:Sleeve 与组合(L1 RV[0.5,1.5]+Sleeve)的 ΔSR(dev/test/全 OOS)、分布面板(Sortino/MDD/CVaR5%/最差日/峰度)、分年 ΔSR、学到的系数(可解释性)。
* 置换:仓位乘数序列相对两腿损益的**圆周平移**(≥60 日,2000 次),族内 max(U2、U3、U4a、U4b)。
* **有证据 ⇔** 族内 p<0.05、dev/test ΔSR 同号为正、全 OOS 组合 ΔSR ≥0.15、CVaR5% 与 MDD 不劣于基线。『线索』⇔ 同号为正且 ≥0.05。
* 先验:U3 最可能是最好的(直接优化目标、参数少);但训练样本小(第一折 ~400 天),**预计全部 |ΔSR|<0.15,通过概率 ≤15%**。分类器的 AUC 会比经济效果好看(重复上一轮的教训)。RVM 预计复现论文的『与隐含波动日变化相关更高』,但作为 Sleeve 仓位会更差(更快的 σ 削掉凸性,`PROPOSAL_ffa_vol` E1)。

## 5. 结果(2026-10-12;`unified_sizing_study.py` 日志 `studies/outputs/full/intraday/unified_log.txt`;事后 `unified_sizing_posthoc.py` 日志 `unified_posthoc_log.txt`;表 `unified_{rvm_replication,profit_curve,econ,panel,k_by_state,coefs,posthoc,posthoc_panel}.csv`)
完整解读见 `docs/REPORT_unified_sizing.md`。这里只记数字与判定。
**校验**:腿级(多+空)重建 vs 基线 0.000000bp。OOS 1166 天(2021–2026,周二至周五)。

### A. RVM 复现(QQQ,2009-09~2026-10,n=4293)
| 隐含波动 | 估计量 | 日变化斜率 | **日变化 R²** | 水平相关 |
|---|---|---|---|---|
| VXN | **RVM** | 0.620 | **0.508** | 0.892 |
| VXN | EWMA(λ=1/40) | 0.831 | 0.063 | 0.817 |
| VXN | GARCH(1,1) | 0.320 | 0.093 | 0.845 |
| VIX | RVM | 0.636 | 0.442 | 0.821 |
**论文结论在 QQQ 上复现**(论文 V2X:RVM R² 0.45 vs EWMA 0.15 vs GARCH 0.003);GARCH 参数 α=0.101、β=0.889 与论文的 0.106/0.897 几乎一致。RVM 替换 σ₁₄ 做 Sleeve 仓位:Sleeve SR 1.023 → 1.097(2019–26,描述性),但高位移日仓位 0.86×(与 FFA 同样的凸性削减)。

### B. 分类诊断(OOS)
* 低位移头 AUC **0.533**、校准斜率 0.19(严重过度自信,Brier 不如常数预测);高位移头 AUC 0.664、校准斜率 0.63。
* OOS Sleeve 日均:低位移日 −28.4bp(18.6%)、**中间日 −6.6bp(60.4%)**、高位移日 **+77.7bp**(21.0%)—— Sleeve 只在前 20% 的位移日赚钱。
* 跳过决策的盈亏平衡:被跳过集合中高位移日占比必须 < `s/(s+g)` ≈ **13%**(s=被跳过非高位移日的平均亏损 ≈11.7bp,g=77.7bp),而基础占比是 21%。
