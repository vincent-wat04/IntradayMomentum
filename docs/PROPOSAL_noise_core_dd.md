# PROPOSAL — 日频信号的去噪,与核心仓(B&H 腿)的回撤控制;Sleeve : 核心仓的配比(预注册,2026-10-29)

分支 `research/crowding-vol-timing-2026-10`。本文在运行前写定。

## 0. 现状与问题
* 组合构造(实盘 = 回测):`R_t = w_t · r_QQQ,t + Sleeve_t`。两条腿共用同一个 `CAPITAL_BASE`(实盘 $500k):QQQ 腿持有 `w × CAPITAL_BASE` 的 QQQ,Sleeve 的敞口是 `e × k × CAPITAL_BASE`(e = min(4, 2%/σ14),k = 仓位模型乘数,经 TQQQ 以 1/3 名义实现)。所以是 1:1 叠加,不是资金切分。
* 上一轮:无条件把 Sleeve 放大 1.5 倍,组合 ΔSR +0.247;即在组合层面,Sleeve 相对核心仓的风险预算偏低。H5(只在 TSM 高拥挤日放大)+0.146;在相同平均杠杆下,择时比无条件多 +0.047。
* 日更拥挤度更及时(比月频早约 50 天),但状态每 4–5 天切换一次;用在核心仓上换手 9 → 22.5 倍/年,dev 为负。

## 1. 文献与可用的去噪方法(转述)
| 方法 | 来源 | 用在本项目 |
|---|---|---|
| 慢 + 快时序动量混合:快慢一致时满仓/空仓,分歧时(回调、反弹)取中间仓位 | Goulding, Harvey & Mazzoleni (2023, JFE) "Momentum turning points";Garg et al. (2021) "Breaking bad trends" | K1:SMA200(慢)+ 21 日收益(快) |
| 条件波动目标:只在波动极端(高/低分位)时调整敞口,其余保持不变;换手与杠杆更低、回撤更小 | Bongaerts, Kang & van Dijk (2020, FAJ) | K4:替换 RV21 的线性映射 |
| 交易成本下的部分调整 / 不交易区间:只朝目标仓位走一部分,或偏离超过阈值才调 | Gârleanu & Pedersen (2013, JF) | K5:核心仓不交易带 |
| 信号平滑 + 滞回(进入阈值高于退出阈值) | 通用信号处理 | K2:日更 C_TSM 做 EWMA + 滞回 |
| 快进慢出:月频为主,日频只在极端时提前触发 | 由上两项组合 | K3 |
| 动量崩盘多发生在"市场下跌后 + 高波动"的恐慌状态,与反弹同时发生 | Daniel & Moskowitz (2016, JFE) | 解释核心仓在趋势过滤下错过反弹的风险(描述) |

## 2. 配置(核心仓,Sleeve 不变 = v4 Sleeve)
基线核心仓 `w = RV21[0.5,1.5] × SMA200(e=0.5)`,成本 2bp/单位换手(不变)。
| 配置 | 核心仓规则 | 自由参数 |
|---|---|---|
| K1 快慢混合 | 趋势乘数 `T = 1 − 0.5 × (0.5·D_slow + 0.5·D_fast)`,D_slow = 收盘 < SMA200,D_fast = 21 日收益 < 0 | 无(权重等分) |
| K2 日更拥挤度去噪 | C_TSM_d 做 EWMA(半衰期 21 日);过去 1260 日分位 ≥ 2/3 进入高拥挤,< 1/2 退出;高拥挤日 w × δ | δ 递归 |
| K3 月频 + 日频(快进慢出) | 进入:月频 C_TSM 高拥挤,或日更 C_TSM ≥ 过去 1260 日的 90% 分位;退出:月频不高且日更 < 中位;高拥挤日 w × δ | δ 递归 |
| K4 条件波动目标 | RV21 分位 p ∈ (0.2, 0.8) 时 w_rv = 1;p ≥ 0.8 或 ≤ 0.2 时 w_rv = clip(σ_med/σ, 0.5, 1.5)(σ_med = 过去 504 日 RV21 中位) | 无 |
| K5 不交易带 | 执行权重只在 \|w* − w_{t−1}\| ≥ 0.10 时调到 w*,否则不动 | 带宽 0.10(固定) |
| K6 = K1 + K5 | | 无 |
δ ∈ {0, .25, .5, .75, 1},每月按 2019-01 至上月末扩展窗口的组合夏普选择(同前)。

## 3. 配置(Sleeve : 核心仓配比)
| 配置 | 规则 |
|---|---|
| S1 | Sleeve × m(所有 OOS 日),m ∈ {1, 1.25, 1.5, 1.75, 2} 递归 |
| S2 | 等风险换配比:组合 = c · (核心仓 + ρ · Sleeve),ρ ∈ {1, 1.25, 1.5, 2, 3} 递归;c 使过去 252 日波动等于 v4 组合过去 252 日波动(c ∈ [0.5, 1.5]),即总风险不变、只把风险从核心仓挪向 Sleeve |

## 5. 结果(2026-10-29;`studies/noise_core_dd.py`、`studies/noise_core_bp.py`)
**核心仓长样本(2000–2026)**:QQQ B&H Sharpe 0.45 / MDD −83%;基线 RV21×SMA200 0.56 / −72%(互联网泡沫 −77% → −65%,金融危机 −41% → −20%,2022 −33% → −20%)。K1 快慢混合 0.55 / −74%(2020 −7.4% → −4.8%,2010–18 MDD −20% → −16%,但 2000–09 更差);K4 0.55 / −71%;K5 不交易带 0.56 / −73%、换手 9.6 → 6.9;K6 0.54 / −75%。**没有一个规则改善核心仓的长期回撤**;核心仓剩下的回撤来自 2000–02 这种持续两年半的熊市,200 日趋势过滤已经吃掉了能吃的部分。
**去噪本身有效**:日更拥挤状态切换 137 次 → EWMA + 滞回 5 次、快进慢出 30 次(OOS 2021–26)。
**组合层(OOS 2021–26,相对 v4 = 1.911)**:K1 +0.011、K4 −0.081、**K5 +0.019 [−0.018, +0.057](dev/test 同正,通过;核心仓换手 9.0 → 5.8)**、K6 +0.016、K2 −0.023、K3 −0.117。
**配比**:S1 Sleeve × m,59/70 个月选上限 2.0,+0.345 [+0.043, +0.670],通过;S2 等风险换配比,66/70 个月选上限 ρ = 3(核心仓平均 × 0.57、Sleeve × 1.62),+0.497 [+0.031, +0.983],通过;MDD −16.9% → −22.9% / −19.1%。两者都是边界解。
**买力约束(事后,+2)**:实盘最坏占用 ≈ w + e·k/3(单位 CAPITAL_BASE),护栏 0.85 × 买力 = 2.57。v4 本身最坏占用最高 4.17、p99 3.84,OOS 14.8% 的日子超过 2.57(线性仓位模型 k 最高 2)。统一按比例缩到 2.57 后:v4c 1.938;S1c 相对 v4c +0.223 [−0.05, +0.55],dev −0.06 / test +0.39,不通过;**S2c +0.440 [−0.015, +0.916],dev +0.34 / test +0.53,通过**,2021 −0.14,其余年份为正,MDD −18.4%。
