# PROPOSAL — LLM(新闻/情绪 ± 宏观上下文)能否预测 10:00 之后的实现波动 / 极低波日

状态:**预注册(执行前冻结)**。脚本 `studies/llm_news_vol_study.py`;API:NUS SoCLaaS(OpenAI 兼容,key 仅经环境变量传入,不写入任何文件)。
同口径前置研究:`PROPOSAL_lowvol_avoidance.md`(同一决策时点 10:00、同一目标、同一 OOS 基线预测 `A·ridge`)。

## 0. 要回答的问题
1. 新闻(盘前 + 开盘 30 分钟)喂给 LLM,零样本给出的「波动评分/低波概率」,能否预测 10:00 之后的实现波动与『低位移日』?
2. **加入宏观上下文(VIX 族期限结构、收益率、美元、USDJPY/AUDJPY carry 代理、信用、油、日经…)** 是否改变?(臂 N vs N+M)
3. LLM 评分在**已有量化基线**(`A·ridge`,即 VIX 族 + σ14 + GEX + 前日 RV)之上是否有**增量**?(这是唯一重要的问题)
4. 与「新闻条数/重要度」这类**无需 LLM 的朴素基线**比,LLM 是否多提供信息?

## 1. 无前视设计
* **决策时点 10:00 ET**。新闻窗口 = 上一交易日 16:00 ET(含)至 当日 10:00 ET(不含);时间戳用 `ts_utc` 转 `America/New_York`(含夏令时);周末/节假日新闻并入下一交易日窗口。
* 宏观上下文只用 **t−1 收盘**数据(Cboe/Yahoo 收盘,t−1 之后的值不进入);相对水平用过去 252 日**因果**分位。
* **时间匿名化**(新闻全文进入 LLM 前):
  去除年份/月日/星期/时分(中英文)、报道机构名;指数点位与大额绝对价格 → `[LEVEL]`;保留涨跌幅与小数值。**不做实体替换**(人名/国家/公司名携带全部事件信息,替换等于删除信号)。
  → 因此残余的泄漏路径是「模型认出某个已发生的 2026 事件」。控制:(a) 选训练截止更早的模型作为主结果(llama3.1:8b 自报 ~2022/2023);
  (b) **日期探针**:对 60 个随机匿名窗口让模型猜年月,命中(±2 个月)比例须不显著高于随机,否则该模型标注为「可能被污染」,只作次要结果。
* 目标变量与标签口径完全沿用 lowvol 研究:`y_rv = log Σ r²(10:00→收盘)`,低波标签 = 剩余日位移 ≤ 训练期(2019–2026-03)的 40% 分位。
* 零样本评分不拟合任何参数 ⇒ 无训练/测试泄漏;唯一被拟合的是 LLM 评分在 126 天上的线性回归系数,用**留一法**评估增量 R²。
* temperature=0,固定模型名,固定提示词(文件内常量),结果按 (模型,臂,日) 缓存,可重放。

## 2. 实验臂(每臂每模型每日一次调用)
| 臂 | 输入 | 作用 |
|---|---|---|
| **N** | 匿名新闻(按重要度降序取前 60 条,≤ 9,000 字) | 新闻单独的信息量 |
| **N+M** | N + 宏观上下文块 | 宏观是否改变/增强新闻 |
| **M** | 只有宏观上下文块 | 控制:LLM 仅凭宏观(≈ 已有量化指标的『文字版』)能否复现 `A·ridge` |
| 朴素基线 | 窗口新闻条数、重要度≥2 的条数、总字数(无 LLM) | LLM 是否比「新闻多不多」更有信息 |
输出 JSON:`vol_score`(1–10,10=剩余交易时段预期波动远大于典型日)、`p_quiet`(0–100,剩余时段净位移处于最小 40% 的概率)。

## 3. 模型
主:`llama3.1:8b`(截止最早)、`qwen3.6:35b`;次(探针/稳健性,视成本):`x-test-1`。其余带思考的模型(gemma4/qwen3.5/qwen3.8)会在小 token 预算下返回空,不采用。

## 4. 评估(冻结)
* 样本 = 2026-04-01 起、有分钟线与新闻窗口的整日(约 126 天)。**有效独立观测 = 交易日。**
* (E1) Spearman(vol_score, y_rv)、AUC(1−p_quiet 或 vol_score 区分『非低波』);95% 区间用**按周聚类**自助(4000 次)。
* (E2) 新闻置换安慰剂:把 LLM 评分在日期间随机置换 2000 次(等价于喂错日期的新闻)得到 null。
* (E3) 增量:留一法 R²:`y_rv ~ ŷ_A` vs `y_rv ~ ŷ_A + score`(ŷ_A 为 lowvol 研究的 OOS 预测);ΔR² 的按周聚类自助区间。
* (E4) 臂对比:AUC(N+M) − AUC(N)、AUC(N+M) − AUC(M) 的配对自助区间。
* **有证据 ⇔** 主模型(llama3.1:8b 与 qwen3.6:35b **都**)满足:E1 区间不含 0 方向一致;E2 p<0.05;E3 ΔR² 区间不含 0 且 >0.01;日期探针通过。否则「没有足够证据」。
* 功效(事先说明):126 天对 ΔR²=0.05 功效 ≈0.68,对 0.01 仅 ≈0.19。**阴性结果 ≠ 无效**,只能说「在本样本下检测不到 ≥0.05 的增量」。

## 5. 先验(写在前面)
* E1:LLM 评分与 y_rv 有正相关(新闻多/地缘事件 → 波动大),Spearman ≈0.2–0.3,但**大部分被 `A·ridge` 吸收**。
* E3:ΔR² 区间含 0 的概率 ≥70%。M 臂应接近 `A·ridge` 的一部分信息,N+M ≈ M。
* 小模型(8B)会更多依赖措辞情绪而非信息量,可能对『地缘冲突用词强烈』过度反应。

## 6. 局限
* 仅 ~126 天、一个 regime、中文快讯(华尔街见闻)为主,英文来源只有 2026-09 起;无法区分盘前 vs 盘中新闻的增量(窗口含到 10:00)。
* 匿名化不彻底(见 §1);模型训练截止未知(自报不可靠)。
* **建议前向验证**:该管线对每个新交易日都能无前视地运行,可以在 optrec / qmacro 服务器上作为只记录不交易的并行记录器,积累 ≥250 天后再判定。

## 结果(2026-10-11;`studies/llm_news_vol_study.py`;表 `outputs/tables/llm_news_vol_eval.csv`、`llm_news_vol_arms.csv`;缓存 `studies/outputs/full/intraday/llm_cache.jsonl`)
样本 126 个交易日(2026-04-02 ~ 2026-10-01);每窗新闻中位 112 条(63–580),无空窗。调用 llama3.1:8b 与 qwen3.6:35b 各 378 次(3 臂 × 126 天),temperature 0,约 5k token/次(N、N+M 臂)。
基线 `A·ridge` 在这 126 天上 corr(ŷ_A, y_rv)=0.684,LOO R²=0.457(2026 年样本内的 VIX 族本身解释力就很强)。低波标签占比 0.52。

**日期探针**(60 个匿名窗口):猜对 2026 年占比 2%(llama)/8%(qwen);±1 月命中 2%/8%;猜测月份与真实月份 Spearman 0.53 / 0.36。
→ 没有认出具体日期(严格泄漏判据通过),但**能从季节线索(酷暑、二季度财报等)粗略定位月份**,故增加了「月份固定效应后的 rho」稳健性列(事后增加,见偏离记录)。

| 来源 | Spearman(score, y_rv) [95%] | 月固定效应后 rho | AUC(区分非低波) | ΔR²(LOO) vs ŷ_A [95%] |
|---|---|---|---|---|
| 新闻条数(朴素) | 0.02 [−0.19,0.22] | 0.01 | 0.59 | −0.006 [−0.010,0.017] |
| 重要度≥2 条数(朴素) | 0.07 [−0.15,0.27] | −0.01 | 0.60 | −0.009 |
| llama3.1:8b N | 0.17 [−0.02,0.33] | 0.05 | 0.50 | −0.008 [−0.011,0.009] |
| llama3.1:8b N+M | 0.31 [0.16,0.43] | 0.21 | 0.51 | −0.002 [−0.009,0.027] |
| llama3.1:8b M | 0.31 [0.13,0.47] | 0.09 | 0.55 | +0.010 [−0.010,0.077] |
| qwen3.6:35b N | 0.31 [0.15,0.47] | 0.19 | 0.51 | +0.003 [−0.007,0.053] |
| qwen3.6:35b N+M | **0.46 [0.29,0.59]** | 0.35 | 0.55 | **+0.046 [+0.001,+0.124]** |
| qwen3.6:35b M | 0.40 [0.18,0.57] | 0.35 | 0.54 | −0.007 [−0.011,0.009] |

臂对比(配对自助):qwen N+M − N ΔAUC +0.041 [−0.013,0.092],Δrho +0.144 [+0.041,+0.238];N+M − M:Δrho +0.057 [−0.100,+0.229];llama 全部区间含 0。
置换 p(rho) 在 llama N+M/M、qwen 全部臂均 <0.001(但见下)。

**判定(按 §4,两个主模型都必须满足):没有足够证据。**
* E1/E2(相关):LLM 评分与 y_rv 确有正相关(0.17–0.46),置换检验显著。但 **M 臂(只有宏观文字块,没有新闻)的相关性与 N+M 相当**(llama 0.31 vs 0.31;qwen 0.40 vs 0.46)
  ⇒ 相关性主要来自宏观块里的 VIX 水平/期限结构等,而不是新闻;这些信息 `A·ridge` 已含。
* E3(增量):llama3.1:8b 所有臂 ΔR² 区间含 0 且点估计 ≤0.01 → **不满足**;qwen3.6:35b N+M 点估计 +0.046,区间下界 +0.001 刚好不含 0——12 个增量检验中的一个边缘结果,未做多重比较校正,且 llama 不能复现,**不构成证据**。
* 低波判别:所有 LLM 评分区分『非低波日』的 AUC 为 0.50–0.55,区间都含 0.5(朴素新闻量 0.59–0.60 区间也含 0.5)。**LLM 无法识别「极低波日」**。
* 分辨率:llama 的 vol_score 只取 3 个值(6/7/8),qwen 7 个值,p_quiet 几乎常数(15/22/25…),评分本身粒度粗;小模型倾向于对大多数日子给「偏高波动」。
* 功效:126 天;对 ΔR²=0.05 的功效约 0.68,对 0.01 约 0.19。结论是「在本样本下检测不到 ≥0.05 的稳定增量」,而不是「新闻无信息」。

## 偏离记录
* **模型排除**:`x-test-1`(推理模型)与 `qwen3.8:27b`(思考模型)在 300 token 预算下返回空(试点已验证),按 §3 排除;未放宽预算重跑(避免事后换模型)。
* **429 限流**:全量运行中 ~1% 的调用被限流返回 ERR,已用 2 个并发补跑到 100% 解析;缓存键含提示词版本、模型、臂、日期、全文。
* **事后新增**列「rho_月固定效应后」(日期探针显示月份可粗定位);是稳健性,不是判据。
* 日期探针的通过标准预注册为「±2 个月命中不显著高于随机」;实际用 ±1 个月与年份命中,并补报月份 Spearman。严格泄漏判据通过,但月份粗定位存在,故 N 臂的结果应被视为含季节性混淆。

# 第二轮(Round 2,2026-10-11,用户要求诊断并迭代)
## R2.0 诊断(第一轮结果的原因)
* **LLM 不是单纯查 VIX 表**:M 臂评分与 VIX 的 Spearman 仅 0.35–0.42(llama)/0.36–0.50(qwen);qwen 与 GEX z −0.69、QQQ 5 日收益 −0.61 更高,说明它在综合多个宏观数字。
  但整体仍是「宏观数字 → 波动」的映射,这部分基线 `A·ridge` 已含。评分与**基线残差**(y_rv − ŷ_A)的 Spearman:M 臂 0.16 / −0.04,N 臂 0.03 / 0.12,N+M 臂 0.09 / 0.23(qwen)。
* **推理日志**(qwen3.6:35b,开发集 6 天:残差最负 3 天 + 最正 3 天,要求逐条列出依据):
  - 系统性高估(残差 −1.2~−1.6):盘前冲击(美伊停火、美联储意外)**已在前 30 分钟释放**,但模型把『已实现的冲击』当成『剩余时段的波动』,又被高 VIX/负 gamma 的文字推向高分。
  - 系统性低估(残差 +1.1~+1.4):漏掉『10:00 之后才发生』的事件(非农后续、收益率冲击、未结算的地缘风险);对已发生的 V 型反转过度推断『风险被吸收』。
  - 结论:第一轮的任务设定**没有区分『已实现』与『剩余』信息,且让 LLM 在已含宏观块上重复估计基线**。这是提示词问题,不是模型能力问题。
## R2.1 设计变更(登记)
* **目标** = 残差 `y_rv − ŷ_A`(ŷ_A 为 `A·ridge` 的 OOS 预测)。评估统计量:LLM 评分对残差的 Spearman,及其对 `y_rv ~ ŷ_A + score` 的 LOO ΔR²。
* **输入**:仅新闻(不再给 VIX/宏观数字);把『基线预期』作为一句话告知:`The quantitative baseline expects the rest-of-day volatility to be at the {pct}th percentile of typical days.`(pct 为 ŷ_A 的因果分位)。
  任务 = 判断新闻是否表明『剩余时段』相对基线**更高/更低/一致**。
* **结构化问题**(逐项 JSON):`already_priced`(0–10:新闻所述冲击是否已在 10:00 前基本反映)、`pending_event`(0/1:是否有 10:00 之后才发生/公布的事件,如数据、议息、讲话、财报、谈判截止)、
  `escalation`(−2..+2:地缘/政策风险是在升级还是缓和)、`surprise`(0–10:相对预期的意外程度)、`vol_vs_baseline`(−2..+2:相对基线剩余波动更低…更高)。
* **允许推理**:`max_tokens` 提高到 1,200;使用 llama3.1:8b、qwen3.6:35b(第一轮同模型),另追加思考型 `qwen3.8:27b`(第一轮因 token 预算被排除,本轮 max_tokens=3,000)。
* **防过拟合协议**:样本按时间锁定划分 —— 开发集 2026-04-02~07-31(83 天)、留出集 2026-08-03~10-01(43 天)。
  提示词迭代**只看开发集**,最多迭代 3 个变体并记账(每个变体都记入本文件);**冻结 1 个**变体后在留出集上评估**一次**。留出集结果不得用于再次修改提示词。
* **主判据(留出集,冻结变体)**:`vol_vs_baseline`(或预注册的组合分数)对残差的 Spearman 的按周聚类 95% 区间不含 0 **且**方向为正,且 ΔR²(LOO) 区间下界 >0。开发集结果仅供迭代。
* **功效说明**:留出集 43 天,只能检测到 |rho|≳0.4。因此阴性结果依然只说明『无法检测到大效应』;阳性结果需要前向样本确认。
## R2.2 样本扩展(未完成)
* 126 天是主要瓶颈。查到的 1990–2025 多源新闻库(Hugging Face `Brianferrell787/financial-news-multisource`)为 gated 数据集,需要账号授权,当前环境无法下载;GDELT 仅有聚合量/语调序列,无原文标题。
* 建议:(1) 用户授权 HF token 后,抽取 2024–2025(llama3.1:8b 训练截止之后,污染最小)的 Benzinga/Yahoo 标题,可将样本扩到 ~500 天;(2) 在 qmacro 服务器上继续累积 wscn 新闻做前向样本。

## 第二轮结果(开发集 83 天;`studies/llm_news_vol_r2.py`;缓存 `llm_cache_r2.jsonl`;表 `llm_news_vol_r2_v{1,2}_dev.csv`)
**迭代记账**:变体 v1(结构化 5 字段 + 残差目标)、v2(加入明确判据与基准频率)。**共 2 个变体,只在开发集运行;留出集(43 天)从未调用,保持未使用状态。**
| 变体/模型 | 预注册主字段 `vol_vs_baseline` 对残差 rho [95%] | 最好的单字段(事后,仅作线索) |
|---|---|---|
| v1 llama3.1:8b | −0.14 [−0.40,+0.13] | already_priced −0.22(区间 −0.36~−0.12,但仅 2 个取值) |
| v1 qwen3.6:35b | +0.08 [−0.13,+0.31] | surprise **+0.34 [0.16,0.52]** |
| v2 llama3.1:8b | +0.08 [−0.13,+0.27] | surprise −0.21 |
| v2 qwen3.6:35b | +0.15 [−0.03,+0.33] | escalation +0.14 |
* **v1 里 qwen `surprise` 的 +0.34 在 v2 里降到 +0.11**:换用更明确的提示词后消失,说明是偶然,而非稳健信号(10 个字段中取最大的选择偏差)。
* **跨模型一致性**:同一变体下 llama 与 qwen 的 `vol_vs_baseline` 相关为 −0.17(v1)/ −0.36(v2)(**互相负相关**);同一模型 v1 vs v2:llama −0.15、qwen 0.50。
  → 信号需要在不同措辞和模型之间稳定才可信;这里**没有共同的底层信号**。
* **行为问题**(诊断):v1 里 qwen `pending_event` 82/83 天=1、`vol_vs_baseline` 66/83=+1(默认『有事件、更高』,没有区分度);v2 改善了分布(取值数 2→4–7),但相关性没有因此变好。
  llama3.1:8b 的输出几乎常数(2–5 个取值),不会分级。
* 与朴素基线:新闻条数对残差 rho −0.005,重要度≥2 条数 −0.173。
**判定**:按冻结协议,**没有任何变体满足冻结条件**(主字段在两模型上同号、区间不含 0);因此**不调用留出集**,也不做第三个变体去在开发集上继续挖掘(会变成数据窥探)。
**对用户假设的回答**:『提示词不够好』只对了一半 —— 提示词确实存在系统性问题(混淆已实现/剩余、默认高波),改进后字段分布更合理;但改进没有带来稳健的预测。
更重要的是诊断出**信息缺口**:LLM 看到的只有 `10:00 之前` 的新闻,而影响剩余波动的是 `10:00 之后` 的事件;其中可事前获知的部分(议息、数据日程)用**确定性日历**更可靠(见 `PROPOSAL_lowvol_avoidance` 第二轮:FOMC 日 +0.81、t=10)。
## 下一步(可执行,不需要更多 LLM 调用)
1. **前向样本**:在服务器上把『新闻窗口 + v2 提示词 + 基线分位』每天无前视地记录(只记录不交易),攒到 ≥250 天再评估;留出集 43 天保留为首个确认样本。
2. **扩样本**:HF `financial-news-multisource`(gated)取得授权后,抽取 2024–2025(llama3.1:8b 训练截止之后)的标题,把评估样本扩到 ~500 天。
3. **改任务**:LLM 更适合做『结构化事件抽取』(是否有 10:00 后的具体催化剂、事件类别),再把离散特征放入线性模型,而不是让它直接给波动评分。

# 第三轮(Round 3,2026-10-11,用户建议):LLM 只做『逐条新闻的结构化事件抽取』→ 线性模型
**动机**:第二轮显示 LLM 直接给波动评分在模型间/提示词间不稳定。抽取任务(『这条新闻是哪类事件』『所述事件是已发生还是今天晚些时候才发生』)是事实性判断,
更不依赖模型对波动的主观直觉,且输出是离散计数,可进入可解释的线性模型。**LLM 不再接触 VIX/宏观数字/基线预期。**
**抽取 schema(冻结)**,对每条新闻返回:
* `etype` ∈ {`central_bank`(央行/议息/美联储官员表态), `macro_data`(经济数据发布/预期), `earnings`(财报/业绩指引), `geopolitics`(战争/冲突/制裁/外交), `policy_trade`(关税/监管/财政/法案), `mkt_wrap`(收盘/盘前行情综述), `corporate`(并购/IPO/个股事件), `other`};
* `timing` ∈ {`past`(已发生/已公布), `today_later`(明确指出今天稍晚/今晚/盘中将发生或公布), `future`(之后的日期), `none`};
* `severity` ∈ {0,1,2}(0=常规,1=值得关注,2=可能引发大幅波动的重大事件)。
**批处理**:每次调用 20 条,按时间顺序编号返回 JSON 数组;temperature 0;模型 `qwen3.6:35b`(主)、`llama3.1:8b`(次,稳健性);提示词 `EXTRACT_V1` 固定,**不迭代**。
**日级聚合特征(冻结 9 个)**:`n_today_later`(timing=today_later 的条数)、`any_today_later`(0/1)、`n_central_bank`、`n_macro_data`、`n_earnings`、`n_geopolitics`、`n_policy_trade`、`max_severity`、`n_sev2`;计数取 log1p。
**评估协议(防过拟合)**:样本 126 天按时间锁定为开发集 2026-04-02~07-31(83 天)与留出集 2026-08-03~10-01(43 天)。
* 在开发集上拟合 `残差 y_rv − ŷ_A ~ 9 个特征` 的岭回归(α=10,特征标准化);**只在留出集上评估一次**:OOS R²(相对开发集残差均值)、预测与实际残差的 Spearman(按周聚类自助)、预测最高/最低三分位的残差均值差。
* 另报开发集内留一法 R² 与 9 个特征各自与残差的 Spearman(描述性,不入判定)。
* **有证据 ⇔** 主模型与次模型在留出集上 OOS R²>0 且 Spearman 区间下界>0;并且开发集中系数符号与先验一致(`n_today_later`、`n_central_bank`、`n_macro_data`、`max_severity`>0)。
* 事件抽取一致性诊断:两模型对同一条新闻的 `etype`/`timing` 一致率(Cohen κ)—— 若 κ<0.4,说明抽取本身不可靠,结论作废。
* 先验:`n_today_later` 与 `n_macro_data`、`n_central_bank` 与残差正相关(与『FOMC 日 +0.81』一致);留出集 43 天功效低,OOS R²>0 的概率 ~30%。

## 第三轮结果(`studies/llm_event_extract.py`;缓存 `llm_extract_cache.jsonl`;表 `llm_extract_eval.csv`)
**抽取质量**:两模型解析覆盖率均 100%(每批 20 条 JSON 数组全部可解析)。日级计数的两模型 Spearman:geopolitics **0.92**、earnings 0.74、macro_data 0.71、sev2 0.67、policy_trade 0.42、central_bank 0.36,
**`n_today_later` 仅 0.19、`any_today_later` 0.06** —— 恰恰是假设最依赖的『今天稍晚是否有事件』在两个模型间最不一致。
**`today_later` 在 qwen 的 94%、llama 的 92% 的天数里 >0**(中文快讯几乎每天都提到『今晚/稍后公布…』),该特征几乎没有区分度。`max_severity` 在日级聚合后两模型均无变异(NaN 相关)。
**留出集(43 天,模型仅在开发集 83 天上拟合)**:
| 模型 | 开发 LOO R²(9 特征) | 留出 OOS R² | Spearman(预测,实际残差) [95%] | 预测最高三分位 vs 最低三分位残差 |
|---|---|---|---|---|
| qwen3.6:35b | −0.102 | **−0.373** | −0.151 [−0.30,+0.01] | −0.394 vs −0.207 |
| llama3.1:8b | −0.187 | **−0.180** | −0.133 [−0.44,+0.15] | −0.408 vs −0.270 |
开发集单变量(描述性):qwen `any_today_later` +0.18、`n_macro_data` +0.16;llama `any_today_later` −0.13(**两模型符号相反**)。
**判定:没有足够证据**。留出集 OOS R² 为负,符号相反,开发集 LOO 为负。**留出集从此已被使用一次,不得再用于调参。**
**为什么结构化抽取也没有帮助(诊断)**:
1. 新闻源(华尔街见闻快讯)的高频叙事使『待发生事件』几乎每天为真,二值化后无信息;真正有信息的是**事件的具体身份**(FOMC 决议日、非农日),而它们由**日历**确定,且在 1,443 个 OOS 日上已证明有大效应(FOMC +0.81,t=10)。
2. LLM 抽取对『事件类型』(geopolitics/earnings/macro_data)稳定,对『时间点』(今天稍晚)不稳定 —— 后者是波动预测最需要的。
3. 126 天样本中,宏观数据日、央行日只有几十个,统计功效很低(见 §4)。
**结论与路线调整**:LLM 新闻路线目前三轮(整体评分 → 提示词重构 → 结构化抽取)均无增量,停止在 126 天样本上继续迭代。保留价值:(a) 抽取管线可复用,(b) 事件类型计数的两模型一致性较高,可用于未来大样本。
