### 3.1 空头止盈：独立 Sharpe 全正，叠加贡献从不为正

8 个独立 Sharpe 差值（dev+test）**全为正**，均值 +0.096~+0.214 —— 这不是噪声，
止盈确实在抬高独立 Sharpe，逐笔统计也证实它按设计工作（空头胜率 33.9%→35.5%、

但 **test 叠加贡献 4 个组合里最好的一个也只是 +0.000，其余为负**。
这与 PART12 的安慰剂结论一致：止盈的收益来自"少做空"，
而空头腿正是这个 sleeve 的对冲性来源，削掉它叠加价值不升反降。
**→ 否决，且这次是在 4 个不同组合上重复验证的。**

### 3.2 无周一：dev 一致说坏、test 一致说好

这是本表最值得注意的一行。dev 期 6 个组合的独立 Sharpe 差值**全为负**，均值 **−0.255**；
叠加贡献也**全为负**，均值 −0.084。test 期则反过来（+0.171 / +0.094）。

**符号在两段样本间系统性翻转，且在各自样本内高度一致。**
这比之前"dev p=0.41 不显著"的读法更不利 —— 不是"看不出来"，
而是 **dev 明确反对、test 明确支持**，典型的样本期特定现象。

当前实盘（③）正是开着 `SKIP_WEEKDAYS=0`（排除周一）的版本，依据主要来自 test 期。
结合 PART11 的样本量估算（要分辨周一效应需约 951 个周一 ≈ 18 年），
**建议把它重新降级为"未决"，并认真考虑恢复全周交易**。

### 3.3 band+尾0.5：dev 全正、test 中性

dev 独立 Sharpe 与叠加贡献在 6 个组合里**全为正**（+0.001~+0.298 / +0.007~+0.087）；
test 在多空版本里约等于 0（叠加 +0.007）。

所以它不是收益改进，而是一个**近乎免费的结构改良**：
笔数少 22%、换手低 19%、单笔亏损有构造上限（≈1% 资金）、
MDD −15.3%→−14.0%、Calmar 0.65→0.84，且 |dev−test| 差异最小。
**→ 维持 PART11 的建议：可以换，但要把它当"风险工程"而非"提收益"。**

### 3.4 只做多：叠加贡献 8 个组合全负

test −0.125~−0.336、dev −0.038~−0.182，**无一例外**。
只做多确实有最好的独立 Calmar（1.15）和最小回撤（−7.4%），
但那是因为它卸掉了空头腿；一旦和 B&H 叠加，这个优点变成缺点。
**→ 只做多仅在"完全不持有 QQQ"的场景下才合理。**

## 5. alpha / beta 分解

脚本 `alpha_beta_decomp.py`（直接复用已存净值曲线，不重跑模拟）、
图 `outputs/full/figs/alpha_beta_decomp.png`、表 `outputs/full/intraday/alpha_beta_decomp.csv`。

日频回归 `r_t = α + β·r_bench,t + ε_t`，α 的 t 值用 Newey-West（HAC, lag=5）。

四个指标：
* **绝对 Sharpe** `mean(r)/std(r)·√252` —— sleeve 自身全部收益，不做任何对冲
* **β** 回归斜率 —— 市场敞口
* **α（年化）** `α_daily·252` —— 剔除市场敞口后的超额
* **alpha Sharpe** `α_daily/std(ε)·√252`（appraisal ratio）—— **把 β 完全对冲掉之后剩下那部分的 Sharpe**，
  这是"alpha 质量"的正确刻度；它与绝对 Sharpe 的差额就是 β 贡献了多少

基准口径：`buy_hold = day_close/prev_close_adj − 1` 是**全日（含隔夜）**，
年化 23.22%、波动 23.88%、Sharpe 0.994。另报对**日内 open→close**
（年化 9.30%、Sharpe 0.576，与全日相关 0.78）的回归，用来回答
"这是不是只是在吃日内市场收益"。策略隔夜空仓，所以对全日基准的 β 天然被稀释，这是对的。

### 5.3 三个结论

**(1) 叠加价值几乎完全由 β 决定：`corr(β_test, 叠加贡献_test) = −0.905`（12 个版本）。**
这给了前面所有"叠加口径"结果一个统一的机制解释：sleeve 对 B&H 的价值来自它的
市场中性（分散化），谁的 β 离 0 越远，叠加贡献就越低。不必再把它当经验规律。

**(2) 空头止盈不创造 alpha，它把 alpha 换成了 beta。**

| | β | α年化 | alpha SR | 绝对SR |
|---|---|---|---|---|
| ①→② | +0.012 → **+0.051** | 12.3% → **10.6%** | 0.935 → 0.937 | 0.963 → 1.069 |
| ⑤→⑥ | +0.006 → **+0.051** | 13.5% → **11.0%** | 0.955 → **0.883** | 0.968 → 1.004 |
| ⑦→⑧ | −0.003 → **+0.041** | 16.3% → **13.9%** | 1.209 → **1.187** | 1.202 → 1.290 |

四个组合里 **α 全部下降、alpha Sharpe 三降一平、β 全部上升**，而绝对 Sharpe 全部上升。
机制很清楚：少做空 = 净多头敞口变大 = β 变大；test 期市场是涨的，所以绝对 Sharpe 好看。
**那不是 alpha。** 这比 PART12 的安慰剂论证更直接 —— 止盈在 alpha 口径下零贡献甚至负贡献。

**(3) 只做多的漂亮数字几乎全是 β。**
⑨ 的绝对 Sharpe 1.235、Calmar 1.15、MDD −7.4% 看起来是全表最优，但
β = +0.161，α 只有 5.3%，**alpha Sharpe 0.702 明显低于多空基线的 0.935**。
⑪只多·band 更极端：α = 3.1%、**HAC t = 0.92，根本没有显著 alpha**，alpha Sharpe 只有 0.360。
绝对 Sharpe 减 alpha Sharpe 的差额：只做多四个版本是 **+0.52~+0.56**，多空八个版本只有 −0.01~+0.13。

对日内 open→close 的回归进一步确认：多空 β = 0.00±0.06，只做多 β = +0.20~+0.25。
**也就是说多空版本连"日内市场收益"都没在吃，是真的择时；只做多有约四分之一来自单纯做多。**

### 5.4 这一节改变了什么

* **band+尾0.5 的证据升级了**：它是唯一在 dev 和 test **同时**抬高 α 与 alpha Sharpe 的改动
  （α：dev 8.9%→11.0%、test 12.3%→13.5%；alpha SR：dev 0.722→0.806、test 0.935→0.955），
  而 β 保持 ≈0。之前只能说它是"免费的风险工程"，现在可以说它**小幅改善了 alpha 质量本身**。
* **只做多被进一步否决**：不只是叠加口径差，而是 alpha 质量本身就差（0.36~0.70 vs 0.88~1.21），
  其中一个版本没有显著 alpha。之前"纯独立 sleeve 可以用只做多"的建议应当撤回 ——
  它的高 Calmar 是 β 带来的，拿 β 当 alpha 卖是不诚实的。
* **无周一的 dev/test 冲突在 alpha 口径下依然存在**：alpha Sharpe dev 0.743/0.770（≈基线），
  test 1.149/1.209（远高于基线）。图 (d) 里 ③⑦⑧④ 全部落在对角线**左上**（test≫dev），
  而 ②⑥（止盈）和 ⑪（只多·band）落在**右下**（dev≫test，过拟合方向）。
  两种偏离都是警讯，只是方向相反。

## 6. 绝对 Sharpe 的参照系：QQQ 自己是多少？

### 6.1 先修一个标注错误

§5 写"基准…年化 23.22%、Sharpe 0.994"用的是**全样本**，却摆在一堆 test 期表格旁边
且没标期间，容易误读。QQQ 买入持有（含股息）按期分别是：

| 期间 | 年化 | 年化波动 | **QQQ Sharpe** | yfinance 独立核对 |
|---|---|---|---|---|
| 全 2019-2026 | 23.22% | 23.88% | **0.994** | 1.006 |
| dev 2019-2022 | 15.26% | 26.95% | **0.662** | 0.666 |
| test 2023-2026 | 32.37% | 20.09% | **1.496** | 1.509 |

逐年：2019 **2.090**、2020 1.284、2021 1.422、2022 **−1.070**、
2023 **2.558**、2024 1.355、2025 0.923、2026 1.355。

所以"QQQ 自己有 1.4"指的是 **test 期（1.496）或 2021/2024/2026 这类年份**，
不是结构性常数 —— dev 期只有 0.662，2022 年是 −1.070。

### 6.2 承认一件事：sleeve 单独跑，是不如直接买 QQQ 的

test 期 sleeve 独立 Sharpe 0.963~1.293，**低于 QQQ 自己的 1.496**。
这个事实必须直说，之前只报 ΔSharpe 容易把它藏起来。

但这不是 sleeve 的用法。Sharpe 对规模是齐次的 ——
**你无法通过加杠杆把 QQQ 的 1.496 变大**。要抬高组合 Sharpe，
唯一的办法是加入一个**低相关、正收益**的东西。这正是 β≈0、α≈13% 的 sleeve 干的事。

### 6.3 正确的绝对口径：组合后的 Sharpe 水平

**test 2023-2026（QQQ 自己 = 1.496）**

### 6.4 相关性这一列是全部论证里最直白的一个

* 多空 sleeve 与 QQQ 相关性 **−0.006 ~ +0.091**

这是"为什么不能用独立 Sharpe 选型"的最干净证明，也和 §5.3 的

### 6.5 顺带修一个历史口径不一致

| 来源 | 引擎 | 重入语义 | test | 全 |

## 7. 更正：§3.2 的"无周一"因子估计是错的

### 7.1 错在哪

§3.2 用 **6 个组合**平均出"无周一"的因子效应，得到 dev 独立 SR 均值 **−0.255**、
并据此写"dev 明确反对"。但那 6 个组合里有 4 个含**空头止盈** —— 而止盈是
§3.1 已经否决的因子。dev 的大负值（−0.214、−0.250）全部来自含止盈的组合，
把它们算进因子均值等于用一个已被拒绝的设定去污染另一个因子的估计。

剔掉止盈组合后，"无周一"在**推荐设定（多空 + 无止盈）**下的干净效应：

| 口径 | ①→③ | ⑤→⑦ |
|---|---|---|
| dev 独立 SR | −0.006 | −0.057 |
| test 独立 SR | +0.177 | +0.234 |
| dev alpha SR | **+0.021** | −0.036 |
| test alpha SR | +0.214 | +0.254 |
| dev 叠加 | −0.005 | −0.031 |
| test 叠加 | +0.115 | +0.144 |
| 全样本 独立 SR | +0.091 | +0.092 |
| 全样本 alpha SR | +0.121 | +0.114 |

**dev 效应 ≈ 0（远在噪声护栏 0.15 以内），不是"明确反对"。**
§3.2 "建议恢复全周交易"的紧迫性建立在错误估计上，**撤回**。

教训：做因子边际效应时，必须在**其他因子取推荐值**的条件下估计，
不能对包含已拒绝设定的全部组合求平均。

### 7.2 补做该做的检验

**配对区块自助（无周一 vs 全周，区块 10 天、4000 次）**

| | dev | test | 全样本 |
|---|---|---|---|
| SOTA ①→③ | −0.006 (p=0.515) | +0.177 (p=**0.097**) | +0.091 (p=**0.228**) |
| band ⑤→⑦ | −0.056 (p=0.606) | +0.234 (p=**0.077**) | +0.092 (p=**0.234**) |

**周一自身的日收益（基线①）**

| 期间 | 周一 | 其他日 |
|---|---|---|
| dev | n=188 +1.77bp t=+0.32 | n=820 +3.60bp t=+1.31 |
| test | n=176 −3.58bp t=−0.86 | n=764 +7.01bp t=+2.20 |
| 全 | n=364 **−0.81bp t=−0.23** | n=1584 **+5.24bp t=+2.51** |

周一全样本均值与零无法区分。它**不是负的，是"不正"**；其他日明确为正。
所以排除周一是去掉一个"不贡献收益但贡献方差"的日子，Sharpe 机械地小幅上升。

**逐年（bp/日）**：2019 −2.48、2020 +6.97、2021 +9.60、2022 −7.40、
2023 −4.73、2024 +1.38、2025 −3.54、2026 −8.96 —— **|t| 全部 ≤ 0.85，符号来回跳**。

**集中度（test 期，n=176 个周一；最差 5 个为 −209/−133/−121/−119/−105bp）**

| 剔掉最差 k 个周一 | 再排除周一的 ΔSharpe |
|---|---|

| 1 | +0.131 |
| 3 | +0.076 |
| 5 | +0.028 |

**拿掉 3/176 个周一，好处少 57%；拿掉 5 个（2.8%）基本归零。**

直接检验两组均值之差：周一 −0.81bp vs 其他 +5.24bp，差 ≈6.05bp，
差的标准误 ≈4.1bp，**t≈1.48 —— 周一的 edge 与其他日的 edge 统计上分不开**。

### 7.3 修订后的结论

* **按点估计，⑦band+无周一 确实最优**（test 独立 1.202、alpha SR 1.209、α 16.3%、
  叠加 +0.421、组合 1.917；全样本 0.954 / alpha SR 1.011 也优于 ⑤）。
  §3.2/§5.5 以"dev 一致反对"为理由排除它，**理由错误，撤回**。
* **但 ⑦ 的 test 加成不可计入预期**：全样本 p=0.23、逐年无一显著、
  test 收益集中在 3~5 个周一、周一与其他日的 edge 统计上不可分。
* **实操建议（修订 §4 与 §5.5）**：
  1. **周一维持现状**（实盘已排除周一，不必改）。周一全样本均值≈0，
     排除它在期望上几乎不花钱，且机制有文献依据（论文 §4.3：周末再平衡
     集中在开盘前 30 分钟，而首个开仓点是 10:00）。
  2. **但规划时按 ⑤ 的水平记账**（组合 ~1.77、α 13.5%），不要按 ⑦ 的 1.917。
     两者相差的 0.14 里一半以上压在几个周一上。
  3. **唯一有两段证据的改动是 band+尾0.5**：dev 6/6 组合全正、test 也正，
     α 与 alpha Sharpe 两段同升，β 保持≈0。
* 即：**该动的是止损，周一维持不动但不计功。**
