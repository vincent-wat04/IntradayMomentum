# 静态再配比 × RV 降风险：组合业绩对比

脚本 `combo_comparison.py`（组合可从命令行改）、图 `outputs/full/figs/combo_comparison.png`、
表 `outputs/full/intraday/combo_comparison.csv`。

组合 = `q · w_t · QQQ + sw · Sleeve`。(q, sw)=(1,1) 就是最早 tearsheet 里的"组合"。
Sleeve = 实盘配置 ⑦，样本 2019-01 ~ 2026-10，RV21/504 日百分位信号（t−1 收盘 → t 日），成本 2bp/单位 |Δw|。
"对照" = 同 sleeve 权重、QQQ 权重取 `q·mean(w)` 的纯静态组合（控制平均敞口）。

## 解读

1. **12 个 RV 组合相对各自的同敞口静态对照，ΔSharpe 全部为正（+0.03 ~ +0.25）。**
   但区间几乎都含零；只有 (1:1, lo=.5) 的两格下沿刚好贴着 0。
2. **静态再配比已经拿走了大部分回撤收益。** 在 (0.6:1.4) 和 (0.5:1.5) 两行，
   RV 降风险相对对照的 ΔMDD 基本为 0（−0.6 ~ +1.9pp）；它在这两行只贡献一点 Sharpe，
   而且这点 Sharpe 的区间含零。RV 降风险真正改变回撤的是 (1:1) 那一行——QQQ 敞口高、有东西可砍。
3. **增量随 QQQ 静态权重下降而缩小**：ΔSR 从 (1:1) 的 +0.13~+0.25 降到 (0.5:1.5) 的 +0.03~+0.10。
4. **COVID 占了约 25~40%**：剔除 2020-02~05 后 ΔSR 普遍缩水（+0.250→+0.165，+0.203→+0.147）。
5. **（重要）这个窗口里 lo=0, hi=2 排第一，与上一轮长历史的结论相反。**
   2019-2026 包含 COVID 和 2022 熊市，是保险"赔付"的窗口；
   上一轮在 SPX/NDX 1992-2026 上，lo=0 是整张图最差的一行。
   这里的排名**不能**当作选参数的依据。lo=0.5 的几格在两处都不差（长历史 ≈ 0 到小正，本窗口为正），更稳。
6. **独立性**：RV 参数是在看过 SPX/NDX 2010+ 的敏感性结果之后选的，与本窗口有重叠，不构成独立样本外。
