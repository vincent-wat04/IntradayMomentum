# PROPOSAL — 拥挤度约束下的波动率择时:迁移到本项目(预注册,2026-10-29)

分支 `research/crowding-vol-timing-2026-10`(基于 `research/intraday-vol-entry-2026-10` 1976805)。本文在运行任何实验前写定。
参考:Feng (2027), *Crowding-Aware Volatility Timing for Factor Portfolios*, JPM Quant Special Issue(经微信解读转述;原文未获取,公式按解读文字还原)。

## 0. 文章要点(转述)
* 同样的波动上升,可能是普通不确定性,也可能是拥挤交易的同步平仓;倒数方差规则不区分两者。
* 收益隐含拥挤度(月频):`C = (z(12 个月累计收益) + z(60 个月 AR(1) 系数) − z(60 个月对 ΔVIX 的 β)) / 3`,每项用截至上月的 120 个月滚动均值/标准差标准化;按因子自身 60 个月滚动三分位划分低/中/高拥挤。
* 发现:标准 VM(倒数方差)在高拥挤状态下增量为负(汇总),动量是最清楚的正面例外;拥挤度单独不是收益信号,与 VIX 压力结合时才有信息。
* 规则(CVM):低/中拥挤保留 VM;高拥挤改用 δ × 原始(未做 VM)暴露,δ ∈ {0, .25, .5, .75, 1} 按扩展窗口历史夏普递归选择。样本外 2013–2026:夏普 0.96 → 1.03,主要改善在波动、偏度与回撤。

## 1. 本项目里此前做过什么
没有做过任何拥挤度指标。相关但不同的研究:FFA/RV 波动预测、VIX 水平与变化作为仓位特征(`lvix_z`、`dlvix`)、Reactive Volatility Model 的恐慌因子、杠杆 ETF 再平衡流(一种直接的仓位代理,本环境无 AUM 数据)。

## 2. 拥挤度指标(按文章方法,月频)
数据:Ken French 月度动量因子 MOM(1927+)、月度 RF;NDX 月末收盘(1985+);CBOE VIX 月末(1990+,`raw/cboe/VIX_long.parquet`,与现有 VIX 文件重叠部分仅 10 天差 > 0.01,不替换后者)。
三个"动量交易":
| 指标 | 因子收益 f_t | 与本项目的关系 |
|---|---|---|
| **C_MOM** | 美股截面动量 MOM(French) | 文章原对象;机构动量仓位、动量崩盘 |
| **C_TSM** | NDX 时序动量:`sign(过去 12 个月 NDX 收益) × r_t` | 与 Sleeve(QQQ 时序/日内动量)和核心仓的趋势过滤同类 |
| **C_MKT** | NDX 超额收益(核心仓的"因子") | 用于核心仓的 CVM(§4 D1) |
构造完全按 §0:run-up 12 个月、AR(1) 与 ΔVIX β 各 60 个月(含当月)、120 个月标准化(截至上月)、60 个月滚动三分位定状态。
**PIT**:月末 t 的指标作用于 t+1 月的交易日;C_MOM 再多滞后一个月(French 数据按月发布,有发布延迟),即月末 t 的值作用于 t+2 月。
可用起点:ΔVIX β 需 60 个月 → 1995;标准化 120 个月 → 2005;状态 60 个月 → 2010。全部覆盖 Sleeve 样本 2019–2026。

## 3. 问题 2:Sleeve 收益与动量拥挤度的关系(描述 + 推断)
* B1 v3 Sleeve(SOTA 腿,未做仓位模型缩放)日损益按 C_MOM / C_TSM 状态分组:均值、Sharpe、偏度、最差日;高 − 低均值差的推断用**月度状态序列的圆周平移**(保持状态的持续性),2000 次。
* B2 文章的核心检验在本项目的对应物:Sleeve 的 VM = 引擎内 σ14 波动目标。VM 增量 = 波动目标 Sleeve − c × 单位仓位 Sleeve(c 使两者 2019–26 波动相等,描述性),按状态分组。
* B3 Sleeve 与 MOM 日收益的相关;动量崩盘日(MOM 日收益 ≤ 5% 分位)Sleeve 的表现,按 C_MOM 状态。
* B4 交互回归(HAC):`Sleeve_t = a + b₁C + b₂ΔVIX + b₃C×ΔVIX`,ΔVIX 分别用当日(同期,描述性)与前一日(可交易)。
* B5 Sleeve 自身的收益隐含拥挤度(日频改写:窗口 252/252/252 日,标准化 252 日)——样本短,只做描述。

## 5. 结果(2026-10-29;`studies/crowding_index.py`、`studies/crowding_study.py`)
指标:投毒自检(切点之后因子收益与 VIX ×(−3))截至切点逐位不变;C 首个可用 2005-01,状态 2010-01。2019 年以来高拥挤月份比例 MOM 39%、TSM 28%、MKT 69%;C_MOM 与 C_TSM 相关 0.43。图 `outputs/figs/crowding_index.png`。v4 复现 1.911。
**B. 关系**
* B1 v3 SOTA Sleeve 日损益按状态:MOM 低/中/高 8.5/11.2/6.8bp,TSM 8.7/3.8/12.4bp;高 − 低的圆周平移 p 0.52–0.73。**Sleeve 收益与动量拥挤度没有可检出的关系**。
* B2 σ14 波动目标相对等波动单位仓位的 ΔSR:MOM 低/中/高 +0.21/+0.34/+0.14,TSM +0.08/+0.31/**+0.39**;MOM、TSM 各状态都为正。与文章的汇总结论(高拥挤时 VM 增量为负)不同,与文章的动量例外一致。
* B3 Sleeve 与 MOM 日收益相关 −0.04。动量崩盘日(MOM ≤ −2.08%,79 天)Sleeve 日均 **+35.7bp**(其余日 +6.7),其中 MOM 高拥挤时 +65.8bp(n=32)。**Sleeve 在动量崩盘日赚钱,是动量崩盘的对冲而不是同向暴露**。
* B4 交互回归:同日 ΔVIX(描述性)下 C_TSM × ΔVIX t = 2.8(TSM 拥挤且 VIX 上升的日子 Sleeve 更赚,凸性);换成可交易的前一日 ΔVIX,所有交互项 |t| ≤ 1.2。
* B5 Sleeve 自身拥挤度(日频,2022-10 起):低/中/高 12.7/5.7/10.6bp,不单调。
**C/D. 纳入策略(组合 OOS 2021–26,相对 v4 = 1.911)**
| 配置 | ΔSR [95%] | dev / test | 判定 |
|---|---|---|---|
| C1 +c_mom | −0.021 [−0.20, +0.18] | −0.03 / −0.02 | 不优于 |
| C2 +c_mom、c_mom×dlvix | −0.049 | +0.13 / −0.15 | 不优于 |
| C3 +c_tsm | −0.045 | −0.19 / +0.01 | 不优于(Sleeve 最差日 −521 → −656bp) |
| C4 +c_tsm、c_tsm×dlvix | −0.097 | −0.28 / −0.04 | 不优于 |
| C5 CVM-TSM(Sleeve) | −0.108 [−0.25, +0.04] | −0.13 / −0.10 | 不优于;递归 δ 70 个月中 65 个月选 1 |
| C6 CVM-MOM(Sleeve) | −0.294 [−0.54, −0.07] | −0.05 / −0.43 | 显著更差 |

结论:动量拥挤度对 Sleeve 没有增量;对 Sleeve 做 CVM 有害(高拥挤状态恰好是 Sleeve 的 VM 增量最大、动量崩盘日 Sleeve 最赚钱的时候)。唯一值得记录的是核心仓的 CVM(D1)在左尾上的改善,但 Sharpe 不显著、dev 为负。

## 6. 追问(`studies/crowding_followup.py`,事后;新配置 +2)
**数据时效**:Ken French 月度与日度文件按月更新,有数周延迟(2026-10-29 下载的文件 "created using the 202609 CRSP database",最后一天 2026-09-30)。C_MOM:月末 t 的值从 t+2 月起使用(t 月数据在 t+1 月内发布,比实盘可得时间晚约 1–3 周,偏保守);C_TSM / C_MKT 由 NDX 与 VIX 收盘构造,月末即可得,从 t+1 月首日起使用,与实盘一致。动量崩盘日的划分用的是 French 日度 MOM,只能事后知道,是描述性的。
**"高拥挤时均值低"与"高拥挤崩盘日赚得多"并不矛盾**:MOM 高拥挤状态 588 天中只有 32 天是动量崩盘日;非崩盘日日均 +3.4bp(低拥挤 +8.0),崩盘日 +65.8bp,32 天贡献了该状态总损益的 53%。
**崩盘日的 B&H**(2019–26,v4 组合 ①):
| 日子 | 天数 | QQQ | 核心仓 | v4 Sleeve | 组合 |
|---|---|---|---|---|---|
| 截面动量崩盘(MOM ≤ 5% 分位) | 79 | +26bp | −17bp | +33bp | +16bp |
| 其中 MOM 高拥挤 | 32 | +97bp | +18bp | +68bp | +86bp |
| 时序动量崩盘(NDX 趋势方向的日收益 ≤ 5% 分位) | 79 | −104bp | −110bp | +108bp | −2bp |
| 其中 TSM 高拥挤 | 18 | −349bp | −302bp | +183bp | −118bp |
这段样本里截面动量崩盘多是"垃圾股反弹"日,QQQ 反而上涨;真正伤 B&H 的是时序动量崩盘(趋势方向的大幅反转),Sleeve 在这些日子平均抵消核心仓亏损的 98%,TSM 高拥挤时抵消 61%。
**机制**:Sleeve 损益按同日 ΔVIX 五分位为 +18.9 / +1.2 / −7.5 / −6.4 / +34.4bp(U 形);VIX 大涨的一档位移 dn 0.98(其余 0.47–0.65)、QQQ 开到收 −107bp、空头腿 +41bp。TSM 高拥挤 × VIX 上升:Sleeve +30.5bp,空头腿 +25.9bp,位移 0.69(与低拥挤 VIX 上升日的 0.73 相近)——拥挤上升趋势中的下跌日不是更大,而是更"一边倒"(推断:同步去杠杆的卖压在日内持续,未单独检验)。同日 ΔVIX 用的是 16:15 的 VIX 收盘,决策时不可得,本质上是在描述当天的结果。
**开仓前可得的 VIX**:VIX 开盘相对前收的跳空(9:30 已知)与 QQQ 跳空相关 −0.50(`gap_n` 已在仓位模型中);交互项 C_TSM × 跳空 t = 0.59、C_MOM × 跳空 t = −0.15。进入 v4 仓位模型:Q1 +vix_gap ΔSR 0.00 [−0.18, +0.17];Q2 +vix_gap + c_tsm + 交互 −0.11。无增量。
