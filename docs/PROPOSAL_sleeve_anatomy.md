## 0. 动机(来自用户的疑问,逐字意图)

1. Sleeve 到底多少天开仓、开仓后多少被止损、多少持到收盘、多少出现「开仓→止损→再开仓」?按方向与 GEX 分层看。
2. **核心问题**:强 GEX 日开仓后,方向延续性是否更好?(`PART12 §6.2` 用标量 GEX 检验"机制"得到「方向相反」,
   然后据此否决了「买逐行权价数据」。但同一文档 §6.1 刚承认「公开 OI 口径的 GEX(= SqueezeMetrics)看不到这些效应」。
   **用一个已知没有分辨力的口径得到的零结果,不能否决更好的口径。** 所以本轮的目标不是再造一个 GEX 策略,
   而是回答:**在我们手上这个口径下,到底有没有可测的信号?逐年是否衰减?这个口径本身是什么?**)
3. 低波日亏钱、大趋势日赚钱(凸性) vs. 「低波动区间 Sharpe 更高」:两者是否矛盾?偏度/峰度是否让 Sharpe 失真?

## 1. 数据与口径(不可变更,与既有实验完全一致)

* 分钟线:`$ETFT_DATA/raw/min1/QQQ.csv`(moomoo,服务器同一份文件),引擎 `etft.intraday.bars.load_bars`;
  1948 天 × 390 bar,2019-01-02 ~ 2026-10-01。
* GEX:`$ETFT_DATA/raw/squeeze_dix_gex.parquet` = SqueezeMetrics 公开 CSV(`date,price,dix,gex`,SPX 口径,**每日标量**,盘后发布)。
  **一致性已验证**:与 `outputs/tables/gamma_proxy.csv` 中研究库实际使用的 GEX 序列,在 1946 个重叠日上**逐位相同**
  (需对我下载序列偏移 +2 个交易日,即 `gamma_proxy.csv` 里的 `gex(t) = 原始GEX(t−2)`;各脚本的滞后惯例不同,见 §1.1)。
* 基线 = 当前实盘配置(同 `PROPOSAL_gex_skip.md §3`):多空、`band+tail`(k=0.5 逐 bar)、voltarget 4×、`reentry=hold`、排除周一。
  **30 个相位**取平均,TQQQ 单股成本(`scale = (QQQ收盘/TQQQ挂牌价)/3`)。
* **复现证据**:本环境下该配置的全样本夏普 0.955 / dev 0.706 / test 1.203 / 年化 12.19% / MDD −11.63%,
  对照研究库 `strategy_comparison.csv`(0.955 / 0.704 / 1.203 / 12.2% / −11.6%)。
  `tools/replay_equivalence.py` 全部 0.00e+00。
* 分期 dev 2019–2022 / test 2023–2026;**噪声护栏 0.15**;配对区块自助 10 天 × 4000。

### 1.1 GEX 滞后
**固定 t−1**(`gex_skip` 惯例;SqueezeMetrics 盘后发布,t−1 是合法最小滞后)。**禁止挑滞后**

## 2. 为什么「逐笔结局」要用相位 0 + 30 相位两层

单相位有「相位运气」(PART10)。本脚本:
* **机制层统计(§3)**:用 30 个相位**各自**的成交明细合并后取比例类指标(比例无偏;**不要**把笔数当独立样本)。
* **收益层(§4 H3)**:30 相位均值曲线。

## 3. 描述性统计(探索性,不进决定规则)

对每个相位的成交明细 `F`(`kind` ∈ ENTRY_LONG / ENTRY_SHORT / STOP / TAILSTOP / MOC …),按**交易日**聚合:

* **A. 开仓**:有 ≥1 次 ENTRY 的日子占比;每个开仓日的 ENTRY 次数分布(1/2/3+)。
* **B. 结局**(对每一笔 ENTRY 判定其**离场原因**):`被硬尾止损` / `被 band 止损或反手` / `持到收盘(MOC)`。
* **C. 重复开仓**:同一天内出现 `ENTRY → 止损类离场 → 再 ENTRY` 的天数;其中「同向 / 反向」。
  (注意:`reentry=hold` 下同向止损+同向信号不会产生往返,所以同向重开只可能来自**硬尾止损之后**下一检查点信号仍成立。)
* **D. 条件分层**:方向(多/空)× GEX 三分位(dev 阈值)× 年份。

每个单元报告:样本数、比例、**入场到收盘的方向收益**(`sgn × (close/entry − 1)`,与仓位无关,不受 vol targeting 敞口污染)、
MFE/MAE(入场后到收盘的最大有利/不利方向偏离)、逐笔净收益。

## 4. 检验(各一个主检验;Bonferroni α = 0.05/3 = 0.0167)

**H1(延续性)**:强 GEX 日(t−1 GEX 位于 **dev 期**三分位的**高档**)开仓后的**入场到收盘方向收益**,
与低档相比有差异。

* 预测方向**不预设**。两个相反的先验都合理:
  (i) 经典 dealer 叙事:高 GEX = 做市商净多 gamma = 压制趋势 → 高档延续性**更差**;
  (ii) 用户直觉:强 GEX 日有结构性,延续性**更好**。
  所以检验为**双侧**,只报告差异的符号、大小与区间。
* 检验量:`E[方向收益 | 高档] − E[方向收益 | 低档]`,按**交易日聚类**的区块自助(10 天 × 4000);
  再做同样的比较但**控制 σ_daily**(回归 `方向收益 ~ 高档 + log σ_daily`),因为 GEX 与波动共线(`PROPOSAL_gex_skip` 的「敞口假象」)。
* **dev 与 test 必须同号**,否则不算通过。

**H2(逐年衰减)**:GEX 对**当日波动幅度**的预测力(这是研究库里**唯一复现成功**的 GEX 结果,`gex_vol_forecast`)
是否随 0DTE 时代(2022-05 每日到期上线)而衰减。

* 检验量:每个日历年,`log|open→close|` 对 `log GEX(t−1)` 的回归斜率与 t 值(HAC),**控制 `log σ_14`**。
* 主检验:2019–2022-04 vs 2022-05–2026 两个子期斜率之差(自助)。**逐年的数字只作描述**。
* 注意:GEX 的**定义**不随时代变(公开 OI 口径),变的是「OI 是否还能代表 0DTE 做市商持仓」。
  所以这个检验只能说明**这个口径的信号**是否衰减,**不能**证明或否定「真实 dealer 持仓」是否有用。

**H3(凸性与 Sharpe 失真)**:
* (a) 在**同一条** 30 相位均值曲线上,按**事前** σ_14 三分位 与按**事后**当日已实现波动五分位,分别报 Sharpe、均值、偏度、峰度、
  最差 5% 的 CVaR、正收益日占比,解释「事前低波 Sharpe 高」与「事后平静日亏钱」为何不矛盾。
* (b) 用 **偏度/峰度不敏感的度量**(Sortino、Omega、Gain-to-Pain、收益的分位数)重新排序三分位,看结论是否依赖 Sharpe。
* 这是描述性的;**不进决定规则**。

## 5. 对照与护栏
* **随机重标签对照**:对 H1,把 GEX 档位在日子之间随机置换 2000 次,得到「差异」的零分布。
* **敞口/波动对照**:见 H1 的 σ_daily 控制。
* **噪声护栏**:任何 ΔSharpe 类结论 |Δ| < 0.15 按噪声处理。
* **独立性**:SPY 与 QQQ 日收益相关 0.79,**不用 SPY 当独立验证**(`PROPOSAL_round3 §1`)。
* 机械化审计:对 `sleeve_anatomy.py` 做**未来数据投毒**(`audit.harness.poison_future`),GEX 档位必须不变。

## 6. 先验(写在前面,防止事后抢救)
* H1:我对「高 GEX 延续性更好」的先验成功概率**低**——8 种用法已被否,且这个口径已被承认「看不到」目标效应。
  但检验本身是有信息的:**它能告诉我们这个口径的分辨力到底有多低**,从而回答是否值得采集真实逐笔方向数据。
* H2:先验**中等**偏高(波动预测是唯一复现成功的)。
* 如果 H1、H2 都不通过:结论是「公开 OI 口径无信号」,**这不否定真实 dealer 位置的价值**,
  只说明**要回答用户的核心问题必须换数据**——这就是 `optrec` 的用途。
