# RV21 降风险：权重参数敏感性

脚本 `sens_rv_weights.py`（全部参数可从命令行改）、图 `outputs/full/figs/sens_rv21_weights.png`、
表 `outputs/full/intraday/sens_rv_weights.csv`、完整输出 `sens_rv_weights.txt`。

## 这是什么、不是什么

* **描述性分析**：SPX/NDX 这两条序列已被看过很多遍，所以不做显著性门槛，只看曲面形状。
* **去掉了均值匹配**：之前 `weight_from` 把权重缩放到全样本均值 1.0，用了全期信息。
  这次权重参数事前固定；MDD 的对照是"同平均敞口的常数权重"。自检：成本 0 时复现上一轮 SPX ΔSR −0.093。
* 成本：每单位 |Δw| 2bp。不汇报最优格子。
* 三段样本：1992-2026 全部 / 2010-2026 / 2010-2026 剔除 COVID（2020-02~05）。

## 读图前的两个方法学提醒

1. **lo=0 一行的 ΔSharpe 对 hi 不变**（−0.113 重复四次）。`w = hi·(1−p)` 是常数倍，Sharpe 对缩放不变。
   所以对 Sharpe 而言这不是二维网格，lo=0 时只有"权重比"一个有效维度。
2. **ΔMDD 沿 hi 方向上升，有一部分是对照的杠杆造成的**：hi 越大，平均敞口 c 越大，
   作为对照的 c·r 本身回撤越深。因此 ΔMDD 只应沿 **lo 方向（固定 hi）** 读，不要读成"calm 期加杠杆降低回撤"。

## 结果

### 面板 A（线性映射，lo × hi）

**1. 默认的 lo=0 是整张图里 Sharpe 最差的一行（5/6 个样本），把下限抬到 0.25~0.5 后六个样本全部改善：**

| 样本 | lo=0 | lo=0.25 | lo=0.5 | （hi=1.5 固定） |
|---|---|---|---|---|
| SPX 1992-2026 | −0.113 | −0.041 | −0.008 | |
| SPX 2010-2026 | −0.061 | +0.009 | +0.032 | |
| SPX 2010+ 剔 COVID | −0.150 | −0.068 | −0.025 | |
| NDX 1992-2026 | −0.029 | +0.016 | +0.030 | |
| NDX 2010-2026 | +0.062 | +0.101 | +0.097 | |
| NDX 2010+ 剔 COVID | +0.020 | +0.062 | +0.067 | |

6/6 同号。但这 6 个样本高度重叠，不是 6 次独立证据。

**2. 这回答了"HH 里 0.40 的权重"的问题**：损失主要来自 **把权重压到 0**（最高波动百分位时完全离场），
恰好错过恐慌中的反弹（HH 象限未来 21 日 +2.09%）。保留一个 0.25~0.5 的底仓，大部分 Sharpe 成本消失，
而 2010 后的回撤改善基本保留：

| SPX 2010+ 剔 COVID | ΔSR | ΔMDD |
|---|---|---|
| lo=0, hi=2（上一轮默认） | −0.150 | +4.4pp |
| lo=0.5, hi=1.0（只降风险） | −0.005 | +3.4pp |
| lo=0.5, hi=1.5 | −0.025 | +6.6pp |
| lo=0.25, hi=2 | −0.084 | +10.3pp |

**3. 曲面是宽平台，不是刀刃**：lo∈[0.25,0.75] 的全部格子在 NDX 三个样本里 ΔSR 全为正（+0.03~+0.10）。
但平台的含义是 **"几乎不付保费"**，不是 "有 alpha"：SPX 全样本的平台在 −0.02~+0.005。

| 面板 A 摘要 | ΔSR>0 占比 | ΔSR>+0.15 | ΔSR<−0.15 | ΔMDD>0 占比 |
|---|---|---|---|---|
| SPX 1992-2026 | 37% | 0% | 0% | 58% |
| SPX 2010-2026 | 74% | 0% | 0% | 100% |
| SPX 2010+ 剔 COVID | 21% | 0% | 21% | 100% |
| NDX 1992-2026 | 79% | 0% | 0% | 79% |
| NDX 2010-2026 | 100% | 0% | 0% | 100% |
| NDX 2010+ 剔 COVID | 100% | 0% | 0% | 100% |

**没有任何格子超过 +0.15 噪声参照。**

**4. 降风险 vs 加杠杆**（只降风险列 hi=1 / 只加杠杆行 lo=1，均值 ΔSR）：
SPX 全样本 −0.031 / +0.004；NDX 2010+ +0.069 / +0.051。加杠杆那一侧（calm 期 w>1）在 NDX 上贡献了
一半以上的正 Sharpe，但它需要 >1 倍杠杆，不是免费的。

### 面板 B（阈值映射 = 纯保险）

| 摘要 | ΔSR>0 占比 | ΔMDD>0 占比 | 年换手(中位) |
|---|---|---|---|
| SPX 1992-2026 | 31% | **25%** | 3.2 |
| SPX 2010-2026 | 94% | 100% | 2.2 |
| SPX 2010+ 剔 COVID | 50% | 81% | 2.1 |
| NDX 1992-2026 | 81% | **25%** | 3.3 |
| NDX 2010-2026 | 94% | 75% | 2.7 |

**作为"纯保险"，长历史里它并没有保到险**：全样本 75% 的格子回撤比同敞口常数权重**更深**
（SPX q=0.9, lo=0 为 −18.9pp）。只有 2010 之后才成立。原因我没有逐事件验证，
推测是 2000–2003 这类熊市反复出现"波动飙升—离场—反弹—再入场"的来回被打。

### 面板 C（信号定义）

12 个 (RV 窗口 × 百分位窗口) 组合，默认映射：

* SPX 2010+ 的 ΔSR 在 −0.085 ~ +0.052 之间；**相邻格子就会变号**（RV21/504 为 −0.061，RV42/252 为 +0.052）。
* RV10 在两个指数上一律为负；RV63/1008 一律为负。正值只出现在 NDX 的 RV21~42 + 短百分位窗口附近。
* 2010 后的 ΔMDD 在**所有** 12 个组合里都是正的（SPX +11.8~+15.4pp），但剔除 COVID 后缩到 +3.0~+6.8pp。

### 噪声参照（配对区块自助，95% 区间半宽）

| 格子 | 半宽 |
|---|---|
| 默认线性 (0,2) | 0.21 ~ 0.34 |
| 阈值 q=0.90, lo=0.5 | 0.08 ~ 0.15 |

**全部格子的点估计都落在各自区间内含零**（唯一接近的是 NDX 全样本阈值格 +0.068，区间 [−0.008, +0.149]）。
因此以上所有差异都只能当作"曲面形状"，不能当作效应估计。

## 结论

1. **"HH 里成本 6.06pp/年"不是 RV21 降风险本身的属性，而是 lo=0 这个参数选择的属性。**
   抬高底仓到 0.25~0.5，Sharpe 成本几乎消失，2010 后回撤改善大体保留。
2. **但这仍然是保险，不是 alpha。** 平台的含义是"不付保费"；没有任何格子显著好于零。
3. **保险只在 2010 后成立**：长历史里阈值保险 75% 的格子回撤更深。与前一轮 R1/R2/R3 一致。
4. 若要在产品里保留 RV 降风险，建议形态是 **底仓 ≥0.5 的温和版本**（如 lo=0.5, hi=1.0~1.5，
   或阈值 q=0.9, lo=0.5），而不是 lo=0 的全退出；静态再配比 (0.6, 1.4) 仍是不依赖体制假设的首选。

## 如何自己改权重

```bash
python sens_rv_weights.py                                   # 默认全部三个面板
python sens_rv_weights.py --lo 0,0.3,0.6 --hi 1,1.4 --panels A
python sens_rv_weights.py --cell thresh:0.9,0.5 --cost-bp 1  # 单格子 + 自助区间
python sens_rv_weights.py --cell linear:0.5,1.0 --rvw-one 42 --pw-one 252
```
参数：`--lo --hi --q --lo-thresh --rvw --pw --cost-bp --panels --cell --rvw-one --pw-one`。
