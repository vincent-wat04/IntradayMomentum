# PROPOSAL 第三轮 — 入场带自适应、O2 迭代、用新方法替换 v3 中重叠的组件(预注册,2026-10-23)

分支 `research/intraday-vol-entry-2026-10`。前两轮见 `PROPOSAL_intraday_vol_entry.md`、`_r2.md`。本文在运行前写定。
基线 B = v3 ① 组合(与第二轮相同,成交缓存为第二轮重建后的版本)。所有配置都在 v3 组合内检验(第二轮结论:只在实盘 Sleeve 上有效的结果不能作为依据)。

## 1. 入场带(第二轮 C3 的迭代)
第二轮 C3 同时放宽入场带与止损带,Sleeve 最差日 −250 → −332bp。本轮把两者分开:
* **E1 只放宽入场带**:入场判断用 `带宽 × s3`,`s3 = clip(√((RV_k/S_RV,k)/(V_k/S_V,k)), 1, 2)`(与 C3 相同);止损带、"同向仍成立则不平仓"(hold)、rearm 判断全部用原带宽。
  实现:不改引擎源码;用 `inspect` 取 `RI.simulate` 源码,只做 3 处文本替换(新增参数 `entry_mult`、入场用的 `ub_e/lb_e`、入场块里的 `side_now → side_e`)生成研究用函数。**门槛:`entry_mult` 为 None 或全 1 时,30 相位成交与日收益逐位等于 `RI.simulate`。**
* **E2 = E1 + A2**:仓位模型 CLEAN + `rv_surp_1000`(第二轮 A2 的特征)。

## 2. O2 的迭代
第一轮 O2(组合下行半方差,阈值 0)在 v3 上 ΔSR +0.068(dev +0.18 / test +0.02),形式上通过、增量小;第二轮 A1(腿级半方差)−0.010。本轮两个迭代:
* **O2-lin**:O2 目标 + 线性链接 `k = clip(1+θᵀz, 0, 2)`(线性链接在 §8 是最好的链接形式)。
* **O2-lpm**:下偏矩只惩罚大亏损:`U = mean(R) − γ/2·mean(min(R − τ, 0)²)`,τ = 训练期基线组合日损益的 10% 分位;`γ = mean(B)/mean(min(B − τ, 0)²)`。
其余同 B(CLEAN、λ 网格、留一年 CV 用各自目标打分)。

## 3. 替换 v3 中与新方法重叠的组件
先验判断(运行前):
| v3 组件 | 与新方法的重叠 | 替换方式 |
|---|---|---|
| FFA-P 跳过(预测振幅最低 20% 的日子不交易) | 同为"今天的波动"信息,作用在低波动一端;新方法(s3)作用在高波动/无量波动一端 | **R1**:去掉 FFA-P 跳过,改用 E1 的入场带 |
| 仓位模型特征 `b30_n`(首 30 分钟振幅 / σ14) | 与 `rv_surp_1000`(首 30 分钟 RV / 同时段季节常态)都是"开盘波动相对常态" | **R2**:CLEAN 中 `b30_n` 换成 `rv_surp_1000`(替换,不是增加) |
| 目标函数(均值–方差) | O2 系列 | 见 §2 |
| CPI 回补、FOMC≥14:30、15:40 平仓、排除周一 | 与新方法无关 | 不动 |
运行时同时报告实际相关(描述性):`rv_surp_1000` 与 `b30_n`、FFA-P 排名的 Spearman 相关。
**两个"新方法版 v3"**(组合替换,一次写定):
* **N1** = v3 + E1 入场带 + R2 特征替换 + O2 目标(保留 FFA-P 跳过)
* **N2** = N1 去掉 FFA-P 跳过
对 N1、N2 给出与 v3 完全同口径的 tearsheet(dev 2019–22 / test 2023–26 / 全期,分布面板、分年、净值与回撤图)。

## 3b. 线性仓位模型与 dur_rate(用户 2026-10-23 追加,运行前写定)
`REPORT_unified_sizing.md` §8.1–8.2 的两个事后候选在本轮按预注册重测:**L1** 线性链接(CLEAN)、**L2** 线性链接 + `dur_rate`(10:00 的价格持续期事件率)。
**按先验顺序的累加阶梯**(每一步只加一个改动,顺序固定,不因结果调整;每一步报相对上一步与相对 v3 的 ΔSR):
| 步 | 改动 | 为什么排在这里 |
|---|---|---|
| S0 | v3 现行 | 基线 |
| S1 | + E1 入场带(还手) | 最上游:改变成交集合;下游的仓位模型要在新成交上重训 |
| S2 | + R2(`b30_n` → `rv_surp_1000`) | 仓位特征:先替换重叠的信息 |
| S3 | + `dur_rate` | 仓位特征:再加新的信息(事件率与开盘振幅相关 0.67 但符号相反,先换掉 b30_n 再加,避免两者在同一模型里互相抵消) |
| S4 | 线性链接 | 函数形式:在信息集确定之后再改形状(§8.2:线性的主要好处是有效正则更弱) |
| S5 | O2 目标(组合下行半方差) | 风险偏好:最后改目标函数 |
| S6 | 去掉 FFA-P 跳过 | 冗余检验:只有在替代信息(E1、rv_surp)都已在模型里时才有意义 |
S5、S6 作为"新方法版 v3"的完整候选出 tearsheet(与 N1、N2 并列)。阶梯不是逐步筛选:无论每一步结果如何,下一步都照常叠加。

读法:
1. 没有配置满足预注册判定;最接近的是 O2-lin(下界 −0.052)。
2. `dur_rate` 在两个上下文里都正:单独(L1 → L2 +0.03)与阶梯中(+0.13,区间 > 0)。是这几轮最稳健的单项增量。
3. 线性链接单独有效(L1 +0.09、O2-lin +0.14),但在 E1+R2+dur_rate 之后为负(−0.07):与信息集有交互,不是普遍更好。
4. 去掉 FFA-P 跳过的点估计大(+0.08~+0.21)但区间极宽、dev 期变差,不是可靠的替换。
5. E1 与第二轮 C3 的 Sleeve 最差日相同(−332bp):29,679 笔出场里只有 271 笔是带宽止损(其余为收盘 19,526、尾部止损 9,882),**左尾来自放宽入场带后更晚、更远的入场,而不是止损变远**。
