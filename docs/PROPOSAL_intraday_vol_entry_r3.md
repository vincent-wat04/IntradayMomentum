## 1. 入场带(第二轮 C3 的迭代)
第二轮 C3 同时放宽入场带与止损带,Sleeve 最差日 −250 → −332bp。本轮把两者分开:
* **E1 只放宽入场带**:入场判断用 `带宽 × s3`,`s3 = clip(√((RV_k/S_RV,k)/(V_k/S_V,k)), 1, 2)`(与 C3 相同);止损带、"同向仍成立则不平仓"(hold)、rearm 判断全部用原带宽。
  实现:不改引擎源码;用 `inspect` 取 `RI.simulate` 源码,只做 3 处文本替换(新增参数 `entry_mult`、入场用的 `ub_e/lb_e`、入场块里的 `side_now → side_e`)生成研究用函数。**门槛:`entry_mult` 为 None 或全 1 时,30 相位成交与日收益逐位等于 `RI.simulate`。**
* **E2 = E1 + A2**:仓位模型 CLEAN + `rv_surp_1000`(第二轮 A2 的特征)。

## 2. O2 的迭代
第一轮 O2(组合下行半方差,阈值 0)在 v3 上 ΔSR +0.068(dev +0.18 / test +0.02),形式上通过、增量小;第二轮 A1(腿级半方差)−0.010。本轮两个迭代:
* **O2-lin**:O2 目标 + 线性链接 `k = clip(1+θᵀz, 0, 2)`(线性链接在 §8 是最好的链接形式)。
* **O2-lpm**:下偏矩只惩罚大亏损:`U = mean(R) − γ/2·mean(min(R − τ, 0)²)`,τ = 训练期基线组合日损益的 10% 分位;`γ = mean(B)/mean(min(B − τ, 0)²)`。
其余同 B(CLEAN、λ 网格、留一年 CV 用各自目标打分)。

## 3. 替换 v3 中与新方法重叠的组件
先验判断(运行前):
| v3 组件 | 与新方法的重叠 | 替换方式 |
|---|---|---|
| FFA-P 跳过(预测振幅最低 20% 的日子不交易) | 同为"今天的波动"信息,作用在低波动一端;新方法(s3)作用在高波动/无量波动一端 | **R1**:去掉 FFA-P 跳过,改用 E1 的入场带 |
| 仓位模型特征 `b30_n`(首 30 分钟振幅 / σ14) | 与 `rv_surp_1000`(首 30 分钟 RV / 同时段季节常态)都是"开盘波动相对常态" | **R2**:CLEAN 中 `b30_n` 换成 `rv_surp_1000`(替换,不是增加) |
| 目标函数(均值–方差) | O2 系列 | 见 §2 |
| CPI 回补、FOMC≥14:30、15:40 平仓、排除周一 | 与新方法无关 | 不动 |
运行时同时报告实际相关(描述性):`rv_surp_1000` 与 `b30_n`、FFA-P 排名的 Spearman 相关。
**两个"新方法版 v3"**(组合替换,一次写定):
* **N1** = v3 + E1 入场带 + R2 特征替换 + O2 目标(保留 FFA-P 跳过)
* **N2** = N1 去掉 FFA-P 跳过
对 N1、N2 给出与 v3 完全同口径的 tearsheet(dev 2019–22 / test 2023–26 / 全期,分布面板、分年、净值与回撤图)。

## 6. 事后:候选叠加与"要不要去掉 FFA-P 跳过"(`studies/r3_stack.py`,累计 +4)

## 9. 细查:去掉 FFA 后 Sharpe 更高,是不是因为仓位模型本来就在 FFA 跳过日给小仓位?(`studies/r3_ffa_check.py`,诊断;新配置 +1)
OOS 2021–26 共 1166 个样本日,FFA 跳过 271 日(23.2%;2022 年 0 日——高波动年里没有预测振幅落在 504 日滚动分位 20% 以下);跳过日 ≡ ffa_rank ≤ 0.2(不一致 0)。
* **假设不成立**。去掉 FFA 后重训的模型在跳过日的 k 并不小:多头 k 均值 0.80–0.96、空头 1.02–1.19,中位 0.94–1.06;线性模型在跳过日 k = 0 的比例(5–14%)反而低于其余日(20–22%)。
* 跳过日本身:未缩放 Sleeve +1.4~+2.3bp/天(其余日 +9.6~+10.2);经去 FFA 模型缩放后 +8.2~+11.0bp(其余日 +12.2~+14.3)。缩放后变好主要来自 2024(+22~+24bp),2026 为 −7~−17bp。
* ΔSR(去 FFA − 保留 FFA)精确分解:
| 设定 | 合计 | ① 只把跳过日加回来 | ② 只换成重训后的模型(其余日) |
|---|---|---|---|
| v3 sigmoid | +0.061 | +0.202(2024 +0.87) | −0.145 |
| L2 线性+dur_rate | −0.016 | +0.099(2024 +0.76) | −0.119 |
| v4 | +0.022 | +0.169(2024 +0.76) | −0.151 |
  三种设定下 ② 都为负:去掉 FFA 后,仓位模型要在 271 个低振幅日上一起拟合,其余日的空头 k 平均下降 0.14–0.25,其余日的组合表现变差。去 FFA 的"好处"完全来自 ①,而 ① 集中在 2024 一年。
* 仓位模型对 FFA 信息只部分吸收:多头 k 按 ffa_rank 五分位 0.79–0.98(Q1)→ 1.21–1.25(Q5),Spearman +0.15~+0.23。但未缩放损益按 ffa_rank 五分位是 +0.8 / +14.1 / +9.2 / +6.4 / +8.0bp——**只有最低一档差,是阈值效应**,线性/sigmoid 的单调形式拟合不了,硬跳过正好对应这个形状。
* 对照:去掉硬跳过、把 ffa_rank 作为连续特征放进 v4 的仓位模型 → 相对 v4 −0.042 [−0.39, +0.31],dev +0.09 / test −0.12,不优于硬跳过。
结论:保留 FFA 硬跳过。
