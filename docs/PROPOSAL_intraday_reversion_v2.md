# PROPOSAL — 日内回转 v2:分钟 K 线可得的技术指标 + 量价微结构代理 + ML(保留 PART8 §4 旧记录)

不删改 `PART8_INTRADAY_TQQQ_AND_BATTERY.md` §4(9 种单标的 + 7 种横截面),本篇是新增。

## 0. 旧记录说了什么(先验的来源)
* QQQ 单标的:`VWAP_REV` 日均 10.4 笔、2023+ Sharpe −1.9(0.5bp)~ −5.4(2bp);`LUNCH_REV` −0.42;`ON_REV` +0.16(dev −0.91);随机方向安慰剂 −0.62。
* 横截面 77 只:`XS_L30_REV` rank IC 4.1%、毛 Sharpe 2.24,但毛收益 1.5bp/天 < 往返成本 3.26bp ⇒「真实但不可交易」。
* 结构性结论:**必须每天开平仓的策略,每笔毛 alpha 只有 ~1.5bp**。本研究要回答:在 QQQ(成本最低的标的之一)上,更丰富的分钟级特征 + ML 能否把「每笔毛 alpha」抬到明显高于成本。

## 1. 用户意图 → 这里的定义
「broker 常用的日内回转降成本」= 持有底仓(B&H)时,日内**高抛低吸**再回到底仓(做 T):净效果等价于在底仓上叠一个**日内平仓的多空叠加仓**(卖出信号 = 叠加空头,买入信号 = 叠加多头)。
所以评估对象是**叠加仓的净收益**,与底仓无关;卖出侧(叠加空)和买入侧(叠加多)分开报,看是否「只在一侧有用」(底仓为多头时,只做卖出侧可以不增加杠杆)。

## 2. 无前视设计
* 决策在第 k 根 1 分钟 bar **收盘**,**下一根 bar 开盘成交**(与 `backtest.py` 一致);k = 34, 39, …(每 5 分钟一次,首次 10:05,保证 30 分钟回看可得)。
* 持有 h ∈ {15, 30, 60} 分钟后在 bar 开盘价平仓;不跨日;**同一时刻只持一个仓位**;半日市排除。
* 特征只用 ≤k 的 bar 与 t−1 及更早的日度数据(同 `PROPOSAL_lowvol_avoidance` 的口径,σ14、VIX(t−1)、GEX(t−1))。
* Walk-forward:2019–2020 首个训练窗,之后**每年初**用截至上年末数据重估;OOS = 2021–2026。标签不跨日,训练窗与测试窗无重叠。
* 阳性对照:把标签方向取反(用未来 h 分钟收益作特征)必须使 IC 暴增(脚本内自检);未来污染自检:污染某天 k 之后的 bar,k 及之前的特征须不变。

## 3. 特征(冻结)
技术:z5/z15/z30(收益按 σ14·√(n/390) 标准化)、距开盘 z、VWAP 偏离 z、30 分钟布林 %B、当日区间位置、距日高/日低(÷σ14)。
量价代理(无逐笔,只有 OHLCV):30 分钟 CLV×量(Chaikin 型)、15 分钟「按 bar 方向给量加符号」的净量比、15 分钟 RV 比、15 分钟波幅比、累计相对成交量(PIT)。
状态:时间 k/390、隔夜缺口/σ14、log σ14、log VIX(t−1)、GEX z(t−1)。

## 4. 模型与规则(冻结)
* 目标 = 未来 h 分钟收益 ÷ (σ14·√(h/390))(去异方差);岭回归(α=100,标准化)与 LightGBM(depth 3,200 棵,lr 0.03,min_child 500,subsample 0.7,colsample 0.8)。
* 入场规则:预测收益(换算回 bp)|pred| ≥ τ,方向 = sign(pred);τ ∈ {1.5, 2.5, 4.0} bp。**τ 不在 OOS 上选择,三个全报。**
* 成本:每边 {0.25(repo 每股口径 ≈ $0.0095/股)、0.5、1.0、2.0} bp;同时报盈亏平衡成本(使净 Sharpe=0)。
* 对照规则(无 ML,方向都测):VWAP 偏离 |z|>2、布林 |%B|>2、z30 |z|>2 的回转与延续两个方向。
* 安慰剂:对 OOS 真实交易按天翻转符号(2000 次)得到毛收益分布;p = 真实毛均值 ≥ 翻转分布。

## 5. 判定规则(冻结)
有证据 ⇔ 同时满足:(i) 2021–22 与 2023–26 毛收益/笔同号为正且 **毛收益/笔 ≥ 2×往返成本(取 1bp/边时 4bp)** ;(ii) 翻转安慰剂 p<0.05(族内 max);(iii) 净 Sharpe(1bp/边)>0 且 |ΔSR 对 0| 区间不含 0;(iv) 邻近 τ、h 同向。
否则写「没有足够证据」。IC 单独显著**不构成**证据(旧记录已证明 IC 4% 仍亏钱)。

## 6. 先验(写在前面)
* IC:OOS 小(rank IC ≤ 1~2%),有时间-of-day 差异;主要来自 `z_open`/`pos_in_range` 的末段(14:00 后)效应。
* 净收益:**失败概率高(≥85%)**。1 分钟 OHLCV 里没有订单流方向,ML 抬高 IC 的幅度有限;PART8 已显示毛收益封顶 ~1.5bp/笔。
* 若出现正结果,最可能是「卖出侧」(高位回落)或 14:00 后的特定窗口——这些是事后解释,需要前向样本。

## 7. 局限
1 分钟 OHLCV 无买卖方向与盘口;只有 QQQ(SPY 相关 0.79,可作同类交叉核对但非独立);2019–2026 一个周期。Hawkes/订单流等需要逐笔,不在本研究范围。

## 结果(2026-10-11;`studies/intraday_reversion_v2_study.py`;日志 `studies/outputs/full/intraday/rev2_log.txt`;表 `outputs/tables/intraday_rev_v2_*.csv`)
面板:1933 个整日 × 59 个决策点(10:05–15:30,每 5 分钟)= 114,047 行;OOS 2021–2026。
**自检**:污染 12 个整日 bar>196(×7),k≤195 的 19 个特征逐位不变;阳性对照(特征里加入未来 5 分钟收益)IC=0.378 ≫ 诚实模型 → PASS。

**1) IC(Spearman,OOS)**:ridge 0.006 / 0.010 / 0.016(h=15/30/60),LightGBM 0.004 / −0.002 / −0.004;逐年符号不稳(2026 全负);k≥14:00 的 ridge-h60 IC 0.039 是唯一像样的格子,但 LightGBM 同窗为 0.000。
→ 即使 IC 为正,量级(≤0.016)与 PART8 的横截面 IC(4%)相比小一个量级。
**2) 交易**(每笔毛 bp,dev-OOS / test;盈亏平衡 = 毛/2 每边):
* ML 配置共 18 个。毛 bp/笔 ≥ 4bp 且两期同号的只有 **ridge h=30 τ=4bp(+4.3 / +19.5,但仅 387 / 69 笔)** 与 ridge h=15 τ=4bp(+7.5 / +25.6,仅 44 / 16 笔);
  LightGBM h=15/30 τ=4bp dev/test 毛 +0.9/+5.3、−2.7/+4.8(符号不一致)。笔数 <100 的格子不可信(一笔 ±50bp 即改变均值)。
* 净 Sharpe(1bp/边):所有 ML 配置 dev-OOS 与 test **同时 >0** 的只有 ridge h=30 τ=4(0.675 / 0.629,69 笔)与 ridge h=15 τ=4(0.431 / 0.465,16 笔)——样本过小;2bp/边下 dev-OOS 的 ML 配置只有这两格为正且 SR≤0.27。
* **置换安慰剂**(翻转符号,族内 max):17 个 ML 配置最小 p_族内 = 0.083(ridge h=30 τ=4),其余 0.5~1.0。**没有一个满足 p<0.05。**
**3) 规则对照(无 ML)——方向很说明问题**:
| 规则 | 回转(高抛低吸)毛 bp/笔 dev / test | 延续 dev / test |
|---|---|---|
| VWAP 偏离 |z|≥2, h=30 | −0.89 / −1.71 | +0.89 / +1.71 |
| VWAP 偏离 |z|≥2, h=60 | −2.99 / −2.85 | +2.99 / +2.85 |

* **VWAP 偏离的「回转」方向在两个期间一致为负,延续方向一致为正(h=60:+2.99 / +2.85bp,盈亏平衡 ≈1.4bp/边,净 SR@1bp +0.31/+0.26,@2bp 转负)。** 这与 PART8 的 VWAP_REV(−1.9~−5.4 Sharpe)和噪声区域突破(延续)同向:
  QQQ 的日内「偏离 VWAP」更像是**趋势的早期信号**,不是可以逆向吸收的噪声。毛 2.9~3.0bp < §5(i) 的 4bp 门槛 → 不构成证据,但**方向一致性**值得记录。
* 「高抛低吸做 T」(底仓上叠加回转)在 QQQ 上按这些规则**毛收益即为负**,不是成本问题。

**判定**:没有足够证据。分钟 K 线 + ML 没有把「每笔毛 alpha」抬到成本之上;与先验(失败概率 ≥85%)一致。新增信息:(a) 回转方向在 VWAP/60 分钟窗口上一致为负;(b) ML 的 IC≈0.01 不足以支付最低成本。
**与已有 Sleeve 的关系**:Sleeve(噪声带突破 = 延续)与「VWAP 偏离延续」是同一类效应的不同参数化(PART8 §4.2:同日同标的,相关 0.55);若要用,应当作为 Sleeve 的**内部过滤/加仓信号**测试,而不是新增一条独立腿。这一步未做。
