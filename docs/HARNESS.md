# 研究 Harness(方法论总纲)

本文件把此前散落在 `studies/audit/harness.py`、`docs/AUDIT.md`、README §4、各 PROPOSAL 的"偏离记录"和 `INTERVIEW_PREP.md` 里的做法合并成一份,并补入 QuantMLResearch/quant-handbook 中对本项目有用的部分。
"讲"指 handbook 的 `module_xx` 讲次。未采纳的条目在 §10 说明原因。

**证据等级(全项目统一用词)**

| 等级 | 含义 | 可以怎么说 |
|---|---|---|
| E3 | 预注册 + 通过全部判据 + 前瞻(未参与任何选择的数据)确认 | "有效" |
| E2 | 预注册 + 通过判据,但样本内/OOS 同属已被反复使用的历史 | "历史上稳健,尚待前瞻确认" |
| E1 | 事后发现或预注册但未过判据的线索 | "线索" |
| E0 | 描述性统计 | 不下结论 |

截至 2026-10:v3 的主要组件为 E2(组件选择本身是事后的),v4/v5 的改动为 E1(见 `REVIEW_2026-10.md`)。**"test 2023–26"已不是干净的留出集**:全项目累计试验 ≈ 413 次(`TRIAL_REGISTRY.md`),这段数据参与了其中大部分决策。

## 1. 工作流(每一轮研究都按这个顺序)

1. **预注册**。运行前把假设、配置清单、判据、数据门槛写进脚本头或 PROPOSAL 文档并提交。不得在看到结果后增删配置。事后想到的配置单列为"事后",证据等级最高 E1。
2. **数据门槛**。脚本开头校验输入 md5/清单(`data/MANIFEST_sandbox_2026-10.md5`),并复现上一版基线的关键数字(±0.03 Sharpe),不能复现则中止。
3. **运行**。固定随机种子;块自助用同一组下标比较所有配置(Romano–Wolf 单步族内 p)。
4. **登记**。在 `docs/TRIAL_REGISTRY.md` 追加一行,更新"合计"行(`overfit_audit.py` 从这一行读取 K)。
5. **判定**。按 §3 的规则;报告分布面板(§4),而不只是 Sharpe。
6. **如实写偏离**。与预注册不一致的地方写在文档的"偏离记录"里。

## 2. 防前视与实现正确性(机械化测试)

沿用 `studies/audit/harness.py` 和 `docs/AUDIT.md`:未来数据投毒、日内 bar 投毒、独立重写对账、预言机(`score_t = r_{t+1}` 必须暴利,`score_t = r_t` 必须≈0)。每个测试必须在已知的真实 bug 上失败,否则不算数。

补充(handbook 第 2、27–28 讲):
- **信号日 < 成交日**。任何日频特征在 t 日决策时只能含 ≤ t−1 的信息;日内特征只能含决策 bar 及之前。
- **新增特征必须过投毒测试**后才能进入 `CLEAN`。
- **回测杀手 4 项**(handbook 第 1–2 讲)对应本项目的检查位置:前视(投毒)、幸存者偏差(QQQ 单一标的,不适用)、成本低估(§6)、过拟合(§5)。

## 3. 判定规则

**旧规则**(sizing 与入场类研究沿用):全 OOS ΔSR > 0,dev(21–22) 与 test(23–26) 同为正,块自助 95% 下界 > −0.05,三者同时满足才算"优于基线"。

**升级(2026-10 起)**
1. 旧规则只能把一个配置判为"没有明显更差"。要写成"改进",还需要**增量序列**(候选 − 等波动基线)的 PSR(>0) ≥ 0.95,且 DSR(K 取登记簿合计,方差取同族增量)≥ 0.5。不满足的只能写 E1。
2. **新的单特征**需要对目标做 HAC(Newey–West)回归,|t| ≥ 3(Harvey–Liu–Zhu 门槛;handbook 第 14 讲);并报分位单调性 MonoScore(第 15 讲,≥ 0.8)。单特征不过但组合层通过的,标 E1 并说明是联合效应。
3. **复杂度预算**(第 17、19–22 讲的共同结论:低信噪比下复杂模型主要放大噪声)。每个新增特征/参数都要有组合层 ΔSR 的置信区间;去掉它,ΔSR 的 95% 区间若仍含 0 且点估计 < 0.05,就记为"未证明必要",默认不上实盘,除非有预注册的经济机制。
4. **去掉整层的检验**(`review_checks.py` R3d):每一层(如仓位层)都要有"整层换成常数"的对照。
5. 增益必须通过**归因**(§7):若增量主要由对 QQQ 收益/收益²的暴露解释,就写成"风险暴露的改变",不写成 alpha。

## 4. 报告格式

凸性/右偏策略(Sleeve)不能只看 Sharpe。统一的分布面板:均值/中位数(bp)、Sharpe、Sortino、CAGR、MDD、Calmar、偏度、超额峰度、CVaR5%、盈亏比、前 5% 日占利润比、最差日。实现:`sizing_sigma_feed.panel`。

## 5. 过拟合审计(`studies/audit/overfit_audit.py`、`review_checks.py`)

- PSR / DSR(Bailey–López de Prado 2012/2014):K 取登记簿合计;SR0 的方差取候选族 SR 的横截面方差。
- CSCV-PBO(S = 16,C(16,8) = 12,870 种切分)。
- **已知局限(必须随结果一起写)**
  - 对基础策略,PSR(SR>0) 与 DSR ≈ 1 是平凡的:样本日 1,166,SR ≈ 1.8,任何合理 K 都不会改变结论。有信息量的是**增量**。
  - 候选族是同一思路的高度相关变体,DSR 用的横截面方差偏小,SR0 被低估。
  - PBO 对候选族的构成极敏感:含 ρ 维度时 PBO = 0.03(v5 ρ=3 在 12,013/12,870 个切分里样本内最优,它只反映"Sleeve 权重越高 Sharpe 越高"),去掉 ρ 维度、只看仓位模型变体时 PBO = 0.73,增量族 0.81。后者才是"v4 是不是被选出来的"的合适度量(见 `REVIEW_2026-10.md` R1)。
- **内层交叉验证加禁运**(handbook 第 18 讲):`wf(..., embargo=N)` / `wf_obj(..., embargo=N)` 在留出年份前后各剔除 N 个交易日。R2 显示 N = 5/10/21 时 OOS SR 的变化在 ±0.05 以内,λ 的选择不稳定但对结果不敏感。默认值仍是 0,新研究应当用 21 报一次作为稳健性。

## 6. 成本、可成交性、容量(handbook 第 17、27–29 讲 + mdrec 实测)

- 回测成本:TQQQ 半价差 $0.005/股 + 佣金 $0.0045/股;QQQ 腿按 `NC.core_weights` 的 2bp 单边。
- **mdrec 实测核对**(2026-10-20…30,6 个完整交易日;`hf_exec_cost.py`、`hf_validate.py`):TQQQ 半价差中位数 = $0.0050(1 tick),与回测假设一致(1.00×);**但只适用于 L1 深度以内**。L1 单边深度中位数 10:00 约 2,800 股、15:40 约 5,000 股;10 档合计 30k–46k 股。
- 一次性市价单逐档吃单的滑点(相对中间价,$/股,日中位数,10:00 / 15:40):2k 股 0.0070/0.0063,5k 股 0.0106/0.0078,10k 股 0.0174/0.0116,20k 股 0.0328/0.0193。
- 因此**成本假设成立的订单规模上限约 2k 股**(额外滑点 < $0.002)。额外滑点达 $0.005(成本翻倍)约在 7.4k 股。CAPITAL_BASE = 500,000 时 v4/v5 的 Sleeve 单笔中位数为 6.2k/7.7k 股,已在翻倍点附近。由于 Sleeve 只在约一半的交易日成交,折算到日均拖累约 0.4–1.2bp,占 Sleeve 日均收益的 3–9%。
- 容量粗估:handbook 第 28 讲 A* ∝ 1/τ³ 的形式在这里不适用(单标的单品种);直接用盘口深度:单笔 ≤ L1 深度 ≈ 2–5k 股,或拆成 ≤ 2k 股的子单。
- 规则:任何要上实盘的版本,先用 `hf_exec_cost.py` 按目标资金规模重算订单规模分布与额外滑点,写进 PROPOSAL。

## 7. 归因(handbook 第 30 讲 Barra/Brinson,轻量版)

`review_checks.py` R4:把增量序列(候选 − 等波动基线)对 [QQQ 收益, QQQ 收益², 高波动三分位哑变量, 2022 哑变量] 做 HAC 回归。解释:β 为线性暴露,收益²系数为凸性(做多波动性质),α 为剩余。

## 9. 留出集政策

1. 冻结 v5(`tearsheet_v5.py` 的配置:buying-power 上限 2.57、核心仓无交易带 0.10、Sleeve:核心等风险 ρ = 1.5、v4 仓位)。
2. 历史样本冻结到 2026-10-30,**前瞻从 2026-11-02 开始**(与 PR #2 的 `noise_band_validation.py` 的冻结日期一致);不足 252 个交易日不给采用结论。影子盘按 §8 记录每日 Sleeve/核心/组合收益与 PSI。
3. 预注册的复核条件(待用户确认阈值):影子盘满 60 个交易日后,若 Sleeve 日均收益 < 回测均值 − 2 个标准误(标准误用回测日波动 / √60),或实测额外滑点 > 回测假设 2 倍,则回到 v3 配置并重新评估;不得在看到影子盘结果后改动 v5 的参数。

## 10. 高频数据(mdrec)验证摘要

详见 `REVIEW_2026-10.md` §HF。结论影响哪些先验:

- Corwin–Schultz 价差估计 QQQ 中位数 2.80bp,实测 L1 价差 0.30bp(高估约 9×),**不可作为成本代理**。
- BVC(用分钟收益推断买卖方向)与交易所给出的真实主动方向:份额相关 0.275(QQQ)/0.287(TQQQ),符号一致率 0.59/0.61,**信息量很弱**。
- L1 订单流失衡(Cont–Kukanov–Stoikov)对 Δ中间价的 R²:QQQ 0.30,TQQQ 0.65;净主动成交量只有 0.07/0.06。订单流失衡的价格影响主要来自挂单变化而不是成交。
- |收益| 对成交失衡分位基本平坦。
- 样本太短(5 个完整交易日 + 1 个半日),以上都是**描述性**而不是 alpha 证据。
