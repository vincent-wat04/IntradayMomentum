## 4) CPI 缺口回补 overlay:能加多少利润(组合 = L1 RV[0.5,1.5] + Sleeve,2019–2025)
overlay 规则:CPI 高于预期(核心+整体)→ 开盘买入 QQQ,低于预期 → 开盘卖空,收盘平仓,符合预期不做;名义 = f × 资本,每笔扣 2bp 往返。
单独:62 笔,每笔均 **+26.9bp**、中位 +21.2bp,胜率 56%,最差 −270bp、最好 +533bp;**去掉最好 3 笔后每笔 +10.8bp**;分年合计 2019 +50、2020 +404、2021 +238、2022 +213、2023 +223、2024 +443、2025 +99bp(1× 名义);与当日 Sleeve 相关 0.09。
