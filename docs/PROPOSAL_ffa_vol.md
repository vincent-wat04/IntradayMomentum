## 0. 用户的问题与我此前做过什么(诚实)
用户:FFA 在低波日误差小,符合『避开小波动日』;缺点是把大波动预测成小波动,仓位抓不到大波动日。问:收益分布会不会变、模型是否有效、缺陷能否解决、6 个基准试过没有。
**此前做过的基准**:只有 HAR 类(σ₁₄、前日 RV、5 日 RV 作为岭回归特征;`vol_monet_decomp` 里的 HAR 子模型)。**没做过** EWMA(0.94)、CARR、成分 CARR、Spline-CARR、RealGARCH。本轮全部补上。

## 1. FFA(按论文)
* 观测 `R_t = (ln H_t − ln L_t)²/(4 ln 2) × 100`(Parkinson,QQQ 日 OHLC,Yahoo,1999 起);`y_t = ln R_t`(R=0 的日子用窗口最小正值)。
* 窗口 W=1000 个交易日内解 `min Σ(y_t − s_t)² + λ Σ(s_t − s_{t−1})²`,解析解 `s = (I + λEᵀE)⁻¹ y`(三对角带状求解)。
* **调参(论文版 FFA-P)**:λ 网格 {10^k, k = −1, −0.75, …, 4}(21 个),最小化 `Σ_{t≤T−h} (y_{t+h} − s_t(λ))²`,其中 s_t 是**窗口内双侧平滑值**(论文原样;窗口内『偷看』t 之后的数据,但不越过预测时点)。
* 预测 `R̂_{T+h} = exp(s_T) · Ĉ`,`Ĉ = mean_{窗口}(exp(s_{t+h})/exp(s_t))`(论文原样)。
* **理论注记**:一阶差分惩罚的右端点 = 局部水平模型的卡尔曼滤波,稳态增益 `k = (−q + √(q²+4q))/2`,`q = 1/λ`,即**对 ln R 做 EWMA**。所以再定义 **FFA-C(严格因果调参)**:用一侧滤波 `s_t = s_{t−1} + k(y_t − s_{t−1})` 的一步预测误差在窗口内选 λ(同一网格),预测 `exp(s_T)·Ĵ`,`Ĵ = mean_{窗口}(R_{t+1}/exp(s_t))`(Jensen 偏差修正)。FFA-P 与 FFA-C 都报。
* **缺陷修复(2 个,预注册)**:
  * **FFA-SD(状态依赖惩罚)**:在 FFA-C 上,若 `y_t − s_{t−1} > c·σ_u`(σ_u = 窗口内创新的标准差,c=1.5),当天增益换成 `k_hi`;`k_hi ∈ {2k, 4k, 0.5, 0.8}` 在窗口内按一步误差选。即『检测到冲击就放松平滑』,论文展望的方向。
  * **FFA-MAX**:`max(FFA-C, EWMA0.94)`(论文缺陷是低估尖峰,取两者较大者)。
* **基准(论文的 6 个)**,全部作用在同一 R 上,窗口 W=1000、**每年初重估参数**(论文是逐日滚动重估;这里为计算量逐年,参数在年内用递推更新预测——偏离 1):
  1. **EWMA**:`F_{t+1} = 0.94F_t + 0.06R_t`(无需估计)。
  2. **HAR**:`R_{t+h} = b₀ + b₁R_t + b₂R̄⁽⁵⁾_t + b₃R̄⁽²²⁾_t`(OLS,预测负值截到窗口最小值)。
  3. **CARR(1,1)+杠杆**:`λ_t = ω + αR_{t−1} + βλ_{t−1} + θR_{t−1}·1[r_{t−1}<0]`,指数 QMLE。
  4. **成分 CARR**(Engle–Lee 型):`λ_t = q_t + α(R_{t−1}−q_{t−1}) + β(λ_{t−1}−q_{t−1})`,`q_t = ω + ρq_{t−1} + φ(R_{t−1}−λ_{t−1})`,QMLE。
  5. **Spline-CARR**(两步近似,偏离 2):`ln R_t` 对时间的二次样条(结点每 250 日)回归得 τ_t,再对 `R_t/τ_t` 拟合 CARR(1,1);预测时 τ 固定在窗口末值。
  6. **RealGARCH(1,1) 对数线性**(Hansen 2012):`r_t = √h_t z_t`,`ln h_t = ω + β ln h_{t−1} + γ ln R_{t−1}`,`ln R_t = ξ + φ ln h_t + τ₁z_t + τ₂(z_t²−1) + u_t`,联合高斯 QMLE;`E[R_{t+1}] = exp(ξ + φ ln h_{t+1} + σ_u²/2)·E[exp(τ₁z+τ₂(z²−1))]`(解析式)。
* 多步(h=5、22):FFA-P/FFA-C/EWMA/HAR/CARR/成分 CARR;Spline-CARR、RealGARCH 只做 h=1(偏离 3)。

## 2. 统计检验
* OOS = 2015-01 ~ 2026-10(主),另报 2021+(与 Sleeve 重叠)。损失:RMSE、MAE、QLIKE(`R/F − ln(R/F) − 1`)。Diebold–Mariano(HAC,滞后 h+5)各模型相对 FFA-P。按**实现 R** 的 OOS 分位分三态:低(≤20%)、正常、高(>80%)分别报。
* 『大波动被预测成小波动』的直接度量:高波动日里 `F/R` 的中位数、以及 `F` 落在其自身 OOS 最低 40% 的比例(被当成平静日)。

## 3. 经济检验(Sleeve 2019–2026,周一排除;组合 = L1 RV[0.5,1.5] + Sleeve,口径同前)
* **E1 Sleeve 仓位**:实盘 `expo = min(4, 2%/σ₁₄)`。替换为 `min(4, 2%/σ̂)`,`σ̂ = √(F/100)·κ_t`,`κ_t = √(mean₂₅₂(r_cc²)/mean₂₅₂(F/100))`(因果,把日内振幅尺度换成收盘到收盘尺度)。Sleeve 日收益对当日 expo 线性(股数∝expo,成本∝股数),所以 `R_new = R_base × expo_new/expo_base`;**尾部止损仍用 σ₁₄**(交易逻辑不变,只改仓位)。对 FFA-P、FFA-C、FFA-SD、FFA-MAX、6 个基准各一次 = 10 个配置(族)。
* **E2 避开低波日**:F 的因果排名 ≤20% → 当天 Sleeve 不交易;另一版用 `F/σ₁₄²`(相对平静)。各模型 + 神谕(真实 R)。描述性,不入族。
* **E3 论文的波动择时(QQQ B&H 层)**:`w = min(1.5, c/√F̂_cc)`,`c` = 此前 252 日 `√F̂_cc` 中位数(平均权重 ≈1),成本每边 2bp;与 RV21 版 `RV[0.5,1.5]` 与静态比较(2004-06 起,块自助 ΔSR)。
* 全部配置报**分布面板**(均值/中位数、Sharpe、Sortino、CAGR、MDD、Calmar、偏度、峰度、CVaR5%、盈亏比、前 5% 日利润占比、最差日)与『高位移日(事后 dn 最高 20%)的平均 expo 与 Sleeve 收益』。
* **判定**:E1 某配置组合 ΔSR dev(2019–22)/test(2023–26)同号为正、全期 ≥0.15、置换族内 p<0.05,且 CVaR/MDD 不劣化 ⇒ 有证据。统计部分『FFA 在 QQQ 上 MAE/QLIKE 显著优于基准』单独判定(DM p<0.05)。

## 4. 先验
* 统计:FFA-P 在 MAE 上赢 GARCH/CARR 类、与 HAR 接近;高波动态 RMSE 输;FFA-C ≈ FFA-P(都是 log-EWMA);FFA-SD 改善高波动态、低波动态略差。
* 经济(E1):σ₁₄ 本身就是一个平滑估计;换模型后 Sleeve 的 expo 差异小,ΔSR ±0.1;FFA 在平静期给更高杠杆(到 4× 上限)→ 均值略升、尾部变厚。E2:由前轮神谕结果(低 RV 日 Sleeve 反而赚),**预计『避开低波日』为负**。

## 结果(2026-10-12;`ffa_vol_study.py`,日志 `studies/outputs/full/intraday/ffa_log.txt`,表 `ffa_{stat,e1_sizing,e2_skip,e3_timing,panel}.csv`;事后稳健性 `ffa_skip_posthoc.py` → `ffa_skip_posthoc.csv`)

DM(相对 FFA-P,正 = FFA-P 更好):绝对误差 t = +2.3 ~ +8.7(**全部显著**);平方误差 +1.2 ~ +2.8;**QLIKE −0.2 ~ −7.4(FFA-P 显著更差,CARR −6.7、成分 CARR −6.8)**。h=5、22 同一格局:FFA-P 的 MAE 仍最低(h=22:0.0088 vs 次优 0.0098),QLIKE 最差(1.23 vs CARR 0.76)。
* **论文的 MAE 优势在 QQQ 上复现**(低波态 MAE 0.0018,是其余模型的 40%~60%)。
* **但原因不是『滤得更准』,而是水平偏低**:论文的修正因子 Ĉ 是平滑值的比值,不修正对数变换的 Jensen 偏差,预测 ≈ 几何均值 ≈ 右偏分布的中位数——中位数天然最小化 MAE。加上 Jensen 修正(FFA-C),MAE 优势消失(0.0086,与 HAR/RealGARCH 同档),QLIKE 从 0.495 改善到 0.419。FFA-P 在高波日只预测出实际的 54%,QLIKE 在高波态最差(1.21)。
* 用户担心的『大波动被预测成小波动』:**排序上并不比基准更严重**(高波日落在预测最低 40% 的比例 7.3%,基准 6.4%~9.6%),问题主要在**水平**(低估一半)。
* **缺陷修复**:FFA-SD(冲击时放松平滑)把高波态 QLIKE 从 0.790 降到 0.763,幅度很小;FFA-MAX 降到 0.693 但低波态 MAE 变差。结构上的结论:对 h=1,一阶差分惩罚的端点就是对数 EWMA,『放松惩罚』只是在调 EWMA 的衰减,改不了本质。

### 2) E1 Sleeve 仓位:替换 σ₁₄(2019–2026,周一排除;族 10 个)
全部 |ΔSR| < 0.15。FFA 系:Sleeve ΔSR −0.03 ~ −0.08,组合 −0.04 ~ −0.05;最好 Spline-CARR +0.043 / 组合 +0.001,HAR +0.032 / −0.008;族内 p ≥ 0.29。
**机制正是用户的猜测**:FFA 在高位移日(事后 dn 最高 20%)给的仓位只有基线的 **0.93×**,在低位移日给 **1.12×**;高位移日 Sleeve 均值 76.0 → 71.3bp。分布面板:FFA-P 把 Sleeve 均值 6.02 → 5.18bp、偏度 2.43 → 1.78、峰度 15.5 → 9.5——**削掉的是凸性**。所有更『准』的预测都有同样效果(基准的高位移日仓位 0.88~0.93×):**σ₁₄ 的『慢』是 Sleeve 的特性**——冲击刚来时它不降仓。

### 判定
1. **统计**:FFA 的 MAE 优势在 QQQ 复现,但来自『预测偏低(中位数)』;Jensen 修正后与基准同档;QLIKE 显著劣于 CARR 类。**FFA 不是更好的波动预测器,是不同损失函数下的不同偏好。**
2. **Sleeve 仓位(E1)**:无证据,且方向为负——任何更快、更准的预测都会在大位移日降仓,削掉 Sleeve 的凸性。
3. **避开低振幅日(E2)**:**线索**(Sleeve +0.17~+0.25,dev/test 同号,组合 +0.04~+0.06 不显著,事后族内 p 0.078~0.34)。
4. **QQQ 择时(E3)**:无增量。
