## 1. 精确规则(冻结)
### A. FOMC 日
* 触发日 = FOMC 计划内决议日(会议第二天,14:00 ET 公告),来源 `studies/event_calendar.py:FOMC_DECISION`(已含到 2026-12);每年初用 federalreserve.gov 的日历核对一次。
* 该日的噪声带检查时点**只保留 ≥14:30 的**(实盘相位下即 14:30、15:00 两个;其余时点不开仓)。已开仓位的止损/平仓逻辑**不变**。非 FOMC 日完全不变。
* 临时/非计划会议**不触发**(2020-03 那类紧急会议按普通日处理,因为事前不可知)。

### B. CPI 回补 overlay(0.5× 名义)
* 触发日 = 美国 CPI 发布日(8:30 ET)。需要三个数:整体 CPI y/y 的**实际**与**共识**、核心 CPI y/y 的实际与共识。
* `s = sign(实际−共识)_整体 + sign(实际−共识)_核心`;`s>0`(热)→ **开盘买入 QQQ**;`s<0`(冷)→ **开盘卖空 QQQ**;`s=0` 不交易。
* 名义 = 0.5 × 资本;**开盘(09:30)市价入场,收盘(16:00)MOC 平仓**;不设止损(与回测一致)。
* **周一不交易**(与 Sleeve 的 `skip_dows=(0,)` 一致;历史上 CPI 从未在周一发布,这是结构性约束)。
* 与 Sleeve 的日内仓位**各自独立计算买力**;overlay 与当日 Sleeve 收益相关仅 0.09。
* **数据缺口(必须先解决)**:回测用的是公开 GitHub 经济日历(只到 2025-12)。实盘需要一个**实时共识来源**(券商日历 / Investing / Trading Economics)。若 8:30 拿不到可信共识 → **当天不交易**,并在日志记 `skipped_no_consensus`。

### C. 影子信号(只记录)
每日记录 FFA-P 对当日 Parkinson 振幅的预测与其过去 504 日的因果分位 `rank`;标记 `rank≤0.2` 与 `rank≤0.3`。**不据此跳过交易**,只在复盘时对比『若跳过』的假设收益。

### D. B&H 腿
`w = clip(0.5 + 1.0×(1 − p_RV21), 0.5, 1.5) × (1 if 收盘 ≥ SMA200 else 0.5)`,`p_RV21` = 21 日已实现波动在过去 504 日的因果百分位;信号用 t 日收盘,t+1 生效;换手成本按实际;年换手约 10 次。平均权重 0.93,**最高 1.5 需要杠杆**,上线前确认买力:QQQ 1.5× + Sleeve(TQQQ,min(4,2%/σ) 的 1/3 名义)同时持仓的最坏买力占用。

## 3. 前向判定(冻结;最早在 **12 个月 / 约 9 个 CPI 事件 + 8 个 FOMC 日** 之后才评估,样本不足时只报不判)
* **A(FOMC)**:前向 FOMC 日的 Sleeve 日均收益 ≥ 同期非事件日日均的 70%,且与历史『公告后入场更好』方向一致 ⇒ 保留;若前向 FOMC 日仍系统性亏钱(日均 < −10bp 且 ≥6 个事件)⇒ 退回不入场或关闭该规则。
* **B(CPI)**:前向每笔均值 > 0 且 ≥ 历史点估计的 1/3(即 ≥ +9bp/笔)⇒ 保留,可考虑升到 1×;若前向每笔均值 < 0 ⇒ **关闭**(不做『再观察一年』的延期)。
* **C(影子)**:若影子跳过在前向 12 个月同时满足『Sleeve 假设收益更高』与『q=0.2 与 q=0.3 同向』⇒ 才进入正式预注册检验;否则永久归档。
* **D(SMA200)**:只在前向出现 ≥15% 的 QQQ 回撤时才有判定意义;期间按 MDD 改善评估,不以 Sharpe 判。
* 任何组件触发否决后,**不得换参数重试**;要重做必须新开一轮预注册并累计配置数。

## 4. 已知风险与局限(写在前面)
1. **A、B、C、E 都是在 2019–2026 这段数据上事后挑出的**,dev/test 只是时间切分,不是样本外;tearsheet v2 里 ①/② 相对现用组合的 Sharpe +0.24/+0.29 **区间含 0**,前向期望应按点估计的一半来规划。
2. CPI overlay 的收益集中:62 笔中去掉最好 3 笔后每笔从 +26.9bp 降到 +10.8bp;单笔最差 −270bp。0.5× 名义下最差单笔约 −135bp。
3. 组合层最大回撤**没有改善**(−19.7% → −21.8%,① 为 −16.1% 是 SMA200 的贡献而非新 Sleeve);新 Sleeve 自身回撤 −11.6% → −8.9%。
4. 收益右偏厚尾(新 Sleeve 偏度 2.86、超额峰度 22.6),Sharpe 低估尾部;以 Sortino/Calmar/CVaR 并列判读。
5. CPI 共识数据的『首次公布 vs 修订』差异、以及第三方抓取的共识可能有错,会直接改变 overlay 方向。
6. 利息未计入:QQQ 权重 >1 的融资成本会使全期 Sharpe 低约 0.1(`sota_bh_leg.csv` 的含利息口径)。
