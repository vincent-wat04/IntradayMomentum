# PROPOSAL — 日内 32 个经典技术指标(东北证券《量化择时系列一》)在 QQQ 5/15 分钟 K 线上的检验

状态:**预注册(执行前冻结)**。脚本 `studies/tech_indicators.py`(指标)、`studies/intraday_tech_study.py`(回测+安慰剂+自检)。
属于 L3 层(日内),不删改任何旧文件。与 `PROPOSAL_intraday_reversion_v2.md`(特征+ML)互补:这里是用户点名的「MACD 之类经典指标,原样默认参数」。

## 0. 用户意图 → 定义
东北研报在**日线**上测了 32 个指标(趋势 8 / 动量 11 / 波动 7 / 成交量 6),默认参数、纯多头、万3 手续费,并看参数高原、样本外、牛熊震荡。
用户要的是:**把同样的检验搬到日内**,看 MACD 等在 QQQ 的日内 K 线上是否有可交易的信号。

## 1. 数据与构造(冻结)
* `raw/min1/QQQ.csv` 1 分钟 → 完整交易日(390 根;半日市排除;1933 天,2019-01 ~ 2026-10,无缺失分钟)→ 重采样 **5 分钟(78 根)** 与 **15 分钟(26 根)**:开=首根开、收=末根收、高低=极值、量=求和、额≈量×收。
* 指标在**跨日连续**的 bar 序列上计算(与研报在连续日线上的做法同构;隔夜缺口会进入指标,这是真实使用者会遇到的情形)。**持仓/通道状态机在每个交易日开盘重置为空仓**。
* 首次决策:10:00 bar 收盘(之后每根 bar 收盘决策);**下一根 bar 的开盘价成交**;每根 bar 的收益 = 该 bar 开到下一 bar 开(最后一根 = 开到收盘价,MOC 强平)。**不跨日**。
* 成本:每边 {0.25, 0.5, 1, 2} bp(**主结果 1bp/边**,与 intraday_reversion_v2 一致);成本 = 每边 × |Δ仓位|,开盘空仓起算,收盘强平计入。

## 3. 模式与检验族(冻结)
每个指标 × {5 分钟, 15 分钟} × 模式 {LO 纯多(s=+1 持多)、LO_inv(s=−1 持多)、LS 多空、LS_inv 反向多空} = 32×2×4 = **256 个配置**。
LO 是研报口径;`_inv` 版本回答「指标是否反着用才有用」(日内回转 vs 趋势)。**族 = 全部 256 个**(族内 max 统计量)。

## 4. 统计与判定(冻结)
* 每个配置:日均笔数(开仓次数)、日均毛收益 bp、净收益 bp、净 Sharpe(1bp)、盈亏平衡成本(bp/边)、dev(2019–22)/test(2023–26)。
* **安慰剂**:把持仓矩阵(天×bar)与收益矩阵整天循环错位 s 天(s∈[5, D−5],1000 次随机),换持仓=保留杠杆、时间结构、换手率、日内时段结构,仅破坏与当天收益的对应;成本不变。族内 max(净 Sharpe@1bp)得到 p。LO 的漂移优势因此被安慰剂吸收(错位后的多头同样吃到漂移)。
* 自检:(a) 污染某天 k 之后的所有 bar → 全部 32 个指标在 ≤k 的信号逐位不变;(b) 阳性对照:故意用下一根 bar 收盘的『泄漏 MACD』必须被同一检验判为失败(即信号变化)。
* **有证据 ⇔** 同时:(i) dev 与 test 的净 Sharpe@1bp 同为正;(ii) 盈亏平衡成本 ≥ 2bp/边;(iii) 族内安慰剂 p<0.05;(iv) 5/15 分钟或相邻模式同向(不是孤点)。否则「没有足够证据」。
* 单个指标漂亮的毛 Sharpe **不构成**证据(旧记录:IC 4% 仍亏钱;毛 alpha 封顶 ~1.5bp/笔)。

## 5. 先验(写在前面)
* 5 分钟 + 每根 bar 都可换仓 ⇒ MACD/SMA 类每天交易 5~15 次,1bp/边下成本 ≈ 10~30bp/天,而 QQQ 日内毛 alpha ≤ 几 bp。**预计 LO/LS 的净 Sharpe 绝大多数为负,无一通过(≥90%)**。
* 可能的例外:`_inv`(回转)或 MAAMT/成交额类,以及 15 分钟、换手低的通道突破;若出现,也要过安慰剂。
* 文献一致性:日内动量主要存在于「首半小时→末半小时」(Gao et al.),已在 v2 第二轮检验并消失,这里不重复。

## 结果(2026-10-11;`intraday_tech_study.py`;日志 `studies/outputs/full/intraday/intraday_tech_log.txt`;表 `outputs/tables/intraday_tech.csv`)
**自检**:未来污染(5/15 分钟,污染某日中间 bar 之后全部 bar)→ 32 个指标在 ≤K 的信号**逐位不变**(0 处差异),K 之后 32/32 有变化(污染有效);阳性对照(偷看未来 20 根的 MACD)被检出(2/1 处变化)。
(备注:第一版阳性对照只偷看 1 根,理论上只能影响 t=K 一个点,功效不足 → 改成 20 根,见偏离记录。)

**判定:没有足够证据。256 个配置 PASS = 0。**
* 净 Sharpe@1bp/边 > 0 的配置只有 13/256;dev 与 test 同时为正的 2 个;盈亏平衡成本 ≥2bp 的 1 个;族内安慰剂 p 最小 **0.42**(15 分钟 Donchian LO)。族内 max 安慰剂 Sharpe 的 95% 分位 = 0.74(随机错位的持仓族也能「最好」做到 0.74),所以单个净 Sharpe 0.3~0.4 完全在噪声之内。
* **成本结构**:5 分钟线每天往返 3~8 次(MACD LO 3.1 次/天,LS 6.2 次/天),LO 的毛收益中位数 1.6bp/天 vs 成本 8.5bp/天 ⇒ 净 Sharpe 中位数 −1.5(LO)、−2.1(LS);盈亏平衡成本中位数仅 0.19bp/边。15 分钟线好一些(中位 LO 净 Sharpe −0.28)但仍为负。
* **MACD(用户点名)**:5 分钟 LO 净 SR@1bp **−1.25**(毛 +0.13);LS −2.12;15 分钟 LO 毛 SR 0.59、净 **+0.06**(dev +0.23 / test −0.17),LS −0.29。反向(LO_inv/LS_inv)同样为负。
* **毛信号并非全空**:15 分钟的趋势/通道类(DC、TRIX、DPO、AROON、EMA)LO 毛 Sharpe 0.7~0.8,**但几乎全部来自 dev(2019–22)**:例如 TRIX 毛 5.3bp/天(dev) → 1.3bp/天(test);DC 4.9 → 0.3bp/天。对照:QQQ 10:00→收盘买入持有毛 +2.34bp/天(SR 0.36;dev 1.12、test 3.65)——LO 类信号 test 期 *不如* 单纯持有。也就是说 dev 的『日内趋势』既不稳健(test 消失),又被漂移基准吸收(安慰剂 p_single 虽 0.02~0.05,族内校正后 0.4~0.8)。
* 分类(趋势/动量/波动/成交量)之间没有一致的好类;MAAMT(无方向,成交量扩张)LO 与持有无差别。

**对用户问题的回答**:在 QQQ 5/15 分钟 K 线上,32 个经典指标(默认参数,纯多/多空/反向)**没有一个**扣除 1bp/边成本后同时通过 dev/test、盈亏平衡与族内安慰剂。结论与旧记录(`PART8` §4、`PROPOSAL_intraday_reversion_v2`)一致:日内毛 alpha 只有 ~1~3bp/天,而这些指标的换手让成本高出 3~10 倍。

3. 指标规则用 TA-Lib 默认值与最标准状态(见 §2 声明);没有看数据后调参。研报里可能存在的不同规则/参数没有被测,这是限制。
