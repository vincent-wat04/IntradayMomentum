# PROPOSAL — A+B+E 波动模型(OOS R² 0.749)能不能变现?

状态:**预注册(执行前冻结)**。脚本 `studies/vol_monetization_study.py`。延续 `PROPOSAL_lowvol_avoidance.md` 的目标(`y_rv` = 10:00→收盘的 log 已实现方差)与 walk-forward(2021–2026 OOS)。
用户问题(2026-10-12):『R² 0.749 看起来不错,我们还是没法 monetize 吗?』

## 0. 先弄清 R² 0.749 里装了什么(不是变现,是解释为什么不容易)
log RV 的 R² 高,主要来自**波动的持续性**(VIX(t−1)、前日 RV),不是『别人不知道的信息』。变现需要的是**相对于已被定价/已被策略使用的那部分**的增量。第一部分把 R² 拆开:
| 模型(ridge,同 walk-forward) | 特征 |
|---|---|
| const | 仅训练期均值 |
| VIX | log VIX(t−1) |
| VIXall | log VIX、VIX9D、VXN(t−1) |
| HAR | log σ14、log RV(t−1)、5 日均 RV |
| B30 | 首 30 分钟 RV(b_log_rv30) |
| A | 既有 A 组(含 VIX、σ14、GEX、gap…) |
| A+B | + B 组(10:00 之前的盘中特征) |
| A+B+E | + 事件日历(FOMC/NFP/OPEX…) |
报:OOS R²(月聚类自助 95%)、AUC(低波标签)、对 VIXall 的 ΔR²。**没有新配置选择**(都是描述性的分解)。

## 1. 变现渠道与检验(冻结,3 条;累计新增配置 = 3 条渠道下的具体变体,见下)
**M1 Sleeve 日级缩放 + 神谕上界。** 已在 lowvol 三轮做过(skip 20%/30%、连续 0.5/1.0,50 个配置,族内最小 p 0.082,邻近格失败)。这里新增一个**神谕对照**:把预测换成真实 `y_rv`(完美预报),用同样的因果缩放规则(skip20%、skip30%、连续 0.5/1.0)。
 * 目的:界定上界。若神谕的 Sleeve ΔSR 也很小 → 『日内波动大小』不是 Sleeve 的主要杠杆,R² 再高也无法变现;若神谕很大而模型很小 → 缺的是『排序精度』而不是『水平精度』。
 * 评价同 lowvol 第三轮:OOS 2021–2026、周一排除、Sleeve ΔSR 与组合 ΔSR(L1 RV[0.5,1.5]+Sleeve 口径)。
**M2 L1 权重:用预测替代 RV21。** 目标 = 当日**全日**log RV(t)(不是 10:00 后);特征只用 **t−1 收盘前**已知的(σ14、VIX/VXN/VIX9D(t−1)、GEX(t−1)、前日 RV、5 日 RV、星期、事件日历);同样的 walk-forward(2021–2026)。
 * 权重 `w = 0.5 + 1.0·(1 − p)`,`p` = 预测的 504 日因果百分位(与 RV21 版 `RV[0.5,1.5]` 同构,`T.weights` 口径,shift 1)。
 * 比较:『预测版 L1』vs『RV21 版 L1』vs 静态;报 ΔSR 相对同平均暴露静态对照(`boot_dsr`,块 40)以及两版之差的区间;圆周平移置换(族内 = 2 个权重版本)。
 * 判定同 L1 既有规则:|ΔSR|<0.15 噪声;区间含 0 不写『有证据』;预测版相对 RV21 版的增量需 dev/test 同号。
**M3 与隐含波动对赌的代理(隐含=VIX1D,2022-05 起)。** 无历史期权价格,只能做**计量代理**,不是可交易回测:
 * `iv_t = (VIX1D(t−1)/100)²/252`(次日隐含日方差);`rv_t` = 当日 session 已实现方差(1 分钟收益平方和)。
 * (a)回归 `log rv − log iv` 对 `预测 − log iv`(M2 的预测,2022-05 起 OOS),斜率 b 与月聚类自助区间:b≈1 → 预测胜过隐含;b≈0 → 隐含已包含全部信息。
 * (b)方差互换代理 P&L:`pos_t = sign(f̂_t − log iv_t − c_t)`,`c_t` = 此前的 (log rv − log iv) 均值(因果的风险溢价调整),`P&L_t = pos_t·(rv_t − iv_t)/iv_t`;报 Sharpe、胜率、尾部。**无买卖价差/保证金成本**,所以只是上界;若上界不显著,期权渠道直接排除;若显著,需要期权数据(optrec 在积累)才能判断。
累计新增:M1 神谕 4 个、M2 2 个、M3 1 个 ⇒ 7 个配置(不并入旧族,单独报)。

## 结果(2026-10-12;`vol_monetization_study.py`、`vol_monet_m1b.py`;日志 `studies/outputs/full/intraday/vol_monet_log.txt`、`vol_monet_m1b_log.txt`;表 `vol_monet_{decomp,m1,m2,m1b}.csv`)
**自检(M2)**:第 i 天全部 bar ×7 → F0 在第 i 天的特征最大差 0;阳性对照(gap_abs/b_ret30)最大差 1.95 → PASS。

### 1) R² 拆解(OOS 2021–2026,1443 天)—— 0.725 里装了什么
| 模型 | R²(log RV)[95%] | 对 VIXall 的 ΔR² |
|---|---|---|
| VIX(t−1) | 0.408 [0.31,0.49] | −0.153 |
| VIXall(VIX+VIX9D+VXN) | **0.561** [0.49,0.62] | — |
| HAR(σ14+RV(t−1)+5 日 RV) | 0.603 | +0.042 |
| B30(仅首 30 分钟 RV) | 0.609 | +0.048 |
| VIXall + B30 | 0.680 | +0.119 |
| A | 0.634 | +0.073 |
| A+B | 0.699 | +0.139 |
| A+B+E | **0.725** [0.67,0.77] | **+0.164** [0.13,0.20] |
即 **77% 的 R² 来自隐含波动(VIXall);相对隐含波动的真正增量是 +0.16**(其中首 30 分钟 RV 约 +0.12,事件日历约 +0.03)。低波标签的 AUC 一直只有 0.63~0.65,**加了 B/E 反而略降**(0.649 → 0.633)——水平精度提高了,排序精度没有。(上一轮新闻研究里的 0.749 是 2021–2023 子样本。)

### M1 Sleeve 缩放:模型 vs 神谕上界(完美预报 `y_rv`)
| 预报 | 规则 | Sleeve ΔSR(全OOS) | 组合 ΔSR(全OOS) | 备注 |
|---|---|---|---|---|
| A+B+E | skip20% / skip30% / cont0.5 / cont1 | −0.32 / −0.36 / −0.19 / −0.26 | −0.18 / −0.20 / −0.09 / −0.12 | 全部为负 |
| A(既有) | skip20% | **+0.31**(dev +0.30 / test +0.31) | +0.10 | 旧线索(族内 p 0.048→0.082);skip30% 邻格 +0.05 |
| **神谕 RV** | skip20% / skip30% / cont0.5 / cont1 | **−0.54 / −0.65 / −0.29 / −0.33** | −0.23 / −0.27 / −0.08 / −0.10 | **完美知道 RV 也变差** |
**含义**:Sleeve 的盈利**不来自『实现波动大』**。按事后 RV 五分位,Sleeve 日均 +14.6 / +1.9 / +0.5 / +8.8 / +11.1bp(不单调,最低分位反而最赚,平滑趋势日 RV 低但位移大)。
**诊断(事后追加,见偏离记录)**:按事后位移 |10:00→收盘| 五分位,Sleeve 日均 **−29.8 / −20.8 / −6.1 / +19.7 / +73.9bp**——Sleeve 赚的是位移(趋势日)。
* 完美知道位移并跳过最低 20%/30%:Sleeve ΔSR **+1.17 / +1.63**,组合 ΔSR +0.57 / +0.78(**上界很大**)。
* 但位移几乎不可预测:`log(disp)` 的 OOS R² 只有 **0.112**(log RV 是 0.72);A+B+E 的 RV 预测与位移的 Spearman 仅 0.37;直接预测位移的模型做 skip20%/30% → Sleeve ΔSR **−0.13 / −0.22**。
**所以 R² 0.75 变现不了,不是模型不够好,而是预测对了错的变量**:波动水平高度可预测(因为持续性),但 Sleeve 需要的是『会不会走出趋势』,这个只能预测 ~11%。

### M2 L1 权重:用全日 RV 预测替代 RV21(2021-12-31 起)
全日 log RV 预测(特征 ≤t−1 收盘)OOS R² 0.692;与 RV21 的相关 0.72。
| 配置 | full ΔSR [95%] | dev(→2023) | test(2024→) | CAGR / MDD(full) |
|---|---|---|---|---|
| 预测版 L1 | +0.044 [−0.24,+0.28] | +0.152 | −0.070 | 13.9% / −31.9% |
| RV21 版 L1 | +0.198 [−0.07,+0.42] | +0.374 | +0.018 | 18.1% / −28.5% |
| 预测版 − RV21 版 | **−0.154** [−0.33,+0.04] | −0.222 [−0.44,−0.07] | −0.088 | |
圆周平移置换 p:预测版 0.20,RV21 版 0.003。**预测更准的版本做权重反而更差**——L1 的价值不是『预报波动』,更像是 RV21 里携带的『近期下跌/杠杆效应』信息;用更干净的波动预测会把这部分丢掉。→ **不可变现**。

### M3 与 VIX1D 对赌(代理,2022-05 起,n=1099)—— **不可信,不下结论**
* 回归斜率 b = 0.741 [0.648, 0.818];方差互换代理 P&L Sharpe **+7.1**、胜率 69%,逐年 4.8~8.9。
* **但是朴素对照同样『赚钱』**:只用『昨日 log RV 对比隐含』的符号,Sharpe **+5.7**(模型只比它多 +1.5);把隔夜缺口方差计入已实现方差后,朴素信号降到 **+1.4**。VIX1D 的日度对数变化自相关 **−0.31**(收盘价带有测量噪声,均值回复),任何第二个波动估计与它相比都会『赢』。
* ⇒ 这个代理主要在度量 **VIX1D 收盘值的噪声与口径(SPX 次日 vs QQQ 当日 session)**,不是模型的 alpha。真实检验需要 QQQ 当日/次日到期期权的**可成交报价与价差**(optrec 在积累)。**期权渠道目前『无法判定』,不是『有』也不是『无』。**

### 判定
M1(i)否:模型版 Sleeve/组合 ΔSR 为负;M2(ii)否:预测版相对 RV21 版为负;M3(iii)不可信。**没有足够证据可变现。**
**可行的变现路径(需要新数据/新目标)**:(a)预测『位移/趋势日』而不是波动水平(R² 仅 0.11,上界 ΔSR +1.2——这是值得投入的目标);(b)用期权实际报价检验隐含 vs 预测(optrec);(c)在 10:00 之后用更多盘中信息更新(B 组之外的路径效率、成交量节奏),对象是 Sleeve 的『持有/平仓』而非『是否入场』。
