# PROPOSAL — 『避开低振幅日』的模型赛马、反向仓位倾斜、Sleeve SOTA 组装、B&H 腿参数(跨周期)

状态:**预注册(执行前冻结)**。脚本 `studies/sota_stack_study.py`。用户 2026-10-12 的五个要求:
1. 『跳过预测振幅最低 20~30% 的日子』只用 FFA 试过吗?→ 用更多方法做赛马,**用 Sleeve 之前的数据(2015–2018)选模型**,避免在 Sleeve 收益上挑模型。
2. 『用 FFA 替换 σ₁₄ 定仓位肯定不对』→ 用户的意思是:σ₁₄ 负责『平稳期放大仓位』,预测模型应当**反方向**作用——预测振幅越大,在 σ₁₄ 仓位之上再加仓。本篇按这个定义检验(上一轮做的是替换,确实不是这个问题)。
3. 把『FOMC 推迟到 14:30』『CPI 缺口回补 1×』『跳过赛马胜出模型预测的最低振幅日』加到 Sleeve 上,得到 SOTA 版本。
4. 详细测试 QQQ 波动择时。
5. B&H 腿选什么参数、要不要价格趋势:跨多周期报告,以及 2019 年后叠加 SOTA Sleeve 的表现。

## A. 『避开低振幅日』模型赛马
* 目标:当日 Parkinson 振幅 `R_t`(Yahoo 日 OHLC,同 `PROPOSAL_ffa_vol.md`)。
* **候选(全部在 2005 年起有 OOS 预测)**:FFA-P、FFA-C、FFA-SD、FFA-MAX、EWMA、HAR、CARR、成分 CARR、Spline-CARR、RealGARCH(复用 `ffa_forecasts.pkl`);**COMB** = 前 9 个(不含 FFA-MAX)预测的几何平均;**ML-盘前** = 岭回归(逐年扩展窗口,α=1,标准化),特征 `ln R_{t−1}, ln R̄⁵, ln R̄²², ln VIX_{t−1}, Δln VIX_{t−1}, |r_{t−1}|, 1[r_{t−1}<0], 星期`;**ML-开盘** = ML-盘前 + `|开盘缺口|`(开盘时已知;Sleeve 10:00 才首次决策)。目标 `ln R_t`,预测取 `exp(ŷ)·mean(exp(残差))`。共 13 个。
* **补充候选(不参与选择)**:**ML-10:00** = ML-开盘 + 首 30 分钟 Parkinson 振幅与首 30 分钟相对成交量(分钟线只有 2019+,逐年训练,OOS 2020+)。
* **选择(冻结)**:2015-01 ~ 2018-12(Sleeve 之前)的 AUC,标签 `low_t = 1[R_t ≤ 过去 504 日 R 的 20% 分位]`,分数 = −F_t。AUC 最高者为胜者;并列(差 <0.005)时取 QLIKE 低者。
* **跳过规则**:`rank_t` = 过去 504 个交易日的**自身预测**中小于 F_t 的比例;`rank_t ≤ q` → 当日 Sleeve 不交易。q ∈ {0.1, 0.2, 0.3}。**SOTA 用的 q 在 dev(2019–22)上选**,test(2023–26)报告。
* 经济评价:全部 13 个候选 × 3 个 q 的 Sleeve ΔSR(dev/test/全)、组合 ΔSR;置换(2019+ 周二至周五内置换跳过掩码,1000 次)族内 max(39 个)。

## B. 反向仓位倾斜(σ₁₄ 仓位之上)
`expo = min(4, expo_σ₁₄ × g_t)`,`g_t = a + b·rank_t`:强(a=0.5,b=1.0)、温和(a=0.75,b=0.5);`rank_t` 用 F_t(绝对)或 `F_t/σ₁₄²`(相对于 σ₁₄ 已包含的波动)。模型 = 赛马胜者与 FFA-P。2 × 2 × 2 = 8 个配置;置换 = 倾斜序列的圆周平移(≥60 日)族内 max。

## C. Sleeve SOTA 组装(2019–2026;按顺序叠加)
S0 实盘 → S1 = S0 + FOMC 日只在 ≥14:30 检查点开仓 → S2 = S1 + 跳过(胜者、dev 选的 q;与 FOMC 规则冲突时取『跳过』)→ **S3(SOTA)= S2 + CPI 缺口回补 1×**(CPI 高于预期开盘买入、低于预期开盘卖空,收盘平仓,扣 2bp 往返;CPI 数据只到 2025-12,所以 2026 没有 overlay)。另报 S3 的 0.5× 版本与『B 部分最好的倾斜』叠加版(仅描述)。
**诚实声明**:FOMC 推迟与 CPI 回补是在 2019–2025 的数据上事后挑出的,所以 S1/S3 的提升是**样本内**;只有 S2 的模型选择是样本外(用 2015–2018 选),q 在 dev 选、test 检验。

## D. B&H 腿(QQQ,2bp/边)
* 权重 = 仓位规则 × 趋势规则(同 `trend_rv_sleeve_study.weights`)。
  * 仓位:静态 1;RV21 百分位线性 [0.5,1.5]、[0,1]、[0,1.5]、[0,2];**波动择时** `w = min(cap, c/√F̂)`(c = 此前 252 日 √F̂ 中位数),F̂ ∈ {赛马胜者、FFA-SD、HAR、成分 CARR},cap ∈ {1.5, 2.0}。
  * 趋势:无;SMA200(e=0.5 / 0);MOM252(e=0.5 / 0);信用 A2_C(e=0.5,第二轮的暴露)。
* 两种口径:**原口径**(与旧记录一致,忽略利息);**含利息口径**(超额收益 = w·(r − r_f),r_f = ^IRX;w>1 付融资,w<1 现金得息)。
* 周期:2004-06 ~ 2026-10(全),2004-06 ~ 2009,2010 ~ 2018,2019 ~ 2026,2015 ~ 2026;熊市窗口 GFC、2018Q4、COVID、2022。指标:平均权重、Sharpe(两种口径)、CAGR、波动、MDD、Calmar、Sortino、年换手、相对同平均暴露静态的 ΔSR(块自助 L=40)。全期族内圆周平移置换 p(全部配置)。
* **2019+ 叠加 Sleeve**:每个 B&H 配置 × {无 Sleeve, 实盘 Sleeve, SOTA Sleeve},报 Sharpe/CAGR/MDD/Calmar/Sortino、dev/test。

### A. 『避开低振幅日』模型赛马(13 个候选 + ML-10:00)
**识别力(AUC,低振幅 = 振幅 ≤ 过去 504 日 20% 分位)**:选择期 2015–18 / 2019–26:ML-开盘 **0.822 / 0.801**、ML-盘前 0.820 / 0.797、CARR 0.805 / 0.764、FFA-MAX 0.803 / 0.783、FFA-C 0.798 / 0.779、COMB 0.795 / 0.779、FFA-SD 0.795 / 0.779、FFA-P 0.790 / 0.771、EWMA 0.790 / 0.762、RealGARCH 0.776、成分 CARR 0.771、Spline-CARR 0.726、HAR 0.705 / 0.759;ML-10:00(不参与选择)— / **0.858**。→ 预注册胜者 **ML-开盘**(VIX、前日振幅、多尺度均值、开盘缺口的岭回归)。
**经济效果(Sleeve 2019–2026)**:39 个(13×3 个 q)中族内 p 最小 0.196;
* **q=0.2 普遍 dev/test 同正**:FFA-P +0.251/+0.208、ML-开盘 +0.133/+0.209、ML-盘前 +0.144/+0.183、RealGARCH +0.274/+0.116、FFA-C +0.337/+0.081、FFA-SD +0.219/+0.111、COMB +0.295/+0.066;组合层 +0.02 ~ +0.06。

* **预注册规则(q 在 dev 选)选中 q=0.3 → test 失败**(Sleeve test −0.146;2023 +23.1%→+12.9%,2024 +33.4%→+11.4%)。

判定:**无证据**(族内 p ≥0.196;预注册的 q 选择 test 失败)。q=0.2 的普遍正值是**线索**(事后)。
