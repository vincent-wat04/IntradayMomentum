# 预注册：规避极高 GEX 日是否有 edge

**本文件在跑任何结果之前写完。** 之后的实验只允许执行这里写明的内容；
任何偏离都必须在文末「偏离记录」里写清楚，并说明为什么不是事后找理由。

---

## 1. 假设与机制

**H1**：在净 gamma 极度为正的日子，做市商为维持 delta 中性必须「涨了卖、跌了买」，
这种逆势对冲压制日内趋势延续，使**突破型（动量）策略**的突破更容易失败。
因此剔除这些日子应当改善风险调整后收益。

机制链条（四步，每步都可独立质疑）：

1. 做市商净多 gamma（机构备兑开仓卖 call、对冲需求卖 put 的镜像）
2. 为维持 delta 中性 → 价格上涨时卖出、下跌时买入
3. 这股流量与价格运动反向 → 日内趋势被削弱、波动被压制
4. 噪声区间策略靠「突破后延续」赚钱 → 这类日子应当赚得更少

## 2. 为什么之前 8 次 GEX 实验没有回答这个问题

| 已做过 | 结果 | 与本假设的区别 |
|---|---|---|
| 分位数做**仓位连续缩放** | p=0.092 | 连续缩放 ≠ 极值日硬性剔除；连续缩放会被中间区间的噪声稀释掉尾部信号 |
| 原始值做仓位缩放 | p=0.15~0.29 | 同上 |
| 过滤**假突破**（止损率）| z=+0.08 | 只看止损率这一个指标，没看整体收益；也没做极值阈值 |
| GEX 条件化的**反转** | 全负 | 反转方向，不是「不交易」 |
| 实时 gamma（期权链） | 前视上界 +0.06~+0.13 | 数据粒度问题，与阈值设计无关 |
| GEX → **波动率预测** → 仓位 | dev +0.166 / test −0.100 | 预测的是幅度而非方向性延续 |
| GEX 条件化**止盈** | 方向相反（高 GEX 最差）| 止盈，不是停止交易 |
| GEX **wall** | 数据只有标量，无法构造 | — |

**真正没测过的点**：把「极高 GEX」当成一个**二元的不交易开关**。
这与连续缩放在统计上不同——如果效应只存在于分布的极端尾部，
连续缩放会被中间 80% 的噪声淹没。所以这是一个合法的、未被回答的问题。

**但先把先验摆明**：8 次全否，唯一复现成功的（GEX 预测波动幅度）也换不成收益。
所以我对 H1 的先验成功概率**低**。把这句写在前面，是为了防止自己事后去抢救一个零结果。

## 3. 数据与口径（不可变更）

* GEX 来源 `etf_timing/data/raw/squeeze_dix_gex.parquet`（SqueezeMetrics，SPX 口径，每日标量）
* **滞后固定 t−1**。理由有两条：
  (a) 该数据盘后发布，t−1 是合法最小滞后；
  (b) 之前发现滞后形状**非单调**（t−0/−1/−2/−3 的系数来回跳），
      说明「挑一个最好的滞后」等于在 5 个里选最优 —— 本实验**禁止**挑滞后。
* 基线策略 = 当前实盘配置：多空、band 止损、硬尾 k=0.5 逐 bar、voltarget 4x、
  reentry=hold、排除周一。30 个相位均值、TQQQ 单股成本。
* 分期：dev 2019-2022 / test 2023-2026，另报全样本。

## 4. 预先指定的参数（禁止扫描以外的取值）

* **阈值**：GEX 的 **dev 期**分位数 80% / 90% / 95%，共 3 个，**全部报告**。
  阈值只在 dev 上估计，再套到 test —— 否则就泄漏了样本外信息。
* **镜像对照**：同样剔除 GEX **最低** 20% / 10% / 5% 的日子。
* 不做阈值精调、不做其他分位、不换 GEX 变换（如 log、z-score、变化率）。

## 5. 三个可falsify的预测

按「离机制的远近」排序，越靠前越直接：

* **P1（交易层，最直接）** 高 GEX 日的逐笔表现应当更差：
  逐笔均值更低、止损率更高、入场后的最大有利偏离（MFE）更小。
  **dev 和 test 必须同号**。
* **P2（单调性）** 阈值越极端，效应越强（80% → 90% → 95% 递增）。
  非单调就说明是噪声形状，不是尾部机制。
* **P3（策略层）** 剔除这些日子后的**叠加贡献** ΔSharpe，
  必须超过「随机剔除同样多天数」所能达到的水平。

## 6. 对照（这是整个设计的重心）

* **C1 随机剔除安慰剂（主对照）**：剔除**同样天数**的随机日子，200 个随机种子，
  得到 ΔSharpe 的零分布。真实效应必须显著高于这个分布。
  理由：剔除任何日子都会改变敞口与波动，而「少交易」本身在本项目里
  反复被证明能抬高独立 Sharpe（止盈那一轮就是被这个对照否掉的）。
* **C2 镜像对照**：如果剔除**低** GEX 日也有同等好处，那就不是 GEX 在起作用，
  而是「剔除极端波动日」这种一般性效应。
* **C3 敞口记账**：报告实际交易天数，让读者看到removed多少敞口。

## 7. 主指标与护栏

* **主指标**：作为 QQQ B&H 叠加层的 ΔSharpe（test 期）。
  **不用独立 Sharpe 做决策** —— 已反复证明它偏向「削弱空头腿/减少交易」的改动
  （`corr(β, 叠加贡献) = −0.905`）。
* 辅助：α、α 的 HAC t 值、alpha Sharpe、β、独立 Sharpe。
* 显著性：配对区块自助（区块 10 天、4000 次）。
* **噪声护栏**：随机日子集的 ΔSharpe 标准差为 0.15~0.80，
  所以 **|ΔSharpe| < 0.15 一律按噪声处理**，不管 p 值多好看。

## 8. 预先承诺的决定规则

**只有以下四条全部成立才采纳**：

* (a) P1 成立：交易层退化在 dev 与 test **同号**
* (b) P2 成立：3 个阈值上**单调**
* (c) test 叠加 ΔSharpe **> 0.15**，且**高于 C1 随机剔除零分布的 90 分位**
* (d) C2 镜像对照**没有**拿到可比的好处

任何一条不成立 → **否决**，并把它记成 GEX 的第 9 次失败，不再尝试变体。

## 9. 这个设计想教的四件事

1. **先写死规则再看数据。** 阈值、滞后、指标、决定规则全部预先固定。
   做完才定标准，等于保证自己能找到"结果"。
2. **机制检验优先于策略检验。** P1 不依赖任何策略实现。
   如果机制在交易层根本看不见，那策略层的"赢"几乎必然是噪声。
3. **对照要匹配你无意中改变的东西。** 这里剔除日子 → 改变了敞口，
   所以对照必须是「剔除同样多天数」，而不是「什么都不做」。
   这正是止盈那一轮翻车的地方。
4. **反向对照证明检验有分辨力。** 镜像（剔除低 GEX）如果也有效，
   说明你的检验量根本不是在测 GEX。

## 偏离记录

1. **计算捷径（事前验证后采用）**：原计划「3 阈值 × 200 种子 × 30 相位 = 18,000 次模拟」
   约需 7.5 小时，不可行。改为利用策略的一个结构性质 ——
   日内平仓、无跨日状态（σ 只用历史价格，与当天是否交易无关），
   因此「剔除某天」应精确等价于「把该天收益置零」。
   **先验证再使用**：重跑模拟 vs 直接置零，最大差 **0.00e+00**，等价成立。
   脚本里保留了这个验证，且写成"不等价就 `SystemExit`"，不允许静默使用捷径。
   此偏离不改变任何统计口径。
2. **修了自己的一个判定 bug**：第一版 P1 只检查「dev 与 test 同号」，
   没检查「符号方向是否符合 H1 预测」。于是"稳定地与预测相反"也会被判成立。
   已改为同时要求 (i) 同号 (ii) 方向正确。**这个 bug 恰好会把本次的否决结论
   误判成成立**，是整轮里最值得记的一处。
3. 其余参数、阈值、指标、决定规则均未偏离。

## 执行结果

### P1 机制检验 —— **稳定地与 H1 相反**

| 期间 | 组 | 逐笔均值 | 止损率 | MFE(σ) |
|---|---|---|---|---|
| dev | 高 GEX（>dev90%，101 天） | **+32.21bp** | **31.0%** | **0.614** |
| dev | 其余（906 天） | +4.65bp | 35.1% | 0.461 |
| dev | 差（高−其余） | **+27.55** | **−4.2pp** | **+0.153** |
| test | 高 GEX（30 天） | **+66.47bp** | **22.7%** | **0.630** |
| test | 其余（910 天） | +13.01bp | 33.8% | 0.488 |
| test | 差 | **+53.46** | **−11.1pp** | **+0.142** |

H1 预测「逐笔均值差<0、止损率差>0、MFE 差<0」，**三个指标全部反号，且 dev/test 一致**。
→ **P1 不成立**（高 GEX 日对本动量策略更有利，不是更不利）。

与之前 PART12 §6.2 的发现互相印证：GEX 条件化止盈在**高 GEX 日最差**，
也就是高 GEX 日趋势延续得更好。两次独立实验指向同一结论。

### 敞口混淆检查（非预注册，但必须做）

`corr(GEX, log σ_trailing) = −0.41`，而仓位 = `min(4, 2%/σ_trailing)`，
所以高 GEX → 低历史波动 → 敞口更大 → 同样价格波动换算成资金 bp 更大。

| 期间 | 组 | σ_trailing | 敞口 | 当日 \|开→收\| | 逐笔 bp | **每单位敞口 bp** |
|---|---|---|---|---|---|---|
| dev | 高 GEX | 0.00978 | 2.388 | 65.6bp | 28.18 | **9.36** |
| dev | 其余 | 0.01526 | 1.716 | 95.5bp | 4.84 | 3.97 |
| test | 高 GEX | 0.01112 | 1.999 | 55.2bp | 78.35 | **15.96** |
| test | 其余 | 0.01173 | 1.931 | 73.9bp | 11.93 | 6.80 |

归一化后优势从 +23.35/+66.42bp 缩到 **+5.39/+9.16bp**，
即 **60~85% 的原始优势只是敞口大小**。残差仍为正，但 test 期只有 **30 天**。

### P2/P3 策略层

基线：dev SR 0.704 叠加 +0.268 | test SR 1.203 叠加 +0.421 | 全 SR 0.955 叠加 +0.366

| 组 | 剔天 | dev SR | test SR | test 叠加 | **Δtest 叠加** | test α | test αSR |
|---|---|---|---|---|---|---|---|
| 剔除高 GEX >80% | 483 | 0.617 | 1.022 | 0.262 | **−0.158** | 10.28% | 0.931 |
| 剔除高 GEX >90% | 131 | 0.457 | 1.137 | 0.358 | **−0.063** | 14.15% | 1.103 |
| 剔除高 GEX >95% | 54 | 0.667 | 1.203 | 0.421 | **+0.000** | 16.31% | 1.209 |
| 镜像·剔除低 GEX <20% | 266 | 0.776 | 0.835 | 0.300 | −0.120 | 12.18% | 0.994 |
| 镜像·剔除低 GEX <10% | 119 | 0.908 | 1.077 | 0.435 | **+0.014** | 15.54% | 1.236 |
| 镜像·剔除低 GEX <5% | 56 | 0.832 | 1.106 | 0.460 | **+0.039** | 16.23% | 1.278 |

剔除高 GEX 日**全部 ≤ 0**；而**镜像对照（剔除低 GEX）反而略好**。→ P3 不成立，C2 反向对照也站不住。

### C1 随机剔除安慰剂（200 种子）

| 组 | 真实 Δ | 随机零分布均值 | std | p90 | 真实值所在分位 |
|---|---|---|---|---|---|
| 剔除高 GEX >80%（483 天） | −0.158 | −0.123 | 0.127 | +0.033 | **38%** |
| 剔除高 GEX >90%（131 天） | −0.063 | −0.030 | 0.075 | +0.062 | **33%** |
| 剔除高 GEX >95%（54 天） | +0.000 | −0.011 | 0.054 | +0.051 | **55%** |

真实效应落在随机零分布的 33~55% 分位 —— **与随机剔除同样多天数毫无区别**。
顺带注意零分布均值为负：剔除任何日子都会平均降低叠加贡献。

## 结论

按 §8 的决定规则逐条核对：

| 条件 | 结果 |
|---|---|
| (a) P1 成立且方向正确 | **否** —— 三个指标稳定反号 |
| (b) P2 三阈值单调 | 是（但方向是"越剔越差"） |
| (c) test 叠加 Δ>0.15 且超随机 p90 | **否** —— Δ 全部 ≤0，分位 33~55% |
| (d) 镜像对照未拿到可比好处 | **否** —— 镜像反而更好 |

**H1 否决。记为 GEX 的第 9 次失败。** 规避极高 GEX 日没有 edge，
剔除它们与随机剔除同样多天数无法区分，而且方向上有害。

## 衍生假设 H1'（**不采纳，仅登记**）

数据反过来提示：高 GEX 日对本策略**更有利**，可考虑超配。
**不采纳**，理由：

1. 这个假设是**看了这份数据之后**才产生的。用同一份数据检验它，就是过拟合。
2. 60~85% 的原始效应已被证明只是**敞口大小**（高 GEX → 低历史波动 → 仓位更大），
   而 vol targeting 已经在吃这块了 —— GEX 可能没有提供任何增量信息。
3. test 期高 GEX 只有 **30 天**。
4. 它与有文献支撑的做市商 gamma 机制**方向相反**，缺少可信的因果故事。

要干净地检验 H1' 需要：新的样本期或别的标的、预注册、
以及一个**敞口归一化**的主指标（而不是资金 bp）。在那之前它只是一条观察。
