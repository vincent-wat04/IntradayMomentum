## 0. 先修一个方法学漏洞：止盈从来没被真正测过

`reimpl_noise.simulate` 里的 `giveback`（从最大浮盈回吐 g 比例出场）挂在**止损槽**上，
而 `stop_design_study.py` / `stop_significance.py` 全部用 `reentry="hold"`，其语义是

```python
if hit and reentry == "hold" and side_now == np.sign(shares):
    hit = False          # 同方向开仓条件仍成立 -> 不平仓
```

也就是说：**浮盈还在涨、趋势还在的时候，giveback 恰好被抑制**。
它只在"信号已经离开你这一侧"时才触发 —— 那是止损，不是止盈。

所以 `stop_design.csv` 里 giveback g=0.4/0.6 的那两行（dev 0.617/0.630、test 1.089/1.105）
**不能当作止盈的证据**。本篇为止盈开了独立的槽（`tp_k` / `tp_side` / `tp_every_bar` /
`tp_rearm`），触发不受 `reentry` 语义干预；默认 `tp_k=None` 完全关闭，
加完后 `audit/audit_engine.py` 仍 **19/19 通过**、基线数字分毫不变
（hold Sharpe 1.1469、cum 1.2307），确认没动既有结论。

## 1. 诊断层：有一个真实且稳健的不对称事实

止盈能不能赚钱只取决于一个条件期望：**到达 +x·σ 之后，剩下那段路的收益是正还是负**。
这个量不依赖任何策略实现，所以必须先测它（`takeprofit_diag.py`，44,769 笔 × 30 相位）。

关键方法学细节：30 个相位复用同一批交易日（相位两两相关 0.880），
所以**必须按天聚类**——先把同一天的 30 个相位取均值，再按天做统计。
不聚类的话 t 值会虚高好几倍（例如空头 x=1.0 的 t 从 −8.11 缩到 −4.30）。

「放弃段」= 止盈之后到实际离场之间、顺着仓位方向的收益，单位 bp：

| x (σ_daily) | 空头 dev19-22 | 空头 test23-26 | 多头 dev19-22 | 多头 test23-26 |
|---|---|---|---|---|
| 0.5  | −12.74 (t=−2.36) | −14.77 (t=−2.69) | −13.03 (t=−3.12) | −2.24 (t=−0.26) |
| 0.75 | −17.19 (t=−2.74) | −18.14 (t=−2.46) | −14.81 (t=−2.77) | −10.44 (t=−0.81) |
| 1.0  | −30.08 (t=−3.64) | −17.64 (t=−2.33) | −15.73 (t=−2.08) | −13.33 (t=−0.56) |

* **空头：dev 和 test 同号、同量级、两段都显著。** 赚到 +0.5~1σ 的空头平均回吐 13~30bp。
* **多头：只在 dev 成立**（test t = −0.26 / −0.81 / −0.56 全不显著），
  且阈值再高就翻正（test x=1.5 为 +86bp）。所以多头侧不能动。

机制与文献一致。[Kaminski & Lo (2014)](https://dspace.mit.edu/handle/1721.1/114876)
的结论是：止损类规则在**动量/正序列相关**环境下增值、在**均值回复**环境下减值，
随机漫步下 0/1 止损必然降低期望收益。止盈是止损的镜像，所以应当**只在均值回复的那条腿上有效**。
我们的空头腿正是在逆着 QQQ 的日内正漂移（+4.20bp/日、54.2% 上涨日）走 = 均值回复；
多头腿带着凸性右尾 = 动量。实测的多空分裂和理论预测完全对上。
（内容已改写以符合授权要求。）

## 2. 策略层：标准口径下看起来是大胜

`takeprofit_study.py`，30 相位均值 + TQQQ 单股成本 + 配对区块自助（区块 10 天、4000 次）：

| 配置 | 腿/日 | dev Sharpe | test Sharpe | dev ΔSR (p) | test ΔSR (p) |
|---|---|---|---|---|---|
| 基线（无止盈） | 2.754 | 0.661 | 0.963 | — | — |
| 空头止盈 k=0.75 rearm | 2.754 | **1.007** | **1.069** | +0.346 (0.027) | +0.106 (0.265) |
| 空头止盈 k=1.0 rearm | 2.754 | 1.002 | 1.016 | +0.341 (0.018) | +0.054 (0.328) |
| 空头止盈 k=0.75 rearm 逐bar | 2.754 | 1.082 | **1.181** | +0.421 (0.026) | +0.218 (0.147) |
| 两侧止盈 k=0.75 rearm | 2.754 | **1.134** | 1.120 | +0.473 (0.020) | +0.157 (0.192) |

16 个配置里 14 个 dev/test **同时为正**，dev 普遍 p<0.03。
独立 Sharpe 从 0.963 提到 1.07~1.18，dev 从 0.661 提到 1.0~1.13。
按通常的判法，这已经可以写进策略了。

**但 test 一个都不显著（p=0.147~0.33）。** 这正是"dev 上过拟合"的典型指纹，必须做对照。

## 3. 安慰剂对照：收益不是来自择时，而是来自"少做空"

空头止盈天然会缩短空头在场时间，而"少做空"**本身就已知有利**
（PART9：long-only 独立 Sharpe 1.185 > 多空 0.873）。
所以必须匹配敞口、只改触发方式（`takeprofit_placebo.py`）：

* **对照 A** `tp_rand_p`：每个检查时点以固定概率**无条件**平空（完全不看盈亏）
* **对照 B** `short_scale`：空头规模整体缩放（完全不改时点）

真止盈把空头持仓从 81.4 bar/日压到 66.4 bar/日。匹配后：

| | dev | test |
|---|---|---|
| 真止盈 vs 基线 | +0.346 | +0.106 |
| 对照A（随机平空 p=0.05，70.3 bar/日） vs 基线 | −0.146 | +0.025 |
| **真止盈 vs 对照A** | **+0.493 [+0.061,+0.905] p=0.013** | +0.081 [−0.185,+0.418] p=0.244 |
| 对照B（空头×0.6） vs 基线 | +0.157 | **+0.173** |
| **真止盈 vs 对照B** | +0.189 [−0.163,+0.521] p=0.159 | **−0.067 [−0.393,+0.293] p=0.646** |

读法：
* dev 上止盈确实有**择时含量**（显著打败随机平空，p=0.013）；
* test 上**没有**：打不过随机平空（p=0.244），而且**打不过单纯把空头规模缩到 0.6**
  （−0.067，对照 B 的 test Sharpe 1.137 反而高于止盈的 1.069）。

## 4. 决定性口径：作为 B&H 叠加层，贡献是零

独立 Sharpe 不是决策指标（PART9 §3 已定过口径）。这个 sleeve 的价值在于低 beta（0.013），
真正要看的是叠加到 B&H 上的 ΔSharpe：

| 配置 | 独立 test Sharpe | **test 叠加贡献** |
|---|---|---|
| 基线（多空） | 0.963 | **+0.268** |
| 空头×0.9 | 1.004 | +0.270 |
| 空头×0.75 | 1.070 | +0.267 |
| 空头止盈 k=0.75 | 1.069 | **+0.265** |
| 空头×0.6 | 1.137 | +0.256 |
| long-only（PART9） | 1.185 | +0.127 |

**独立 Sharpe 从 0.963 一路涨到 1.185，叠加贡献从 +0.268 一路跌到 +0.127。**
这是一条干净的单调权衡，而且解释了一个贯穿全项目的现象：

> 任何削弱空头腿的做法（止盈、缩规模、long-only）都会抬高独立 Sharpe、
> 同时压低或持平叠加贡献 —— 因为**空头腿就是这个 sleeve 的对冲性本身**。

止盈的 test 叠加贡献 +0.265 vs 基线 +0.268 = **−0.003**，完全是零。
所以在实际部署口径下，止盈不值一分钱。

逐年也不稳：+0.393 / +0.051 / +0.802 / +0.315 / +0.158 / +0.032 / **−0.451(2025)** / +0.891，
集中在 2021 与 2026 两年。

## 5. 同向多次开仓：本来就在发生，强行增加有害

用户问的"同天可多次同向开仓"其实已经是现状。基线统计：

* 开仓 **1.377 次/日**，**30.9%** 的日子有 ≥2 次开仓
* **同向**连续再开仓 **0.355 次/日**

机制：`hold` 语义下止损只在"信号已离开本侧"时触发；之后若信号再回到同一侧，
下一个检查时点就会再开仓。所以同向再开仓是既有设计的一部分，不需要新加。

止盈之后的再进场规则（`tp_rearm`）实测（单相位逐笔计数，账本自检全部通过）：

| 模式 | 总腿 | TP 次数 | 空头开仓 | MOC | dev ΔSR | test ΔSR |
|---|---|---|---|---|---|---|
| 基线 | 3060 | 0 | 721 | 587 | — | — |
| `done`（止盈即收工） | 3058 | 107 | 720 | 487 | +0.356 | +0.051 |
| `rearm`（等回带内再突破） | 3060 | 107 | **721** | 488 | +0.341 | +0.054 |
| `next_check`（下个检查点可重开） | **3280** | 117 | **831** | 569 | +0.103 | **−0.041** |

三件事：

1. 止盈触发 107 次 / 721 笔空头 = **14.8% 的空头交易**。
2. `rearm` 的空头开仓数 **721 = 基线完全一致** —— 也就是说"价格回到噪声带内、
   当天再次向下突破"在一个盈利的空头之后**几乎从不发生**。所以 `rearm` 这套机制
   买不到任何东西，和 `done` 等价。
3. `next_check` 带来 **+110 次额外空头开仓**（≈ 每次止盈都立刻重开一次）、
   **+220 条腿**，而它是**唯一 test 为负的配置**（−0.041）。
   即：强行允许同向立刻再开仓 = 白付 2 条腿、换一个更差的入场价。

另外注意：TP 出场腿替代的是 MOC 腿（数量 1:1，所以腿数几乎不变），
但 **TP 要付半价差+佣金，MOC 只付佣金**，所以同样腿数下止盈其实更贵一点。

## 6. GEX wall：数据上做不了，机制上也不支持

### 6.1 数据粒度（硬约束）

手上的 GEX 是 `etf_timing/data/raw/squeeze_dix_gex.parquet`：
字段只有 `(price, dix, gex)`，**每天一个标量**，SPX 口径，2011-05-02 ~ 2026-10-01，3878 行。

而 gamma wall 需要**逐行权价**的 gamma 分布（OI×gamma 按 strike 聚合，
再找 call wall / put wall / gamma flip）。单个标量算不出任何 wall。
各家口径也都明确 GEX 是按 strike 从全链逐个算起的
（[Quant Data](https://help.quantdata.us/en/articles/15807345-gamma-exposure-gex-api-python-quickstart-dealer-positioning-guide)，
内容已改写以符合授权要求）。

所以"GEX wall 止盈"在现有数据上**不是方法问题，是数据问题**。
顺带一提：`/opt/longvol` 确实有逐行权价期权数据、也已经在算 gamma wall
（`strategy.json: gamma_wall_min_abs_gex_share = 0.05`），但那是小盘恐慌股、
且 2026-09-30 才开始攒，样本长度完全不够回测。

另需注意：gamma wall 这套说法目前主要来自券商/数据商的实践材料，
缺少同行评议证据 —— 这与之前 firmtape 的发现一致：
**公开 OI 口径的 GEX（= SqueezeMetrics 口径）看不到这些效应**，
只有 tape-signed（主动成交方向签名）的 0DTE 做市商库存才看得到。

### 6.2 机制检验（可测，且被推翻）

标量 GEX 虽然算不出 wall，但能检验 wall 背后的**机制**：
净正 gamma 越大 → 做市商越"涨了卖、跌了买" → 日内波动被压制、价格趋于钉住
→ 行情更容易衰竭 → **止盈应该在高 GEX 日最有效**。

这是个可 falsify 的命题，而且用的正是之前唯一复现成功的 GEX 结果
（GEX 对日内幅度有预测力：四分位 |open→close| 比值 0.42~0.56、样本外 R² 0.009→0.035、DM t 最高 +3.88）。

`takeprofit_gex.py`，GEX 取 t−1，三分位阈值**只用 dev 期**计算（避免用到 test 信息）：

| 止盈只在哪组日子生效 | 天数 | dev ΔSR (p) | test ΔSR (p) | test 叠加贡献 |
|---|---|---|---|---|
| 仅**高** GEX 日 | 877 | **−0.090 (0.761)** | +0.005 (0.469) | +0.223 |
| 仅中 GEX 日 | 601 | +0.237 (0.009) | +0.079 (0.154) | +0.308 |
| 仅**低** GEX 日 | 470 | +0.158 (0.066) | +0.008 (0.380) | +0.270 |
| 全部日子 | — | +0.346 (0.027) | +0.106 (0.261) | +0.265 |

**预测方向完全相反**：高 GEX 日是止盈**最差**的一组（dev 为负），不是最好的一组。
中间组最好 —— 但"中位最好"没有任何机制解释，是典型的噪声形状。

所以：gamma/钉住机制**解释不了**这个止盈效应。连机制都不支持，
就没有理由去买逐行权价数据做 wall 版本。这是 GEX 的**第 8 种用法被否决**。

## 7. 决定

* **不加止盈。** 诊断层的事实是真的（空头回吐 13~30bp，dev/test 都显著），
  但它在策略层打不过"单纯缩小空头规模"这个最笨的对照，
  而且在真实部署口径（B&H 叠加贡献）下贡献为 **−0.003**。
* **不改再进场规则。** 同向多次开仓已是现状（0.355 次/日）；
  `rearm` 与 `done` 等价、`next_check` 明确有害。
* **不买逐行权价期权数据做 GEX wall。** 机制检验方向相反。
* 保留本篇的实现（`tp_*` 参数、两个安慰剂对照 `tp_rand_p` / `short_scale`），
  默认全部关闭，供以后复核。

### 方法学留痕

这一轮最值得记的是：**如果只看独立 Sharpe，我会把止盈当成本项目最大的改进写进策略**
（dev 0.661→1.134、test 0.963→1.181）。
救回来的是两件事 ——
① 匹配敞口的安慰剂对照（随机平空 / 缩小空头规模），
② 用叠加贡献而不是独立 Sharpe 当决策指标。
以后任何"削弱某一条腿"的改动，都必须同时过这两关。
