## 1. 日更拥挤度(与月频方法等价,只是每天重算)
* 在第 t 天开盘前,用截至 t−1 收盘的数据:把最近 61×21 个交易日切成 21 日的"月块",块收益 = 块内日收益之和,块 ΔVIX = 块末 VIX − 上一块末 VIX。run-up = 最近 12 块之和;AR(1) 与 ΔVIX β 用最近 60 块。z = 相对此前 2520 个交易日(≈120 个月)该统计量日度值的均值/标准差;状态 = C 相对此前 1260 日(≈60 个月)的三分位。
* **C_TSM_d**:f = sign(过去 252 日 NDX 对数收益之和,截至前一日) × 当日 NDX 对数收益。**C_MKT_d**:NDX 日收益。全部收盘即得,无延迟。
* **C_MOM_d(实时拼接)**:第 t 天可得的 French 日度 MOM 截至最后一个满足"月末 + 30 自然日 ≤ t"的月末 E(t)(实测 9-30 的数据在 10-26 前后发布);(E(t), t−1] 的缺口用 MTUM 与 SPY 的日收益拟合补齐:在 E(t) 之前 504 个 French 已知日上做 OLS `MOM ~ MTUM + SPY`(≥ 120 个重叠日)。MTUM 上市(2013-04)之前没有补齐,块序列截止到 E(t)。
* 自检:投毒(切点之后所有输入 ×(−3),切点及次日的指标逐位不变);拼接质量(拟合值与随后发布的 French MOM 的相关)。
* 描述:日更状态与月频状态的一致率、日更状态平均提前多少天切换。
