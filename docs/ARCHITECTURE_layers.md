# 分层架构:一个大策略下的各层(2026-10-11)

目的:把散落的研究放进同一个框架,每一层有**输入、输出、接口、评估协议**,避免『每个想法各自一套口径』。后续新增研究先说明属于哪一层、对哪一层的输出产生增量。

```
 L4 信息层      新闻/事件(LLM 结构化抽取)、确定性日历(FOMC/NFP/OPEX)   → 输出: 特征,不直接交易
 L3 日内回转层  分钟线上的回转/微观结构信号                              → 输出: 日内叠加仓 (与 L2 同类,独立评估)
 L2 Sleeve 层   噪声带日内动量(实盘 live_noise)                          → 输出: 日级叠加收益 s_t (30 相位)
 L1 仓位层      RV21 波动率权重 w_rv ∈ [0.5,1.5]                         → 输出: 对 B&H 的权重
 L0 择时/Regime 趋势 + 宏观/市场环境 → 暴露 e_t ∈ {0, 0.5, 1}           → 输出: 对 QQQ 的暴露(多/空仓)
 组合: x_t = e_t · w_rv,t · r_QQQ,t − cost + sleeve_t
```

## 层间接口(统一约定)
* **时间**:t 日收盘形成信号,t+1 日起生效(`.shift(1)`);日内信号 k 根 bar 收盘决策、k+1 开盘成交。
* **PIT**:所有宏观/月度数据按『发布日』可用;Shiller 月度滞后 1 个月;COT 周二数据周五发布 → 下周一起可用;滚动 z 分数只用截至 t 的数据。
* **成本**:QQQ 2bp/边(日换手);Sleeve 用 TQQQ 每股成本口径(repo 既有)。
* **基线**:每层的增量都对『同平均敞口纯静态对照』报 ΔSR / ΔMDD(`trend_rv_sleeve_study.boot_dsr`,块自助,慢信号块长 40 日)。
* **噪声护栏**:|ΔSR| < 0.15 按噪声;区间含 0 不写『有证据』。
* **多重检验**:每个研究登记配置总数;安慰剂用『保持自相关的圆周平移』(慢信号)或置换(日内)取族内 max。
* **防过拟合**:dev/test 时间切分写在预注册里;结果出来后不得删改特征;需要改动则开新一轮并累计配置数。
* **自检**:污染测试(未来价格 ×k,信号逐位不变)+ 阳性对照。

## 层间关系(研究问题)
* L0→L2:宏观环境是否决定 Sleeve 在哪些 regime 赚钱?(把 L0 的 regime 特征作为 L2 日级缩放的特征)
* L4→L2/L0:事件日历/新闻抽取是否能解释 Sleeve 的亏损日、L0 的假信号?
* L2↔L3:日内回转与 Sleeve 是同一维度(延续 vs 回转)的两侧,不应作为独立腿叠加,而是互为过滤。

## 叠加结果(`studies/layer_stack_study.py`,全部为已登记配置,无新选择)
2019~2026(含 Sleeve):静态 1.001 → +L1 1.168 → +L0 趋势 1.222 / 信用 1.189 / 两者平均 1.210 → **+L2 Sleeve 1.644(MDD −15.6%,Calmar 2.39)** → +L4 FOMC 关闭 1.677。
2004-06~2026(无 Sleeve):静态 0.774 / MDD −53.4% → +L1 0.910 / −37.5% → +L0 信用 0.975 / −25.0%(趋势 0.896 / −27.6%)。
相邻层增量(2019~2026):L1 +0.167 [−0.07,+0.39];L0(任一)+0.02~+0.05 [区间含 0];**L2 +0.43 [+0.01,+0.85]**;L4 +0.033 [−0.10,+0.14]。
**一句话**:Sleeve 是这个体系里唯一有显著增量的层;L0/L1 提供回撤保护但 Sharpe 增量统计上不可分;其余研究方向(日内回转、LLM 新闻、日级避开低波日)在 ~6 轮、~150 个配置的搜索后没有可交易的增量。
**下一步的价值排序(预期收益/成本)**:(1) 前向样本记录器(逐笔入场特征、regime 状态、新闻窗口);(2) 把已有的弱线索作为前向假设冻结(逐笔过滤空头侧、FOMC 日、A2_all off);(3) 取得 HF 数据集授权后重做 LLM 新闻(样本扩到 ~500 天);(4) 获取真实期权/订单流数据(optrec 已在记录)再做 GEX/dealer 持仓。
