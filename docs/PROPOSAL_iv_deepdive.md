# PROPOSAL — 与隐含波动对赌:更接近可交易的 0DTE 跨式代理 + 『包含检验』

状态:**预注册(执行前冻结)**。脚本 `studies/iv_deepdive_study.py`。承接 `PROPOSAL_vol_monetization.md` M3(『无法判定』:方差互换代理里朴素信号也有 Sharpe 5.7,VIX1D 收盘值带测量噪声,日变化自相关 −0.31)。用户 2026-10-12:『隐含波动对赌不可判定这个方向能不能再深究一下』。

## 0. 能做什么、不能做什么(诚实边界)
* **没有**历史 QQQ 期权价格(optrec 仅最近的快照,在服务器上,本会话无法访问)。所以任何结论都是『在指数隐含波动代理下的』;**不能**证明真实 0DTE 跨式的可交易性,只能判断**模型相对于所有可得的市场隐含度量 + 朴素持续性是否还有增量信息**——这是必要条件。
* 决策时点 = 前一收盘(信息 ≤t−1),持有 = 当日开盘买入跨式,收盘了结。**10:00 的盘中信息(B 组)无法与当时的隐含价比较**(没有盘中隐含),所以 B 组不在本检验里。

## 1. 数据(2022-05-16 起,VIX1D 有数据之后,约 1100 个交易日)
`VIX1D, VIX9D, VIX, VXN`(Cboe,t−1 收盘);模型预测 `f̂` = M2 的全日 log RV 预测(特征 ≤t−1 收盘 + 事件日历 + GEX(t−1),walk-forward,OOS);真实 `rv`(当日 1 分钟 RV)、`m = ln(C/O)`(开→收)。

## 2. 检验 A:包含回归(encompassing)
* 模型 1:`log rv ~ log iv1d + log iv9d + log ivxn + log rv(t−1) + log rv5 + log σ14`(全部市场隐含度量 + 持续性)。
* 模型 2:模型 1 + `gex_z + 事件日历 + 星期`(模型对隐含/持续性之外多出来的信息)。
* 样本外:在 2022-05 ~ 2023-12 拟合,2024-01 ~ 2026-10 评估(也报逐年滚动);报 OOS R²、ΔR²(月聚类自助 95%)、以及 `f̂` 加进模型 1 后的 HAC t 值。

## 3. 检验 B:0DTE 跨式代理(2 种溢价定义 × 2 个阈值 × 4 种成本)
* 隐含日波动 `σ_iv,t = (VIX1D_{t−1}/100)/√252 · (VXN_{t−1}/VIX_{t−1})`(把 SPX 的 1 日隐含按 NDX/SPX 的 30 日隐含比例缩放到 QQQ)。
* ATM 跨式溢价 `prem_t = λ_t · 0.798 · σ_iv,t`,`λ_t` = 过去 60 个交易日 `mean(|m|) / mean(0.798·σ_iv)`(因果;让平均跨式『公平』,风险溢价被吸收,只检验日间相对错价)。
* **溢价定义 P1**:如上(原始 VIX1D);**P2**:VIX1D 取 t−1 与 t−2 的几何平均(降噪,检验『边际收益是否来自单日收盘噪声』)。
* 模型的预期绝对位移 `E|m|_t = κ_t · 0.798 · √exp(f̂_t)`,`κ_t` = 过去 60 日 `mean(|m|)/mean(0.798·√exp(f̂))`(因果校准);edge `e_t = E|m|_t / prem_t`。
* 规则:`e_t > 1+h` 做多跨式,`e_t < 1−h` 做空跨式,否则不交易;`h∈{0, 0.1}`。成本 c∈{0, 3%, 5%, 10%}(多头付 `prem(1+c)`,空头收 `prem(1−c)`)。损益单位 = 溢价。
* **对照(同一收益函数)**:朴素持续性(`E|m|` 用昨日 RV 同样校准)、随机方向。**判定的关键**:模型相对朴素的增量,而不是绝对 Sharpe。
* 配置数:2(P1/P2)× 2(h)× 4(c)= 16(c 只是成本敏感性,主结果 c=5%);族 = {P1,P2}×{h} = 4 个主配置。
* **有证据 ⇔**(i)检验 A 的 ΔR² 区间不含 0 且 f̂ 的 HAC |t|>2;(ii)检验 B 在 c=5% 下 P1 与 **P2** 的均值损益 >0、月聚类区间不含 0,**且**模型相对朴素的差 >0;(iii)逐年同号。否则『没有足够证据 / 仍不可判定』。

## 4. 先验

### 判定
**仍不可判定,但已排除『大 edge』**:
1. 模型在隐含波动与持续性之外有**一点**真实信息(ΔR² +0.022,来自星期效应与 FOMC 日历,不是 GEX),这是必要条件;
2. 把这点信息放进更接近可交易的跨式代理后,均损益 +0.03~0.07 个溢价单位/天,**扣 5% 成本后区间多半含 0,10% 成本即归零**,且模型相对朴素信号的增量区间含 0;
3. 无事件日的损益 ≈ 0,事件日的结果随溢价定义翻转;**全部判定条件(ii)(iii)不满足**。
**要真正判定,需要 QQQ 当日/次日到期期权的实际买卖报价**(optrec 在服务器上记录;需要你允许我读取/导出)。如果将来做:先看事件日(FOMC 前一日、OPEX、节后第一天)的真实跨式 vs 模型期望位移,这是唯一出现过『方向性线索』的子集。
**B 组(10:00 盘中信息)不能与盘中隐含对比**(无盘中隐含数据),所以 `PROPOSAL_disp_prediction` 里的盘中特征只能在方向性策略(Sleeve)上检验,不能在期权上检验。
