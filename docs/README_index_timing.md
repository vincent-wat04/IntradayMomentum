# 指数择时因子回测框架（SPY / QQQ）

## 运行

要求 Python 3.10+、`numpy`、`pandas`。输入 CSV 必须含 `datetime,open,high,low,close,volume`，时间戳为**纽约本地交易时间**，五分钟 bar 以起始时间标记。

```bash
python index_timing_framework.py \
  --spy /path/to/SPY_5min.csv \
  --qqq /path/to/QQQ_5min.csv \
  --output results.json
python -m unittest test_index_timing_framework.py
```

`--fee-bp` 默认 1，`--orthog-lookback` 默认 120 个过去有效信号日，`--orthog-min-periods` 默认 60。如输入范围/交易日历不同，必须用重复的 `--early-close YYYY-MM-DD` 明确指定**全部**早收盘日。当前默认只覆盖源样本中 2024–2025 年的六个早收盘日。对于新的数据源，请核查时间区、时标、复权及早收盘；缺失 09:30、终盘或采样点会报错。

分桶检验默认覆盖 `SKEW_DIFF` 的全部 K 日窗口、原始/同日期/正交残差和两种执行模式；用重复的 `--layer-factor MID_AVG --layer-factor MID_MED` 可指定其他已登记因子。

## 因子

在 10:30–15:30 的 11 个半小时检查点，计算此前 14 个完整交易日对应检查点的平均日内噪声，向后移一日：

\[
b_{t,\tau}=\operatorname{mean}_{s=t-14}^{t-1}|P_{s,\tau}/O_s-1|,\quad
U_{t,\tau}=\max(O_t,C_{t-1})(1+b_{t,\tau}),\quad
L_{t,\tau}=\min(O_t,C_{t-1})(1-b_{t,\tau}).
\]

\[
z_{t,\tau}=\frac{P_{t,\tau}-(U_{t,\tau}+L_{t,\tau})/2}{(U_{t,\tau}-L_{t,\tau})/2}.
\]

`MID_MED` 是 `z` 的日内中位数，`MID_AVG` 是均值，`SKEW_DIFF = MID_AVG − MID_MED` 是 11 个采样点的日内均值与中位数之差，`MID_END` 是 15:30 值，`OUT_AVG` 是带外有符号超额 `sign(z)max(|z|-1,0)` 的均值。`SKEW_DIFF` 是不再除以标准差的偏态代理，**不是标准化的 Pearson 偏度系数**。之后对各日因子用 **1/5/10/20/30/60 日**均值聚合。滚动分位阈值基于信号日之前最多 120 个已经形成的日频因子值，至少需要 80 个。

### K 日过去收益正交

对聚合窗口为 K 的因子 \(F_{t,K}\)，定义 \(X_{t,K}=C_t/C_{t-K}-1\)。逐日使用 **t−1 及以前**最多 120 个有效 \((F_{s,K},X_{s,K})\) 配对（最少 60 个）拟合含截距 OLS：

\[
F_{s,K}=\alpha_{t-1,K}+\beta_{t-1,K}X_{s,K}+\varepsilon_{s,K},\qquad
F^\perp_{t,K}=F_{t,K}-\widehat\alpha_{t-1,K}-\widehat\beta_{t-1,K}X_{t,K}.
\]

\(X_{t,K}\) 需要 t 日收盘价，届时才形成残差信号，执行仍为 t+1。若训练不足或控制收益无方差，残差为空。**滚动样本外残差不保证在整段样本上与过去收益恰好零相关**；输出另列实际相关系数。残差自己的 1/3/5/8/10% 和 90/92/95/97/99% 阈值用过去残差重新拟合。

结果的“因子版本”有 `原始`、`原始_同日期`、`正交残差`。比较后两者才能保持预测 IC 的日期完全相同；原始完整样本则保留历史结果。K=60 的长持有期与极端分位数样本会因两层历史训练明显缩小。

## 执行与期限

日内输入均截至 t 日 15:30，假定信号在 t 日收盘确认。两种版本都在 t+1 才交易：

| 执行代码 | 成交与第一段收益 | 持有 h 日事件收益 |
| --- | --- | --- |
| `next_open`（表中 T+0） | t+1 开盘交易，t+1 收盘有价格盈亏 | `C[t+h]/O[t+1]-1` |
| `next_close`（表中 T+1） | t+1 收盘交易，t+2 收盘有第一段价格盈亏 | `C[t+1+h]/C[t+1]-1` |

两个版本均报告 **1/5/10/20/30/60/90/120 日**。在“共同样本”表中，两个执行版本及所有期限强制共用能完整观察至收盘入场 120 日后的一批信号；“各自样本”表按各期限全部可观测信号分别计数。两表不可混作同一组独立样本。

低分位触发定义为因子 `<=` 过去分位阈值，高分位触发为 `>=` 过去阈值。原有带中点因子沿用探索性的低位看多、高位看空方向；`SKEW_DIFF` 按偏态延续的探索假设使用**低位看空、高位看多**方向。胜率按行中标注的方向计算，**收益率始终是 ETF 原始价格收益，不反号**。同一因子的相邻事件会重叠，另给出贪婪去重次数；它不是严格的统计有效样本量。组合部分对偏态因子同时列出低位买入与高位买入两种分位方向，以便核对方向风险。

## 输出与模块

- `load_market`：数据校验、早收盘处理、因子构造。
- `orthogonalize_past_k` 与 `make_factor_cache`：逐日以过去 K 日收益拟合滚动投影，缓存原始/配对原始/残差与各自的历史阈值。
- `event_prices`：唯一的执行价/退出价映射；所有事件表及 IC 共用。
- `event_study`：分位事件的方向胜率、平均原始收益、触发次数、非重叠次数。
- `predictive_metrics`：全信号 Pearson IC、Spearman RankIC、以持有期限为最大滞后阶的 Newey–West 斜率 t 值；它们是单一 ETF 的**时间序列**指标。
- `yearly_predictive_metrics`：按信号年份拆分 IC 与样本日数；2024 年信号的持有期可跨入 2025 年。长持有期收益高度重叠，该拆分不等于独立样本外验证。
- `orthog_diagnostics`：在配对信号日计算原始因子、滚动残差分别与过去 K 日收益的实际相关系数。
- `trailing_bucket_ids` 与 `bucket_study`：逐个信号日，用**该日以前**最多 120 个同版本有效因子值（至少 80 个）计算当前因子的历史中位秩百分位，分五桶/十桶，桶 1 最低。逐桶计算未来 1/5/10/20/30/60/90/120 日的原始价格收益均值、中位数、上涨比例、相对于同组所有可评估日期的超额、触发日数和贪婪非重叠次数。`bucket_layers` 同时给出各期限可评估样本和五分桶的共同 120 日样本；`bucket_yearly` 是按信号年拆分的五分桶；`bucket_summary` 提供高桶减低桶条件均值、桶序与桶均值的 Spearman 相关、相邻桶均值严格上升的段数。
- `portfolio_study`：五种基础因子、三个因子版本、两种执行的 long/cash 示例。偏态代理额外运行反向分位规则。次日开盘版本中，旧仓位承担隔夜缺口，新仓位承担开盘到收盘；次日收盘版本中新仓位从后一天开始承担价格波动。成本按每次仓位变动扣 1 bp。
- `run`：多标的汇总，返回可以写成 JSON 或接入表格生成器的结构。

添加新因子时，可在 `load_market` 生成的 `factors` DataFrame 中加入一列，并在 `FACTOR_NAMES` 登记；因子必须只依赖 t 日已知信息。不同数据源建议适配数据加载层，而保留 `event_prices` 和评估层。

## 解释限制

当前公开样本从 2024-06-03 到 2025-12-31，每标的 397 个交易日，**不包含 2026**。源数据的末根五分钟 `close` 不是经核验的正式收盘撮合价，`09:30 open` 也未证明可按该价格足量成交；ETF 分红/拆分调整、滑点、市场冲击和开/收盘拍卖的具体订单条件均未验证。因此这是**按未来可见时序对齐的价格代理实验**，尚非实盘可执行收益。

分桶属于**单只 ETF 跨不同日期**的条件收益研究，按历史百分位固定分桶，桶的观测数不一定均衡。“高减低”是不同日期的条件均值差，不是同一天可建立的多空收益。总体市场上涨会使低桶的原始收益也为正，须结合相对全体收益、桶间单调性、分年与非重叠次数判断；长周期事件互相重叠，五个桶均值并非独立观测。只用残差可用日得到的 `原始_同日期` 与 `正交残差` 是可比口径。

本次测试枚举了因子构造、窗口、分位和执行方式，属于探索性研究；已对过去 K 日 ETF 收益做单变量滚动正交，尚无独立市场状态样本外、其他风格正交、GEX 分层、交易量调整或 2026 检验。高胜率与 IC 的显著性均可能受重叠样本、多重尝试及市场状态影响。进一步迭代应固定候选集合后做滚动样本外、按年份/波动与 GEX 状态分层、分红复权与真实成交价格复验，再用同一执行层比较原因子与滚动残差化因子。
