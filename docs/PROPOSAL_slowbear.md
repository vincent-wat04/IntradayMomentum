# 预注册：慢熊行情的处理（slow-bear study）

日期：2026-10-08　状态：**跑结果之前冻结**。脚本：`slowbear_study.py`

## 0. 问题与已知事实
上一轮诊断（`bear_regime_diag.txt`）：快崩（COVID/GFC/2022）里 RV 降风险有用；**慢熊（互联网泡沫 2000-02）里没有**
——SPX 买入持有 −49.1%，红圆 −59.3%，浅蓝 −54.1%，只有 lo=.5/hi=1（不加杠杆）−42.2%。
机制：RV 百分位相对自己过去 504 天，持续的温和高波动会让百分位"适应"下来，权重反而回到 >1。
结论：**RV21 擅长"波动尖峰"，对"价格慢速下行"没有信息。** 需要另一类信号：价格水平/趋势/回撤/宏观。

## 1. 候选方案（头脑风暴后冻结；参数取文献通用值，**不扫描**）
基底 B = 浅蓝（lo=.5, hi=1.5, 百分位 RV21/504）。叠加规则全部只用 t 日收盘及以前的数据，作用于 t+1。

| 编号 | 名称 | 规则 | 依据 |
|---|---|---|---|
| H0 | 浅蓝 B | 基底 | — |
| H1 | 深蓝（不加杠杆） | hi=1 | 上轮诊断：慢熊中 w>1 占比 0% |
| H2 | 200 日趋势 | 收盘 < SMA200 → w=0.5，否则 B | Faber 2007 |
| H3 | 12-1 时间序列动量 | 过去 252 日收益（剔除最近 21 日）<0 → w=0.5，否则 B | Moskowitz-Ooi-Pedersen 2012 |
| H4 | 趋势门控杠杆 | 收盘 < SMA200 → min(B,1)，否则 B（只禁止下跌趋势中加杠杆） | 本研究，针对"慢熊里 w>1" |
| H5 | 回撤刹车 | 回撤 ≤ −10% → w=0.5，回撤收窄到 > −5% 才恢复（滞回） | 回撤式风控 |
| H6 | 绝对波动率目标 | w = clip(σ*/RV21, .5, 1.5)，σ* = SPX/NYA 15%，NDX/RUT 20% | Moreira-Muir 2017（用绝对而非百分位） |
| H7 | 收益率曲线倒挂 | 10y−3m 的 21 日均值 < 0 → w=min(B,1) | Estrella-Mishkin 1998；**探索性**，只有 ~3 次事件 |
| H8 | 组合 | min(H2, H3, H5) 逐日取最小权重 | 多信号一致才满仓 |

没有收录并说明原因：
- **买入 put / 领口**：上一轮证明"保险"期望为负，且无真实期权链历史（合成定价不可信）。
- **做空 / 反向 ETF**：前几轮已否决（长短、衰减、做空尾部）。
- **宏观/信用利差/广度**：本地数据无 1990 年起的可用序列（HYG 2007 起），无法做 2000 年样本检验。
- **债券/黄金避险**：1990 年代无 IEF/GLD；只能做 2007 年以后的旁证（第 6 节）。

## 2. 评估口径（所有方案相同）
- 收益 = w·r + (1−w)·rf − 2bp·|Δw|，rf = IRX。w>1 的部分按 rf 融资，w<1 的部分记现金收益。
  这与实盘 QQQ 腿（不计现金收益）口径不同，**好处**是 1990 年代 5% 利率下对降仓位公平；**所有方案、所有对照同一口径**。
- 夏普 = 超额收益（减 rf）年化。
- 市场：SPX、NDX、RUT、NYA，1992-01 → 2026-10（预热 504 天）。四者高度相关，**不是四个独立样本**。
- 慢熊区间（沿用 `bear_regime_diag.py` 的自动峰谷）：互联网泡沫 2000-02、金融危机 2007-09、2022。
  指标：峰→谷收益、谷后 252 日收益（"错过反弹"的代价）。
- 全样本：CAGR、夏普、MDD、Calmar、平均权重、年换手。
- 对照：**同平均权重的静态组合** mean(w)·r + (1−mean(w))·rf。ΔSR 的 95% CI 用成对循环块自助（L=10, 4000 次）。
- 分段：1992-2009 vs 2010-2026（后者几乎没有慢熊，用于衡量"牛市成本"）。

## 3. 判定规则（冻结）
一个方案要被推荐用于实盘，必须**同时**满足：
- (a) 互联网泡沫与金融危机两段，在 SPX 和 NDX 上，峰→谷收益都**优于 H0**；
- (b) 全样本 MDD 优于 H0，且 Calmar ≥ H0；
- (c) 全样本 ΔSR vs 同平均权重静态对照 ≥ 0（不要求显著，但不得为负）；
- (d) 2010-2026 子样本夏普不比 H0 低超过 0.10（牛市成本上限）；
- (e) 在 RUT、NYA 上 (a)(b) 的方向与 SPX/NDX 一致（至少 3/4 市场）。
Bonferroni：8 个方案，α = 0.05/8 = 0.00625；ΔSR 的显著性只作参考，不作为采纳条件（样本里只有 3 次熊市，功效很低，会明说）。

## 4. 明确的局限（先写下来）
- 慢熊独立事件 ≈ 2 次（2000-02、2007-09 的下行阶段较慢），不可能给出统计显著的结论；只能做"机制一致 + 多市场方向一致"的判断。
- 趋势类规则的已知代价是震荡市反复止损（whipsaw）；2010-2026 是它最不友好的样本，必须一并报告。
- 不允许在看到结果之后改参数或换均线长度；若要探索，另开一节标为"事后探索"。

## B. 关键数字
- 互联网泡沫峰→谷（SPX / NDX）：B&H −49.1% / −82.9%；浅蓝 −54.0% / −81.7%；**H2 −33.1% / −64.3%；H3 −29.7% / −56.1%**。
- 全样本 MDD（SPX / NDX）：浅蓝 −56.0% / −81.7%；H2 −35.3% / −65.6%；H3 −33.9% / −56.1%。
- 全样本 ΔSR vs 同平均权重对照：H2 +0.020 / +0.050，H3 +0.022 / +0.107；CI 全部含 0；H3-NDX P(Δ≤0)=0.04，H6-NDX 0.01，均不过 Bonferroni 0.00625。
- RUT / NYA 上 ΔSR 为负（H2 −0.038/−0.042），保护方向一致但夏普不改善。
- **代价**：谷后 252 日的反弹被错过（NDX 泡沫后：浅蓝 +101%，H2 +53%）。趋势类是"用反弹换回撤"。

## C. 事后稳健性（`slowbear_robust.py`，仅作参考，不改变上面的判定）
- R1 回看长度不是刀口：SMA100~250、动量 126~252 在 SPX 泡沫段都把峰→谷从 −54% 降到 −30%~−38%。
- R2 关闭态权重是**风险偏好旋钮**而非 alpha：e_off 从 1.0→0，SPX MDD −56%→−25%（SMA200）/ −58%→−21%（动量），夏普几乎平（0.36~0.47），CAGR 略降。
  即用户的直觉"lo=0 更能处理熊市"——**对趋势信号成立，对 RV 百分位信号不成立**。
- R3 **去掉互联网泡沫**（2003-06 起）：H2/H3 夏普反而低于浅蓝（SPX 0.53/0.54 vs 0.56；NDX 0.72/0.75 vs 0.78），只在 MDD 上略好（SPX −33% vs −41%）。
  → 保护效果高度依赖 2000-02 这一个事件。
- R4 关闭态持 IEF：GFC 更好（−27.6% vs −33.3%），2022 更差（−23.8% vs −17.7%）。债券不是通用避险。
- R5 实盘形态（QQQ 腿 + 1×Sleeve，2019-26，实盘口径）：浅蓝 Sharpe 1.563 / MDD −19.7% / Calmar 1.99 / 2022 −7.0%；
  H2 1.599 / −16.0% / 2.41 / −0.7%；H3 1.567 / −16.0% / 2.33 / −1.7%；深蓝 1.531 / −16.4% / 1.97 / −1.1%（CAGR 降到 32.4%）。

## D. 结论与局限
1. 慢熊需要的是**价格趋势信号**，RV 信号对它没有信息；H2/H3 是唯一通过全部预注册规则的类别。
2. 样本里只有约 2 个真正的慢熊事件，且 R3 显示去掉 2000-02 后优势基本消失，只剩 MDD 的小幅改善；统计上**不能宣称显著**。
3. 它们是保险而不是 alpha：Sharpe 持平（ΔSR CI 含 0），换来回撤下降，代价是错过反弹和 ~1 次/年的额外换手。
4. 是否上实盘是风险偏好决策，而非统计决策。
