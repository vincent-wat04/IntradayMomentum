# PROPOSAL — Sleeve 逐笔入场过滤:用入场时刻的信息预测「这一笔」的结果

状态:**预注册(执行前冻结)**。脚本 `studies/trade_filter_study.py`。前置:`PROPOSAL_sleeve_anatomy.md`(凸性画像)、`PROPOSAL_lowvol_avoidance.md`(三轮日级预测均未能变现)。

## 0. 为什么换层级
日级预测(预测当天剩余波动)三轮都不能变现:Sleeve 的损失来自『有突破却没有延续』的那一笔,而不是『当天波动小』本身(Sleeve 在被跳过日的标准差与其余日几乎一样,87 vs 91bp)。
所以直接预测**这一笔的结果**:样本从 ~1,400 天变为 ~29,000 笔(30 相位合计;**有效独立观测仍按交易日聚类**)。

## 1. 无前视设计
* 决策点 = 实际入场的检查 bar 收盘(`k_dec = k_in − 1`);特征只用 ≤k_dec 的 bar 与 t−1 的日度数据;成交已是下一根 bar 开盘(引擎既定)。
* 特征(冻结):
  - **突破质量**:突破强度 = (收盘相对带边界的超出量)/σ_profile(k);当日已发生的上/下穿次数;距 VWAP 的方向偏离;z_open、z5/z15/z30(按 σ14 标准化)。
  - **量价代理**(1 分钟 OHLCV):方向性净量比(15 分钟)、30 分钟 CLV×量、相对成交量(PIT)、15 分钟 RV 比、15 分钟波幅比。
  - **状态**:入场时刻 k/390、方向(±1)、隔夜缺口/σ14、log σ14、log VIX(t−1)、GEX z(t−1)、`ŷ_A` 的因果分位(10:00 的基线预期)、事件日历 E 组(FOMC/NFP/OPEX/月初月末/半日)。
  - 方向性特征按交易方向取符号(顺势为正),使一个模型可同时处理多空;并保留 `side` 本身。
* 目标:`y = 方向收益(入场→实际离场)`,单位 bp(含止损的实际结局)。
* Walk-forward:2019–2020 首个训练窗,之后每年初重估(扩展窗),OOS 2021–2026;dev-OOS=2021–22,test=2023–26。**同一天的多笔(多相位)全部在同一年内,不会跨训练/测试**。
* 污染自检:污染某天 k_dec 之后的 bar,k_dec 及之前的特征须逐位不变;阳性对照:把『入场后 5 分钟收益』加入特征,IC 必须暴增。

## 2. 规则(冻结)
* 模型:岭回归(α=100,标准化)、LightGBM(depth 3,200 棵,lr 0.03,min_child 500,subsample 0.7,colsample 0.8);特征集 F1=突破质量+量价;F2=F1+状态+E+ŷ_A分位。共 4 个模型。
* 过滤:预测 y 落在『此前所有 OOS 预测』因果分位的最差 q → 剔除该笔;q ∈ {10%, 20%, 30%}。连续:s=clip(exp(γ·z), 0.5, 1.5),z=标准化预测(因果),γ ∈ {0.5, 1.0}(笔级缩放)。共 4×5=20 个配置。
* **口径说明**:逐笔剔除是『信号出现但不执行』的近似 —— 引擎中被剔除的那笔之后,同一天可能出现的重新入场不会被模拟(保守)。日曲线 = 保留笔的净盈亏(含按 TQQQ 口径换算的佣金)之和 ÷ 30 相位。已验证全部笔相加 = 引擎日收益(误差见脚本输出)。
* 评估:Sleeve ΔSR(dev-OOS、test、全 OOS)、组合 ΔSR(RV[0.5,1.5]+Sleeve 1:1);置换安慰剂:随机剔除同比例的笔(2000 次),取**族内 max**(20 配置 + 日级累计 50 个配置的计数,共 70)。
* 判定:dev-OOS 与 test 同号、|ΔSR|≥0.15、邻近 q 同号、族内 p<0.05;且**被剔除笔的平均 y 必须为负、保留笔必须较高**(机制检查)。

## 3. 先验
* 成功概率 ≤15%。『突破质量』是最有机制的特征(弱突破更容易回落),但噪声带突破本身已是质量过滤的结果;1 分钟 OHLCV 缺订单流方向。
* 若有信号,最可能是**突破强度**与**FOMC/半日市**;量价代理的作用预计很小。

## 结果(2026-10-11;`studies/trade_filter_study.py`;日志 `studies/outputs/full/intraday/trade_filter_log.txt`;表 `outputs/tables/trade_filter_*.csv`)
**重构与自检**:29,679 笔(30 相位);逐相位日收益 − 逐笔净盈亏最大误差 1.4e-17(精确);污染自检(12 笔,k_dec 后价格/量×7)特征逐位不变;阳性对照(加入入场后 5 分钟收益)IC=0.131 ≫ 诚实模型。
**1) 逐笔预测力**(OOS 2021–2026,22,498 笔;IC=Spearman):F1·ridge −0.026 [−0.081,0.027];F2·ridge −0.012;**F1·lgbm +0.024 [−0.025,0.072]**;F2·lgbm −0.015。全部区间含 0。
单变量最大 |rho|=0.06(side 0.062、e_fomc −0.057、bo_cross 0.052)。
**2) 变现(20 个配置)**:19 个 |ΔSR|<0.15 或 test 为负;唯一族内 p<0.05 的是 **F1·lgbm skip20%/30%**(族内 p=0.021/0.020;Sleeve ΔSR dev-OOS +0.039/+0.090,test +0.133/+0.109,全 +0.102/+0.103;组合 ΔSR +0.011/−0.026)。
**对抗检验(事后,仅检验稳健性,不改配置)**:
* 邻近格:skip q=5/10/15/20/25/30/35/40% 的 Sleeve ΔSR,dev-OOS 全正(+0.005~+0.165)、test 全正(+0.040~+0.133);LGBM 换 5 个随机种子:全 OOS +0.083~+0.117。→ 方向稳定,是本研究**第一个邻近格全同号**的结果。
* **效应量**:全部 <0.15 护栏;**组合层面 ΔSR 为 +0.011 ~ −0.03(≈0)**;选定配置的组合 ΔSR 区间含 0。
* **集中度**:把贡献最大的 5 个交易日还原为原收益,全 OOS ΔSR 由 +0.102 降至 **+0.012**(改善几乎全来自少数几天)。
* **仅空头有信号**:逐笔 IC 空头 +0.036(dev +0.040 / test +0.029),多头 0.000(−0.017 / +0.013)。被剔除的空头笔均 y +1.0bp vs 保留 +7.2bp;被剔除的多头笔 +12.2bp vs 保留 +10.8bp。
* **机制线索**:LGBM 增益重要度:`relvol` 33%、`z_open` 13%、`bo_strength` 12%。`relvol`(相对成交量)五分位 y = 5.7 / 5.6 / **18.1** / 7.4 / 5.7bp(非单调:只有中间一档延续);`bo_strength` 五分位 4.9 / 7.2 / 9.9 / 11.0 / 9.6(弱突破更差,与预设机制一致)。
* **但中档优势不稳**(切点取自 2019–2020,冻结后分方向检验,中档−其余,日聚类 t):空头 +4.9(t 1.0)/ −11.6(t −1.4)/ −3.0(t −1.0);多头 +2.3(0.5)/ +18.2(1.9)/ −1.7(−0.2),三个时期符号不一致。仅『多空合并』时看起来稳定(中档 +8.1/+16.1/+15.0 vs 其余),是方向混合造成的表象。
**判定:没有足够证据**(效应量 <0.15、组合 ≈0、集中在极少数天、关键的非线性结构分方向后不稳定),**但这是目前所有路线中最接近成立的一条**:邻近 q 与随机种子全部同号,有可解释的机制(弱突破、量能异常)。
**如何确认**:前向样本。在服务器的 live_noise 旁以『只记录』方式保存每笔入场的 F1 特征,攒够 ~150 个交易日 / ~4,500 笔(30 相位等价)后冻结 `F1·lgbm skip20%` 并一次性检验;若前向 ΔSR 同号且 >0.1,再考虑纳入。
