# v5 的仓位到底是怎么定的

问题:PPP 模型不是已经把 B&H 腿(核心仓)的权重定好了吗?为什么 v5 又在减核心仓权重?

先说结论:**PPP 从来没有决定过核心仓权重。** PPP 只管 Sleeve 的多头腿和空头腿。核心仓权重由一条固定规则给出,v5 在这条规则之上又加了一层不拟合参数的组合规则,核心仓被减,是这一层造成的。

数字来自 `studies/audit/explain_v5.py`(OOS 2021–26,`outputs/tables/explain_v5.csv`)。

## 1. 三层,各管什么

| 层 | 管什么 | 怎么定 | 有没有拟合参数 |
|---|---|---|---|
| 核心仓(B&H 腿) | QQQ 的目标权重 w_t | 规则:21 日已实现波动在过去 504 日里的分位 → 线性映射到 [0.5, 1.5](越平静越重);再乘趋势项(收盘低于 SMA200 则乘 0.5);全部滞后一天 | 无 |
| Sleeve | TQQQ 日内突破腿的大小 | 波动目标 e_t = min(4, 2%/σ14) 乘以 **PPP 的 k_long、k_short**(线性链接,特征 = CLEAN 7 个 + dur_rate,每年初用到上年底的数据重训,λ 由留一年交叉验证选) | 有(PPP) |
| v5 组合层 | 核心仓和 Sleeve 的相对比例与总占用 | 三条固定规则,见下 | 无(ρ = 1.5 事先固定) |

PPP 的目标函数里,核心仓的收益(加 CPI 回补)是被当作**外生给定**的一项(`Eb`),PPP 只是在给定核心仓的前提下,为两条 Sleeve 腿选 k。所以 PPP 没有能力、也没有被要求去定核心仓权重。

## 2. v5 组合层的三条规则

组合收益 = c·f·w·r_QQQ − 成本 + c·ρ·f·Sleeve_v4

1. **等风险配比 c_t(ρ = 1.5)。** 把 Sleeve 的权重从 1 提到 ρ = 1.5 会抬高组合风险。c_t = clip(σ252(v4 组合) / σ252(核心仓 + ρ·Sleeve), 0.5, 1.5)(滞后一天)同时缩小核心仓和 Sleeve,让组合波动保持在 v4 的水平。**核心仓权重下降的主要原因是这一条。** 平均 c = 0.85。
2. **买力上限 f_t。** TQQQ 是 3 倍,Sleeve 的名义占用是 e·k/3 倍资金。核心仓最高 1.5 倍,再加上 Sleeve,最坏情形占用可达 4.17 倍资金,而护栏是 2.57 倍(= 0.85 × 买力 \$1,513,400 / CAPITAL_BASE \$500,000)。f_t = min(1, 2.57 / 最坏占用),同时缩小两条腿。f<1 的天数约 15–20%,平均 f = 0.97,对核心仓权重的影响只有约 3%。
3. **核心仓不交易带 0.10。** 执行权重只在目标偏离当前持仓 ≥ 0.10 时才调整(或必须调整以满足买力上限),为了降低核心仓换手。

## 3. 核心仓权重去哪了

| 配置 | 核心仓均权 | Sleeve 乘数均值 | c 均值 | f 均值 | f<1 天数 | 核心仓年化波动 | Sleeve 年化波动 | 组合年化波动 | OOS Sharpe |
|---|---|---|---|---|---|---|---|---|---|
| v4 | 0.949 | 1.000 | 1.000 | 1.000 | 0% | 18.4% | 13.9% | 22.5% | 1.911 |
| + 买力上限 | 0.922 | 0.980 | 1.000 | 0.980 | 15% | 18.1% | 13.8% | 22.2% | 1.938 |
| + 买力上限 + 不交易带 | 0.925 | 0.980 | 1.000 | 0.980 | 15% | 18.1% | 13.8% | 22.2% | 1.959 |
| v5(ρ = 1.5) | 0.769 | 1.230 | 0.849 | 0.967 | 20% | 15.2% | 17.1% | 22.2% | 2.204 |

- v5 把核心仓权重从 0.95 减到 0.77(−19%),同时把 Sleeve 乘数从 1.0 提到 1.23(+23%),组合总波动几乎不变(22.5% → 22.2%)。这是在固定风险预算下把风险从核心仓搬到 Sleeve。
- 核心仓权重的下降**不是**"Sleeve 开仓时才减":Sleeve 有仓位的日子平均少 0.157,其他日子少 0.201。c 每天都作用,不依赖当天是否开仓。
- Sharpe 的提升(1.911 → 2.204)里,买力上限和不交易带合计约 +0.05,等风险配比约 +0.25。

## 4. 为什么要这样搬

两个资产的样本内数据(OOS 2021–26,v4 的两条腿):

| | 年化均值 | 年化波动 | Sharpe |
|---|---|---|---|
| 核心仓 | 11.1% | 18.4% | 0.60 |
| Sleeve(乘数 1) | 32.2% | 13.9% | 2.31 |
| 相关系数 | −0.05 | | |

核心仓的 Sharpe 只有 Sleeve 的约四分之一,两者几乎不相关。均值方差最优的 Sleeve:核心仓比例在样本内约 4.35 倍(相对 v4 的 1:1)。ρ = 1.5 是远低于这个数的保守取值,事先固定,不是从数据里挑的。

## 5. 这个设计的问题(诚实版)

1. **ρ 无法由数据识别。** ρ = 1/1.5/2/3 时 Sharpe 是 1.96/2.20/2.33/2.45,MDD 从 16.9% 加深到 18.9%。数据一直说"Sleeve 越重越好",所以 ρ 只能按风险偏好选。
2. **增益主要来自对波动的做多暴露。** v5 − v3(等波动)对 QQQ 收益的 β = −0.12(t = −5.2),对 QQQ 收益²的系数 = +2.46(t = 4.8),剩余 α = 3%/年(t = 0.78)。
3. **PPP 没有针对新的核心仓重训。** PPP 的效用函数用的是 v4 的核心仓,v5 之后核心仓变小了,风险厌恶系数和协方差都对不上。这是一个不一致,没有修。更干净的做法是把核心仓和 Sleeve 放进同一个 PPP,让 k 和核心仓权重由同一个效用函数决定。**这没有被检验过。** 如果要做,需要预注册,并且要说明为什么它不是又一次事后选择。
4. **买力上限里用了当日 kmax,有小的前视。** PR #2 发现,量化后 ΔSR = −0.024。实现时用 k = 2 的上界(`build_v5(..., pit_cap=True)`)。
5. 证据等级 E1(见 HARNESS.md)。v5 是多轮研究后选定的,没有前瞻验证。
