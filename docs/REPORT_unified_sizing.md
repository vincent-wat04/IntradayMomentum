# 研究报告:用一个模型统一「低波动日缩仓」与「恐慌日空头加码」

2026-10-12。数字全部来自 `PROPOSAL_unified_sizing.md`(预注册)与其偏离记录(事后)。脚本 `studies/unified_sizing_study.py`、`studies/unified_sizing_posthoc.py`。

## 1. 先回答你的三个问题

**Q1. 该用一个模型还是两个(低波模型 + 高波模型)?**
不该把它当成两个分类问题。原因是 Sleeve 的收益结构:OOS 2021–2026 里,位移最低 20% 的日子日均 **−28.4bp**,中间 60% 的日子 **−6.6bp**,最高 20% 的日子 **+77.7bp**。也就是说"平静日"不是唯一的问题,**中间的 60% 也在亏**,而所有利润集中在 20% 的大位移日。两个分类头(U4)各自只看一端,会对中间区域一无所知;而真正决定仓位的是"今天这条腿的期望收益是多少"这一个连续量。

更关键的是,**两条腿在同一天的条件期望经常符号相反**(上一轮发现:"今日跳空跌且 VIX>20"时空头腿 +8.4bp、多头腿 +0.5bp)。所以统一模型的输出应该是**每条腿一个仓位乘数** `k_long(x)`、`k_short(x)`,而不是一个"今天大不大"的标量。

**Q2. 看 precision、recall 还是 AUC?**
三个都不该作为选模型的标准,应该直接看经济目标。证据:
* 识别低振幅日 AUC 最高的模型(ML-10:00,0.858)经济效果最差(上一轮)。
* 本轮低位移头 AUC 只有 0.533,而且严重过度自信(校准斜率 0.19,Brier 比常数预测还差)。
* 跳过决策是**代价不对称**的:错跳一个大位移日亏 78bp,正确跳过一个平静日只省 12~28bp。可以从数据直接算出跳过决策需要的 precision:**被跳过的日子里大位移日占比必须低于约 13%**,而它们的基础占比是 21%。没有一个模型能在任何标记率下稳定做到这一点(利润曲线见 §4)。

如果非要选一个分类指标,应该是**代价加权的利润曲线**(按"标记比例 → 被标记日平均收益"画),这和 Elkan(2001)的代价敏感学习、以及 de Prado 的 meta-labeling 思路一致。AUC 是排序指标,对称地对待两类错误,在这里是错的度量。

**Q3. 用 sigmoid 缩放仓位?**
方向对,但要注意**把什么放进 sigmoid、用什么目标拟合**:
* 先训练分类器、再把概率塞进 sigmoid(U4a)→ **最差**(Sleeve ΔSR −0.218)。两步法里分类器优化的是对数损失,不是收益。
* 先回归预测收益、再 sigmoid 映射(U2,de Prado 式)→ ≈0。
* **直接用 sigmoid 作为策略的函数形式、以效用为目标端到端拟合(U3,Brandt–Santa-Clara–Valkanov 2009 的参数化组合策略 PPP)→ 本研究线上第一个族内显著的结果。**
  `k_leg = 2·σ(θ_legᵀ z)`:θ=0 时 k=1(就是基线),输出天然有界在 (0,2),系数可解释。

## 2. 方法(专业视角的五个设计决定)

1. **目标函数 = 经济目标**:最大化 `mean(R) − γ/2·var(R) − λ‖θ‖²`,γ 取使基线处于一阶条件的值,λ 按"留一年"交叉验证。不预测任何中间变量。
2. **腿级分解**:从 30 相位成交明细精确重建每条腿的逐日净损益(与基线逐日差 0.000000bp)。仓位缩放对止损逻辑无影响,所以对某条腿乘 k 是**精确**的,不需要重跑模拟。
3. **σ₁₄ 不动,模型在其上做乘数**:符合你"σ₁₄ 负责平稳期放大、模型反向调整"的定义;同时避免了上一轮"替换 σ₁₄ 会削掉凸性"的问题。
4. **严格的 walk-forward**:每年初只用之前的数据训练,OOS 2021–2026。第一折只有 397 天,所以模型必须低复杂度(10 个特征、线性指数)。
5. **污染控制**:三个特征(`ffa_rank`、`P3`、`P4`)是在 2019–2026 上发现的,会让 OOS 偏乐观。我专门做了去掉它们的版本。

## 3. 你给的论文:Reactive Volatility Model(Valeyre et al. 2013)

**它做什么**:用两条价格均线(慢 λ_s=0.024、快 λ_f=0.148)构造一个"修正价格水平" L,让 ΔI/L 比 ΔI/I 更同方差;波动 = 稳定的 σ̃ × 即时的反应因子 L/I。核心是**恐慌效应**:价格跌破快均线时,σ 按 `ℓ·(L_f − I)/L_f` 即时放大(ℓ=8,指数跌 1% → 波动升约 8%)。

**在 QQQ 上复现**(2009–2026,n=4293):

| 估计量 | 与 VXN 日变化的 R² | 论文(V2X) |
|---|---|---|
| **RVM** | **0.508** | 0.45 |
| EWMA | 0.063 | 0.15 |
| GARCH(1,1) | 0.093 | 0.003 |

论文结论完全复现,GARCH 参数(α=0.101、β=0.889)也和论文几乎一致。

**它对我们有什么用**:
* 论文自己说这个模型**不能预测极端事件**(按它的预警规则,96.7% 的极端事件会被漏掉)。所以它不是"高波动预测模型"。
* 它的价值在于**即时性**:恐慌因子可以在 **10:00 用当时的价格更新**,这是 VIX(t−1) 做不到的。我把它做成了两个特征 `rvm_panic`、`rvm_ratio`。
* 在学到的模型里它确实有用:空头腿 `rvm_panic` 系数 −0.84、`rvm_ratio` −0.88;多头腿 `rvm_ratio` +0.95。
* 直接拿 RVM 替换 σ₁₄ 做仓位:Sleeve SR 1.02 → 1.10,但大位移日仓位降到 0.86 倍 —— 和 FFA 一样会削凸性,不推荐。

## 4. 结果

### 4.1 预注册的 4 个方案(OOS 2021–2026)
| 方案 | Sleeve ΔSR(dev / test) | 组合 ΔSR(dev / test / 全) | 族内 p |
|---|---|---|---|
| U2 双头回归 + sigmoid | +0.05 / +0.02 | +0.12 / −0.02 / +0.03 | 0.51 |
| **U3 PPP(Sleeve 效用)** | **+0.60 / +0.16** | +0.40 / **−0.08** / +0.08 | **0.026** |
| U4a 双分类器 + sigmoid | −0.30 / −0.17 | +0.00 / −0.12 / −0.07 | 0.98 |
| U4b 只跳过 | −0.18 / −0.23 | −0.09 / −0.17 / −0.13 | 0.98 |

U3 在 Sleeve 层显著(族内 p=0.026),**但在组合层 test 期为负**。按预注册判定:线索,不是证据。

### 4.2 为什么 Sleeve 层赢、组合层没赢:模型拆掉了自己的对冲
诊断发现:**空头腿和 QQQ 腿的相关是 −0.40**(多头腿 +0.37)。U3 只优化 Sleeve 自身的效用,把空头腿平均缩到 0.77 倍,结果 Sleeve 与 QQQ 腿的相关从 −0.08 变成 +0.04 —— 在组合层面拆掉了对冲。

**这是一个目标函数设定错误**:Sleeve 是组合的一部分,应该优化组合效用。我把目标改成组合(Sleeve + QQQ 腿)后重跑(事后,已标注):

| 事后方案 | 组合 ΔSR(dev / test / 全)[95%] | p(圆周平移) | 组合 CAGR / MDD |
|---|---|---|---|
| 基线 | — | — | 30.4% / −20.3% |
| U3p(组合目标) | +0.46 / **+0.11** / +0.23 [−0.07, +0.55] | 0.026 | 38.7% / **−19.6%** |
| **U3p-clean(组合目标、去掉 3 个污染特征)** | +0.11 / **+0.32** / **+0.24** [−0.09, +0.58] | **0.025** | **39.3%** / −20.3% |

**最重要的发现:去掉在本样本上发现的三个特征后,增益不降反升**(+0.237 vs +0.231)。说明增益来自通用特征(VIX 变化、RVM 恐慌因子、首 30 分钟振幅、隔夜缺口),不是来自我们事后挑出的规则。

### 4.3 模型学到了什么(可解释,U3p-clean 六折均值)
| 特征 | 多头腿系数 | 空头腿系数 | 含义 |
|---|---|---|---|
| `dlvix`(昨日 VIX 变化) | −1.17 | **−2.16** | 昨天恐慌升温 → 两腿都缩,空头更多(昨日恐慌后常反弹,与上一轮 P1/P2 一致) |
| `rvm_panic`(10:00 即时恐慌) | +0.05 | −0.84 | 已经在跌 → 空头缩仓(避免追空) |
| `rvm_ratio`(反应因子) | **+0.95** | −0.88 | 价格低于均线的程度 → 多头加、空头减(均值回归) |
| `b30_n`(首 30 分钟振幅) | **+0.82** | +0.21 | 开盘就动起来 → 加仓(对应"高位移日"识别) |
| `lvix_z`(VIX 水平) | −0.01 | **+0.71** | 高波动环境 → 空头加仓 |
| `gap_n` / `r30_n` | +0.72 / −0.66 | +0.01 / +0.27 | 缺口方向与首半小时反向时多头加仓 |

注意:这和你直觉中的"恐慌时加大空头"**只部分一致**。模型学到的是区分**恐慌水平**(VIX 高 → 空头加)和**恐慌变化**(VIX 刚升 / 价格已跌 → 空头减,因为常有反弹)。

### 4.4 局限(必须看)
* **事后**:组合目标与去污染版本都是看到 U3 结果后加的,共 8 个配置;按 8 个族校正后 p 约 0.1~0.2。
* **2022 年(熊市)所有变体都为负**(−0.02 ~ −0.31)。模型在单边下跌年里会少赚。
* **左尾没改善**:clean 版本组合 CVaR5% 从 −244.6 变成 −265.9bp,最差日从 −438.5 变成 −514.2bp。均值–方差目标不惩罚左尾。
* 第一折训练只有 397 天;6 个 OOS 年里有 2 个为负。

## 5. 判定与建议

**判定:强线索(前向验证候选),不是证据。** 这是整个研究线上第一个同时满足以下条件的结果:族内 p<0.05、dev/test 同号为正、去掉污染特征后依然成立、系数有经济含义。但组合 ΔSR 区间含 0,按 8 个配置校正后不显著。

**专业建议(按优先级):**
1. **前向影子运行 U3p-clean**:冻结当前系数(或每年初重训),每天 10:00 记录两条腿的 k 值与假设收益,不实际执行。12 个月后用冻结的标准判定。
2. **目标函数换成惩罚左尾的版本**:例如 `mean − γ/2·var − η·CVaR5%`,或 Sortino 效用。这是唯一可能同时改善 Sharpe 和最差日的方向。需要新的预注册。
3. **约束 k 的范围**:实盘建议把 k 限制在 [0.5, 1.5] 而不是 (0, 2),减少极端仓位;回测里 k 的标准差约 0.4。
4. **不要做的事**:不要把分类器 AUC 当作选模型的标准;不要把两个分类器的概率差塞进 sigmoid;不要只优化 Sleeve 自身的效用(会拆掉对冲)。
